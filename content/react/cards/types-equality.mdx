## Why it exists

JavaScript converts types on its own in `==`, `+` and `if`. Knowing the rules explains most "what prints?" puzzles and many real bugs.

## How it works

<Compare id="loose-vs-strict-equality" />

- `+` with a string operand joins text; `*` turns strings into numbers.
- Copying an object copies the reference: see [shallow vs deep copy](compare:shallow-vs-deep-copy).

## Example

```javascript
console.log(typeof null, typeof NaN, typeof function () {});
console.log(0 == "", null == undefined, null == 0);
console.log("1" + 2, "3" * 2, [] == false);
console.log(NaN === NaN, Number.isNaN(NaN), Object.is(NaN, NaN));
console.log([] === [], Boolean([]), Boolean(""));
```

```text output
object number function
true true false
12 6 true
false true true
false true false
```

## Interview Qs

### How do you check for NaN?

`Number.isNaN(x)`. `NaN` is not equal to itself, so `x === NaN` is always false, and the global `isNaN` converts its argument first.

### Why is typeof null "object"?

A quirk from the first JavaScript version; a proposed fix was rejected. Test with `x === null`.
