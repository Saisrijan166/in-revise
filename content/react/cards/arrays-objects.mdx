## What it is

Arrays and objects are the everyday containers in JavaScript, and both are objects, so they are copied and compared by reference (you saw this in [types and equality](card:types-equality)). Array methods fall into two groups: some return a new array and leave the old one alone, and some change the array in place. Three pieces of newer syntax make working with data shorter: spread and rest (both `...`), destructuring (pulling values out by shape), and the `?.` and `??` operators for values that might be missing.

## Why it exists

Most frontend work is reshaping data: filter a list of payments by status, add up a cart, copy one field of state before changing it. Doing this by hand with index loops is long and error-prone. The array methods and the spread, destructuring, `?.` and `??` syntax express each of these tasks in one readable line. The one thing you must track is which operations copy and which mutate, because in React you must replace state, not change it in place.

## How it works

| Need | Use |
|---|---|
| Transform every item | `map` |
| Keep only matching items | `filter` |
| Find one item, or a yes / no | `find`, `some`, `every` |
| Combine into one value | `reduce` |
| A sorted copy | `toSorted` (not `sort`, which mutates) |
| Copy an object or array | `{ ...obj }`, `[...arr]` |
| Read a maybe-missing value | `obj?.prop`, `value ?? fallback` |

1. `map` and `filter` walk the array and return a new one; the original is never touched.
2. `reduce` carries a running value from item to item, so a cart of prices folds down to a single total.
3. `sort`, `push` and `splice` change the array in place; the ES2023 `toSorted`, `toReversed`, `toSpliced` and `with` do the same jobs but return a copy.
4. `obj?.prop` returns `undefined` instead of throwing when `obj` is null or undefined, and `a ?? b` gives `b` only when `a` is null or undefined (unlike `||`, which also replaces `0` and `""`).

## Example

The payments dashboard totals a cart, lists names, and finds the cheapest item without disturbing the original order.

```javascript
const cart = [
  { name: "Wireless Mouse", price: 799, qty: 2 },
  { name: "USB-C Cable", price: 299, qty: 1 },
];
const total = cart.reduce((sum, item) => sum + item.price * item.qty, 0);
const names = cart.map((item) => item.name);
const cheapest = cart.toSorted((a, b) => a.price - b.price)[0];
console.log(total, names, cheapest.name, cart[0].name);
const { name, discount = 0 } = cart[0];
console.log(name, discount, cart[2]?.name);
console.log(0 || 50, 0 ?? 50);
```

```text output
1897 [ 'Wireless Mouse', 'USB-C Cable' ] USB-C Cable Wireless Mouse
Wireless Mouse 0 undefined
50 0
```

What to notice:

- `reduce` starts at `0` and adds `price * qty` for each item, giving `1897`.
- `toSorted` returns a sorted copy, so `cart[0].name` is still `"Wireless Mouse"`: the original order is preserved.
- `discount = 0` is a destructuring default; it applies because `cart[0]` has no `discount` field. `cart[2]?.name` is `undefined` instead of an error because `cart[2]` is missing.
- `0 || 50` is `50` (0 is falsy) but `0 ?? 50` is `0`: `??` keeps a real zero.

## Rules and defaults

- **Copying vs mutating methods:** `map`, `filter`, `slice`, `concat`, `toSorted`, `toReversed`, `toSpliced` and `with` return a new array; `push`, `pop`, `splice`, `sort` and `reverse` mutate in place.
- **`toSorted` and friends:** added in ES2023, supported in current browsers and Node 20+.
- **Destructuring defaults:** apply only when the value is `undefined` (or the property is absent), never when it is `null`.
- **`??` vs `||`:** `??` falls back only for `null`/`undefined`; `||` falls back for any falsy value. For a numeric or string field that can be `0` or `""`, use `??`.

## Not to be confused with

Spreading an object or array (`{ ...order }`) makes a shallow copy: the top level is new, but nested objects are still shared with the original. A [deep copy](compare:shallow-vs-deep-copy) with `structuredClone` copies every level. Rule: spread is enough when you only change top-level fields; reach for `structuredClone` when you must change nested data without touching the original.

## Interview Qs

### What is the difference between map and forEach?

`map` returns a new array built from what the callback returns for each item, so you can chain it or render it. `forEach` only runs the callback for its side effects and returns `undefined`, so it cannot be chained and is not used to build a value.

### What is the difference between spread and rest?

They share the `...` syntax but work in opposite directions. Spread expands an array or object into separate pieces, as in `[...cart, item]` or `{ ...order, status: "paid" }`. Rest collects several pieces into one, as in `function add(...items)` or `const { id, ...others } = product`.

### When does a destructuring default actually apply?

Only when the value is `undefined` or the property is missing. A property set to `null` keeps `null` and ignores the default. If you also want to replace `null`, read the property and apply `?? fallback` instead.
