## Why it exists

Most frontend work is reshaping lists and objects: filtering products, totalling a cart, copying state. Knowing which methods copy and which mutate prevents bugs.

## How it works

| Need | Use |
|---|---|
| Change every item | `map` |
| Keep some items | `filter` |
| One item, or a yes / no | `find`, `some`, `every` |
| One total | `reduce` |
| Sorted copy | `toSorted` (not `sort`) |
| Copy an object | `{ ...obj }` or [structuredClone](compare:shallow-vs-deep-copy) |

- React state must be replaced, not mutated: see [useState](card:use-state).

## Example

```javascript
const cart = [
  { name: "Wireless Mouse", price: 799, qty: 2 },
  { name: "USB-C Cable", price: 299, qty: 1 },
];
const total = cart.reduce((sum, item) => sum + item.price * item.qty, 0);
const names = cart.map((item) => item.name);
const cheapest = cart.toSorted((a, b) => a.price - b.price)[0];
console.log(total, names, cheapest.name, cart[0].name);
const { name, discount = 0 } = cart[0];
console.log(name, discount, cart[2]?.name);
console.log(0 || 50, 0 ?? 50);
```

```text output
1897 [ 'Wireless Mouse', 'USB-C Cable' ] USB-C Cable Wireless Mouse
Wireless Mouse 0 undefined
50 0
```

```javascript
const order = { id: 1, items: [{ name: "Laptop Stand", qty: 1 }] };
const shallow = { ...order };
const deep = structuredClone(order);
shallow.items[0].qty = 5;
console.log(order.items[0].qty, deep.items[0].qty);
```

```text output
5 1
```

## Interview Qs

### map vs forEach?

`map` returns a new array of the callback's results. `forEach` only runs the callback and returns `undefined`, so it cannot be chained or rendered.

### Spread vs rest?

Same `...` syntax. Spread expands an array or object into places: `[...cart, item]`. Rest collects leftovers into one: `function add(...items)` or `const { id, ...rest } = product`.

### When does a destructuring default apply?

Only when the value is `undefined` or missing, not when it is `null`.
