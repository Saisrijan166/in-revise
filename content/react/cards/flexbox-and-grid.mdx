## What it is

Flexbox and Grid are the two modern CSS layout systems. You turn an element into a **container** (`display: flex` or `display: grid`), and its direct children become **items** that the container arranges for you, instead of you giving each child a fixed width and position. **Flexbox** lays items out along one axis at a time, a row or a column, and lets the content decide the sizes. **Grid** lays items into rows and columns together, from a layout you define up front.

## Why it exists

Before these, people built layouts with floats and fixed pixel widths, which broke the moment the content or the screen size changed, and centring a box vertically was a well-known headache. A layout really needs items that align, space out and resize as the screen changes. Flexbox and Grid do that with a few properties on the container, so the items flow and stretch on their own instead of being pinned to exact sizes.

## How it works

The quickest way to choose between them is to compare what each one is built for.

<Compare id="flexbox-vs-grid" />

1. You pick the container type: `display: flex` for a single row or column, `display: grid` for a two-dimensional layout.
2. In Flexbox you set the direction (`flex-direction`), then space items along the main axis with `justify-content` and along the cross axis with `align-items`.
3. In Grid you define the columns (and optionally rows) with `grid-template-columns`, often using the `fr` unit and `repeat()`.
4. Both use `gap` to set the space between items, and both can wrap items onto new lines.

So the key is the number of dimensions: reach for Flexbox when one axis is enough, and Grid when rows and columns must line up together. Where the layout itself changes by screen size is the job of [media queries](card:responsive-design).

## Example

This builds two pieces of a payments dashboard: a flex navbar and a grid of payment cards.

```css
/* Top bar: one row, Flexbox */
.navbar { display: flex; justify-content: space-between; align-items: center; gap: 16px; }

/* Payment cards: as many columns of at least 200px as fit */
.payment-cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}

/* Centre an "empty state" box both ways */
.empty-state { display: grid; place-items: center; }
```

What to notice:

- `justify-content: space-between` pushes the first and last items to the edges of the row and spreads the rest evenly, so the logo and buttons sit at opposite ends.
- `minmax(200px, 1fr)` says each column is at least 200px and may grow to a share of the leftover space; `auto-fill` then makes as many such columns as fit before wrapping.
- `place-items: center` is shorthand for `align-items` plus `justify-items`, so the content lands dead centre of the grid both ways in one line.
- Change `auto-fill` to `auto-fit` and empty trailing columns collapse, so the visible cards stretch to fill the whole row.

## Rules and defaults

- **Flex defaults:** `flex-direction: row`, and each item is `flex: 0 1 auto` (do not grow, may shrink, start from the content size); items stretch to fill the cross axis.
- **justify-content vs align-items:** `justify-content` always works along the main axis, `align-items` along the cross axis; the axes swap when `flex-direction` is `column`.
- **fr unit:** a fraction of the leftover space in a grid, so `1fr 2fr` splits the free space one-third and two-thirds.
- **gap:** works in both Flexbox and Grid for the space between items, and replaces older margin tricks.

## Interview Qs

### How do you centre a div horizontally and vertically?

The simplest way is to make the parent a flex container with `display: flex; justify-content: center; align-items: center`, which centres the child on both axes. With Grid, `display: grid; place-items: center` does the same in one property. Both work regardless of the child's size, which is why they replaced the old margin and transform tricks.

### What does flex: 1 mean?

`flex: 1` is shorthand for `flex-grow: 1; flex-shrink: 1; flex-basis: 0%`. Each item starts from a base size of zero and then takes an equal share of the free space, so several siblings with `flex: 1` end up the same width, unless their content forces a larger minimum size on one of them.

### auto-fill versus auto-fit in repeat()?

Both create as many column tracks as fit the container. The difference shows when there are too few items to fill a row: `auto-fill` keeps the empty tracks, so your items stay their defined size and leave gaps; `auto-fit` collapses the empty tracks, so items with a `1fr` maximum stretch to fill the whole row.
