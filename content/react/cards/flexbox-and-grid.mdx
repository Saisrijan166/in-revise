## Why it exists

Layouts need items aligned, spaced and resized as the screen changes. Flexbox and Grid do this with a few properties on the container instead of fixed widths.

## How it works

<Compare id="flexbox-vs-grid" />

- Both use `gap` for the space between items.
- Where the layout changes by screen size is a job for [media queries](card:responsive-design).

## Example

```css
/* Navbar: one row, Flexbox */
.navbar { display: flex; justify-content: space-between; align-items: center; gap: 16px; }

/* ProductList: as many columns of at least 200px as fit */
.products {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}

/* Centre a box both ways */
.empty-cart { display: grid; place-items: center; }
```

## Interview Qs

### How do you centre a div horizontally and vertically?

Make the parent a flex container with `justify-content: center` and `align-items: center`, or a grid container with `place-items: center`.

### What does flex: 1 mean?

It is flex-grow 1, flex-shrink 1, flex-basis 0%. Each item starts from zero and takes an equal share of the free space, so siblings with flex: 1 match unless content forces a bigger minimum.

### auto-fill vs auto-fit in repeat()?

Both create as many tracks as fit. auto-fit then collapses the empty tracks, so items with a 1fr maximum stretch across the row; auto-fill keeps the empty tracks.
