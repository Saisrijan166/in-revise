## Why it exists

A slow first screen or janky scrolling comes from one step of this pipeline; knowing the steps shows which to fix.

## How it works

<Steps label="From URL to pixels">
  <Step title="DNS lookup">Find the server's IP address.</Step>
  <Step title="TCP and TLS">Open the connection; HTTPS adds a TLS handshake.</Step>
  <Step title="HTTP request">GET the HTML; parsing starts on the first chunk.</Step>
  <Step title="HTML to DOM">Build the DOM; fetch the files it names.</Step>
  <Step title="CSS to CSSOM">Build the CSSOM; rendering waits for it.</Step>
  <Step title="Render tree">Visible nodes with computed styles.</Step>
  <Step title="Layout">Work out the size and position of every box.</Step>
  <Step title="Paint and composite">Fill pixels per layer, then stack the layers.</Step>
</Steps>

- These steps are the critical rendering path; a shorter one paints sooner.
- Load app scripts with `defer` (or `type="module"`): [async vs defer](compare:async-vs-defer).
- To measure load speed, see [measuring performance](card:measuring-performance).

## Example

```html
<head>
  <link rel="stylesheet" href="/shop.css" />   <!-- render-blocking -->
  <script src="/analytics.js" async></script>  <!-- runs as soon as it arrives -->
  <script src="/app.js" defer></script>        <!-- runs after parsing, in order -->
</head>
```

## Interview Qs

### What happens when you type a URL and press Enter?

DNS finds the IP, TCP and TLS open a secure connection, and the browser sends a GET. It parses HTML into the DOM and CSS into the CSSOM, builds the render tree, then runs layout, paint and compositing.

### What triggers a reflow, and how do you avoid extra ones?

Changing geometry: width, height, position, new nodes, a resize. Batch DOM changes, animate `transform` and `opacity` instead of box properties, and give images a width and height.

### Why use defer instead of a plain script in the head?

A plain script pauses HTML parsing while it downloads and runs. A deferred script downloads in parallel and runs after parsing, so content appears sooner.
