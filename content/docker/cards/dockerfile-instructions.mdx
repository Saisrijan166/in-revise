## Why it exists

An image built by hand cannot be repeated or reviewed. A Dockerfile writes the steps down, so anyone can rebuild the same image with one command.

## How it works

| Instruction | What it does |
|---|---|
| `FROM` | Picks the base image and starts a stage |
| `WORKDIR` | Sets the folder for later steps; created if missing |
| `COPY`, `ADD` | Put files in the image: [COPY vs ADD](compare:copy-vs-add) |
| `RUN` | Runs a command; the result becomes a layer |
| `ARG`, `ENV` | Variables: [ARG vs ENV](compare:arg-vs-env) |
| `LABEL` | Adds key-value metadata |
| `EXPOSE` | Documents a port: [port mapping](card:port-mapping) |
| `USER` | User for later steps and the container: [image security](card:image-security) |
| `VOLUME` | Marks a mount point: [volumes](card:volumes-and-mounts) |
| `HEALTHCHECK` | A command that tests health: [health checks](card:container-health-checks) |
| `STOPSIGNAL` | The signal docker stop sends: [shutdown](card:signals-and-graceful-shutdown) |
| `CMD`, `ENTRYPOINT` | What the container runs: [RUN vs CMD vs ENTRYPOINT](card:run-cmd-entrypoint) |

- `# syntax=docker/dockerfile:1` on line 1 makes BuildKit use the latest stable Dockerfile syntax.
- The final `.` in `docker build` is the [build context](card:docker-build-context).

## Example

```dockerfile
# syntax=docker/dockerfile:1
FROM eclipse-temurin:25-jre
WORKDIR /app
LABEL org.opencontainers.image.version="1.4.0"
COPY target/payment-service-1.4.0.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```

```bash
./mvnw package                            # the jar must exist first
docker build -t payment-service:1.4.0 .
```

## Interview Qs

### What is a Dockerfile, and how do you build it?

A text file of instructions that produces an image. `docker build -t payment-service:1.4.0 .` runs it, sending the current folder as the build context.

### Which instructions run at build time?

FROM, RUN, COPY, ADD and ARG work during the build. CMD, ENTRYPOINT, EXPOSE and HEALTHCHECK are only stored as settings for containers. ENV and USER affect both.

### Why should WORKDIR be set explicitly?

Without it, the default is `/` or whatever the base image chose. Setting it avoids running steps in an unknown folder.
