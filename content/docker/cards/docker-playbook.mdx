## Why it exists

Most Docker questions reuse a dozen rules. Learn images, the Dockerfile, ports, volumes and networks first.

## How it works

| Don't say | Say |
|---|---|
| A container is a small VM | [A process sharing the host kernel](card:containers-and-vms) |
| EXPOSE publishes the port | [It documents; -p publishes](card:port-mapping) |
| `latest` is the newest version | [Only the default tag name](card:registries) |
| `docker ps` lists every container | [Running only; add -a](card:docker-cli-essentials) |
| Files in a container are kept | [Lost on docker rm; use a volume](card:volumes-and-mounts) |
| ENV is fine for a password | [docker inspect shows it](card:env-and-secrets) |
| Running means healthy | [Add a health check](card:container-health-checks) |
| Docker restarts crashed containers | [Only with a restart policy](card:container-lifecycle) |
| depends_on waits for the DB | [Only with service_healthy](card:compose-startup-order) |
| Root inside is harmless | [Set a non-root USER](card:image-security) |
| Ship the JDK and Maven | [Multi-stage: JRE and JAR only](card:multi-stage-builds) |
| Kubernetes needs Docker | [A CRI runtime is enough](card:docker-and-orchestration) |

- Build: FROM, RUN, COPY, ADD, ARG. Run: CMD, ENTRYPOINT, -e, -p, -v. ENV: set at build, -e overrides.

## Interview Qs

### What happens when you run `docker run -p 8080:8080 payment-service:1.4.0`?

Docker pulls the image if missing, creates a container with a writable layer, joins the default network, publishes port 8080 and starts ENTRYPOINT plus CMD.

### Explain Docker in one minute.

An image is a read-only template built from a Dockerfile; a container is its running instance with a writable layer. Containers share the host kernel, publish ports with -p, keep data in volumes; Compose runs several.
