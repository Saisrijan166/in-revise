## Why it exists

An app that works on a laptop often fails on a server with other library versions. A container carries the app and its dependencies, so it runs the same everywhere.

## Example

```bash
uname -r                                          # host kernel: 6.8.0-45-generic
docker run --rm eclipse-temurin:25-jre uname -r   # container: 6.8.0-45-generic, the same kernel
```

## Interview Qs

### Can a Linux container run on a Windows or macOS machine?

Not directly: it needs a Linux kernel. Docker Desktop runs a small Linux VM (WSL 2 by default on Windows) and the containers run inside it. Windows containers are a separate kind that need a Windows host.

### Does a container contain a full operating system?

No. It has user-space files from its base image, such as libraries and a shell, but no kernel. Every container on a host uses the host's kernel.

### Containers or VMs: which do you choose?

Usually both. VMs give a strong boundary and any OS; containers pack many apps densely and start fast. In the cloud you rent VMs and run several containers on each.
