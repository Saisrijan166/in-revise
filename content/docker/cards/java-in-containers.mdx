## Why it exists

A JVM sizes its heap and thread pools from the memory and CPUs it sees. Inside a container it must use the container's limits, not the whole host's.

## How it works

| JVM flag | What it controls | Default (Java 25, Linux) |
|---|---|---|
| `UseContainerSupport` | Read the container's memory and CPU limits | On |
| `-XX:MaxRAMPercentage` | Max heap, as % of available memory | 25 |
| `-XX:InitialRAMPercentage` | Starting heap, as % of available memory | 1.5625 |
| `-XX:ActiveProcessorCount` | CPUs used to size GC and pool threads | Detected |

- A 1 GB [memory limit](card:resource-limits) gives a 256 MB max heap by default.
- Spring Boot 4.1: `java -Djarmode=tools -jar application.jar extract --layers` gives four layers: dependencies, spring-boot-loader, snapshot-dependencies, application.
- Shutdown on SIGTERM: [graceful shutdown](card:signals-and-graceful-shutdown).

## Example

```dockerfile
FROM eclipse-temurin:25-jre AS extract
WORKDIR /x
COPY target/payment-service-1.4.0.jar application.jar
RUN java -Djarmode=tools -jar application.jar extract --layers --destination out

FROM eclipse-temurin:25-jre
WORKDIR /app
COPY --from=extract /x/out/dependencies/ ./
COPY --from=extract /x/out/spring-boot-loader/ ./
COPY --from=extract /x/out/snapshot-dependencies/ ./
COPY --from=extract /x/out/application/ ./
ENTRYPOINT ["java", "-jar", "application.jar"]
```

## Interview Qs

### Does Java know it runs in a container?

Yes. On Linux, since JDK 10 and 8u191, the JVM reads the container's memory and CPU limits; UseContainerSupport is on by default. Older Java 8 builds sized the heap from the host's memory.

### The container was OOM-killed but the heap looked fine. Why?

The limit covers the whole process: heap plus metaspace, thread stacks and direct buffers. Lower MaxRAMPercentage or raise the limit; see [troubleshooting](card:troubleshooting-containers).

### Why use a layered jar?

A fat jar is one layer, so each code change re-ships every library. With layers, the dependencies layer stays cached and only the small application layer changes.
