## Why it exists

Interviewers reuse one data set, a list of employees with a name, a department and a salary, because it tests filter, sort, max and grouping in a few minutes.

## How it works

| Question | Pipeline |
|---|---|
| Highest-paid employee | `max(comparingInt(Emp::salary))` |
| Names earning over 50,000 | `filter(e -> e.salary() > 50_000).map(Emp::name).toList()` |
| By salary, highest first, then name | `sorted(comparingInt(Emp::salary).reversed().thenComparing(Emp::name))` |
| Top 3 earners | `sorted(comparingInt(Emp::salary).reversed()).limit(3)` |
| Nth highest salary | `map(Emp::salary).distinct().sorted(reverseOrder()).skip(n - 1).findFirst()` |
| Count, total or average per department | `groupingBy(Emp::dept, counting())`, or `summingInt`, `averagingInt` |
| Names per department | `groupingBy(Emp::dept, mapping(Emp::name, toList()))` |
| Highest paid per department | `toMap(Emp::dept, e -> e, BinaryOperator.maxBy(comparingInt(Emp::salary)))` |
| Over and under 50,000 | `partitioningBy(e -> e.salary() > 50_000)` |
| Department with most people | count per department, then `entrySet().stream().max(Map.Entry.comparingByValue())` |

- Static imports assumed: `Comparator.*` and `Collectors.*`. Each collector is explained in [Collectors](card:collectors).

## Example

```java
record Emp(String name, String dept, int salary) {}
List<Emp> emps = List.of(new Emp("Asha", "IT", 90_000), new Emp("Ravi", "IT", 70_000),
        new Emp("Meena", "IT", 70_000), new Emp("Neha", "HR", 60_000));
Map<String, Emp> topByDept = emps.stream().collect(Collectors.toMap(
        Emp::dept, e -> e, BinaryOperator.maxBy(Comparator.comparingInt(Emp::salary))));
// {HR=Neha, IT=Asha}
int secondSalary = emps.stream().map(Emp::salary).distinct()
        .sorted(Comparator.reverseOrder()).skip(1).findFirst().orElseThrow();   // 70000
String busiest = emps.stream().collect(Collectors.groupingBy(Emp::dept, Collectors.counting()))
        .entrySet().stream().max(Map.Entry.comparingByValue())
        .map(Map.Entry::getKey).orElse("none");                                 // IT
```

## Interview Qs

### Highest salary in each department, without Optional in the map?

`groupingBy(Emp::dept, maxBy(...))` gives `Map<String, Optional<Emp>>`. Use `toMap(Emp::dept, e -> e, BinaryOperator.maxBy(...))`, or wrap it: `collectingAndThen(maxBy(...), Optional::get)`.

### How do you sort by salary descending, then by name?

`comparingInt(Emp::salary).reversed().thenComparing(Emp::name)`. `reversed()` flips everything chained before it, so call it before `thenComparing`, or the names come out in reverse too.
