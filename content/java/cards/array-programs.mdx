## What it is

Array programs take an `int[]` and answer one question about it: the largest value, the second largest, the sum, the reverse or the duplicates. An array is a fixed-size row of values of one type, read by index from 0 to `length - 1`. Most answers are a single pass: one loop over every element that updates a few variables, the state from [the coding method](card:coding-method).

## Why it exists

Arrays test loops, indexes and edge cases at the same time: an empty array, one element, duplicates and negative numbers. The usual bugs are a wrong start value, such as 0 for a max when every value is negative, and an index that runs one past the end. Interviewers also check that you solve it in one pass instead of sorting first.

## How it works

| Problem | Pattern |
|---|---|
| Sum, average | `sum += n`; average is `(double) sum / a.length` |
| Max, min | start from `a[0]`, then `Math.max`, `Math.min` |
| Count even or odd | `if (n % 2 == 0) count++` |
| Search | a loop, or `Arrays.binarySearch` on a sorted array |
| Sort | `Arrays.sort(a)`: ascending, in place |
| Merge two arrays | `System.arraycopy` twice into a new array |
| Frequency | a [frequency map](card:collection-programs) |
| With streams | `Arrays.stream(a).max()`, `.sum()`: see [number streams](card:primitive-streams) |

1. Decide the state: one value (max), two values (the two largest), two indexes (reverse) or a collection (a Set of seen values).
2. Give each variable a start value that any real element can replace: `a[0]`, or `Integer.MIN_VALUE`.
3. Loop once over the array and update the state for each element.
4. After the loop, handle the "no answer" case: an empty array, or no second distinct value.
5. Return the result, and print an array with `Arrays.toString`.

## Example

Max, min and average come out of the same loop.

```java
int[] a = {4, 9, 2, 7};
int max = a[0], min = a[0], sum = 0;
for (int n : a) {
    max = Math.max(max, n);
    min = Math.min(min, n);
    sum += n;
}
System.out.println(max + " " + min + " " + (double) sum / a.length);
```

```text output
9 2 5.5
```

What to notice: the `(double)` cast turns the division into a decimal one. Without it, `22 / 4` is 5. `a[0]` fails on an empty array, so check `a.length` first in real code.

The second largest needs two variables and one extra condition.

```java
static int secondLargest(int[] nums) {
    int first = Integer.MIN_VALUE, second = Integer.MIN_VALUE;
    for (int n : nums) {
        if (n > first) { second = first; first = n; }
        else if (n > second && n != first) second = n;
    }
    return second;              // MIN_VALUE: no second distinct value
}
System.out.println(secondLargest(new int[] {5, 9, 9, 7}));
```

```text output
7
```

What to notice: when a new largest arrives, the old largest moves down to `second`. The `n != first` test keeps the second 9 from becoming the second largest.

Reversing in place swaps the two ends and moves inwards.

```java
int[] a = {1, 2, 3, 4, 5};
for (int i = 0, j = a.length - 1; i < j; i++, j--) {
    int t = a[i];
    a[i] = a[j];
    a[j] = t;
}
System.out.println(Arrays.toString(a));
```

```text output
[5, 4, 3, 2, 1]
```

What to notice: the loop stops when `i` and `j` meet. Looping to the end instead would swap every pair twice and give back the original order.

A Set finds duplicates in one pass.

```java
int[] a = {3, 1, 3, 2, 1};
Set<Integer> seen = new LinkedHashSet<>();   // keeps first-seen order
Set<Integer> dups = new LinkedHashSet<>();
for (int n : a) {
    if (!seen.add(n)) dups.add(n);           // add returns false: already there
}
System.out.println("unique " + seen + ", duplicates " + dups);
```

```text output
unique [3, 1, 2], duplicates [3, 1]
```

What to notice: `seen` doubles as the answer to "remove duplicates and keep the order". A `HashSet` would also find them, but prints in no fixed order.

## Rules and defaults

- **Index range:** valid indexes are 0 to `a.length - 1`; any other index throws `ArrayIndexOutOfBoundsException`.
- **length:** an array's size is the field `a.length`, with no brackets.
- **Arrays.sort:** sorts ascending, in place, and returns nothing.
- **Arrays.binarySearch:** needs sorted input; when the value is missing it returns a negative number, not -1 in general.

## Interview Qs

### How do you find duplicates in an array in O(n)?

Add each value to a HashSet; `add` returns false for a value already seen. Sorting first and comparing neighbours also works, in O(n log n) time but without the extra set.

### How do you merge two arrays into one?

Create an array of length `a.length + b.length`, then copy twice: `System.arraycopy(a, 0, r, 0, a.length)` and `System.arraycopy(b, 0, r, a.length, b.length)`. The fourth argument is where the copy starts in `r`, so `b` lands right after `a`.

### Why start a max at a[0] and not at 0?

If every value is negative, a max that starts at 0 stays 0, which is not in the array. Starting from the first element, or from `Integer.MIN_VALUE`, means any real value can replace the start.
