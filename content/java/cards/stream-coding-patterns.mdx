## Why it exists

A coding round leaves no time to recall whole programs. A few question words map to a few operations, so any new question becomes a pipeline.

## How it works

| The question says | Write |
|---|---|
| which, only, where | `filter(...)` |
| convert, get the names | `map(...)`; nested lists: `flatMap(List::stream)` |
| unique | `distinct()` |
| sorted, highest first | `sorted(...)` with `Comparator.reverseOrder()` or `.reversed()` |
| top N, skip the first N | `sorted(...).limit(n)`, `skip(n)` |
| how many; highest, lowest | `count()`; `max(...)`, `min(...)` |
| total, average | `mapToInt(...).sum()`, `.average()` |
| is there any, do all, none | `anyMatch`, `allMatch`, `noneMatch` |
| how many of each, group by | `groupingBy(..., counting())` |
| split into two | `partitioningBy(...)` |
| combine into one value | `reduce(...)` |
| print each | `forEach(...)`: no result |

- Details: [Collectors](card:collectors), [number streams](card:primitive-streams), [comparators](card:comparable-comparator).
- Words: `Arrays.stream(s.split(" "))`. Characters: `s.chars()`. Rebuild text: `joining(" ")`.

## Example

```java
// "Names of IT employees earning over 60,000, highest paid first"
List<String> names = emps.stream()
        .filter(e -> e.dept().equals("IT"))                        // IT            -> filter
        .filter(e -> e.salary() > 60_000)                          // over 60,000   -> filter
        .sorted(Comparator.comparingInt(Emp::salary).reversed())   // highest first -> sorted
        .map(Emp::name)                                            // names         -> map
        .toList();                                                 // list          -> collect
```

```java
List<Integer> nums = List.of(5, 9, 2, 9, 5, 7);
Map<Integer, Long> freq = nums.stream()                                       // frequency
        .collect(Collectors.groupingBy(Function.identity(), Collectors.counting()));
Set<Integer> dups = freq.entrySet().stream()                                 // duplicates
        .filter(e -> e.getValue() > 1).map(Map.Entry::getKey).collect(Collectors.toSet());
int second = nums.stream().distinct().sorted(Comparator.reverseOrder())      // 2nd highest
        .skip(1).findFirst().orElseThrow();
List<Integer> top3 = nums.stream().sorted(Comparator.reverseOrder()).limit(3).toList();
System.out.println(freq);
System.out.println(dups + " " + second + " " + top3);
```

```text output
{2=1, 5=2, 7=1, 9=2}
[5, 9] 7 [9, 9, 7]
```

## Interview Qs

### How do you find duplicate elements with streams?

Count each value with `groupingBy(Function.identity(), counting())`, keep entries with a count above 1, map to the key. `filter(x -> !seen.add(x))` also works, but it is a stateful lambda, which the Stream docs discourage.

### How do you find the first non-repeated character?

Count the characters into a `LinkedHashMap`, which keeps first-seen order: `groupingBy(Function.identity(), LinkedHashMap::new, counting())`. Then take the first entry with count 1.
