## Why it exists

A `Stream<Integer>` holds boxed objects and has no `sum` or `average`. `IntStream`, `LongStream` and `DoubleStream` hold primitives and have both.

## How it works

| I want | Write | Returns |
|---|---|---|
| Sum of a field | `mapToInt(Emp::salary).sum()` | `int` |
| Average | `mapToInt(...).average().orElse(0)` | `OptionalDouble`, then `double` |
| Largest or smallest | `mapToInt(...).max().orElse(0)` | `OptionalInt`, then `int` |
| Count, sum, min, max, average at once | `mapToInt(...).summaryStatistics()` | `IntSummaryStatistics` |
| Numbers 1 to n | `IntStream.rangeClosed(1, n)` | `IntStream` |
| Characters of a String | `s.chars()` | `IntStream` of `char` values |
| Back to objects | `boxed()`, `mapToObj(c -> (char) c)` | `Stream<Integer>`, `Stream<T>` |

- `IntStream` has only `sorted()`. For descending order, `boxed()` first, then `sorted(Comparator.reverseOrder())`.
- With no elements, `summaryStatistics().getMax()` is `Integer.MIN_VALUE`: check `getCount()` first.

## Example

```java
List<Integer> nums = List.of(4, 9, 2, 9);
int sum = nums.stream().mapToInt(Integer::intValue).sum();                    // 24
double avg = nums.stream().mapToInt(Integer::intValue).average().orElse(0);   // 6.0
IntSummaryStatistics st = nums.stream().mapToInt(Integer::intValue).summaryStatistics();
System.out.println(st.getMax() + " " + st.getCount());

int squares = IntStream.rangeClosed(1, 3).map(i -> i * i).sum();             // 1 + 4 + 9 = 14
long vowels = "interview".chars().filter(c -> "aeiou".indexOf(c) >= 0).count(); // 4
List<Character> letters = "abc".chars().mapToObj(c -> (char) c).toList();   // [a, b, c]
```

```text output
9 4
```

## Interview Qs

### Why use mapToInt instead of map?

`map(Emp::salary)` gives a `Stream<Integer>`: boxed objects and no `sum()`. `mapToInt` gives an `IntStream` with `sum`, `average`, `max` and ranges, and no boxing.

### Why does IntStream.max() return OptionalInt, not int?

An empty stream has no maximum. `OptionalInt` makes that visible, so you choose `orElse(0)`, `orElseThrow()` or `getAsInt()`.

### How do you count one character in a String with streams?

`s.chars().filter(c -> c == 'a').count()`. `chars()` gives one value per UTF-16 `char`, so most emoji count as two; `codePoints()` gives one value per code point.
