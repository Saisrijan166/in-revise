## What it is

`IntStream`, `LongStream` and `DoubleStream` are [streams](card:streams) of plain `int`, `long` and `double` values instead of objects. A `Stream<Integer>` holds `Integer` objects, the [wrapper class](card:wrapper-classes) around `int`. Number streams add methods that object streams do not have, such as `sum()`, `average()` and `summaryStatistics()`, and they can produce ranges such as 1 to 10. You get one from an object stream with `mapToInt`, `mapToLong` or `mapToDouble`.

## Why it exists

Say you want the total paise of all paid payments. A `Stream<Long>` has no `sum()`, so you would write `reduce(0L, Long::sum)`, and every amount is boxed into a `Long` object and unboxed again, which wastes memory and time on large lists. `mapToLong` gives a `LongStream` of raw `long` values with `sum()` ready to call. Number ranges also replace counting loops such as `for (int i = 1; i <= n; i++)` inside a pipeline.

## How it works

| I want | Write | Returns |
|---|---|---|
| Sum of a field | `mapToLong(Payment::amountPaise).sum()` | `long` |
| Average | `mapToLong(...).average().orElse(0)` | `OptionalDouble`, then `double` |
| Largest or smallest | `mapToLong(...).max().orElse(0)` | `OptionalLong`, then `long` |
| Count, sum, min, max and average at once | `mapToLong(...).summaryStatistics()` | `LongSummaryStatistics` |
| Numbers 1 to n | `IntStream.rangeClosed(1, n)` | `IntStream` |
| Characters of a String | `s.chars()` | `IntStream` of `char` values |
| Back to objects | `boxed()`, `mapToObj(c -> (char) c)` | `Stream<Integer>`, `Stream<T>` |

1. Start with objects: `payments.stream()` gives a `Stream<Payment>`.
2. Call `mapToLong(Payment::amountPaise)`. Each payment becomes a plain `long`, and the result is a `LongStream`.
3. Finish with a number operation. `sum()` returns a `long`; `average()`, `max()` and `min()` return an optional number, because an empty stream has no average or maximum.
4. To go back to objects, call `boxed()` for a `Stream<Long>`, or `mapToObj(...)` to build any object from each number.

## Example

Totals and averages over the payments, plus a range and a String.

```java
List<Payment> payments = List.of(new Payment(1, 80_000, Status.PAID),
        new Payment(2, 20_000, Status.PAID), new Payment(3, 90_000, Status.FAILED));
long paidTotal = payments.stream()
        .filter(p -> p.status() == Status.PAID)
        .mapToLong(Payment::amountPaise)              // Stream<Payment> to LongStream
        .sum();
double avg = payments.stream().mapToLong(Payment::amountPaise).average().orElse(0);
LongSummaryStatistics st = payments.stream().mapToLong(Payment::amountPaise).summaryStatistics();
int squares = IntStream.rangeClosed(1, 3).map(i -> i * i).sum();             // 1 + 4 + 9
long vowels = "interview".chars().filter(c -> "aeiou".indexOf(c) >= 0).count();
System.out.println(paidTotal + " " + avg + " " + st.getMax() + " " + squares + " " + vowels);
```

```text output
100000 63333.333333333336 90000 14 4
```

What to notice:

- `sum()` is available only after `mapToLong`. On a `Stream<Long>` the same call does not compile.
- `average()` returns an `OptionalDouble`, because an empty list has no average. `orElse(0)` decides the answer for that case.
- `rangeClosed(1, 3)` includes 3. `range(1, 3)` would stop at 2 and give 1 + 4 = 5.
- `chars()` gives the characters as `int` codes, so `indexOf(c)` checks each code against the vowels: i, e, i, e makes 4.

## Rules and defaults

- **Empty stream:** `sum()` returns 0; `max()`, `min()` and `average()` return an empty optional.
- **Empty statistics:** `summaryStatistics().getMax()` is `Integer.MIN_VALUE` (or `Long.MIN_VALUE`) when nothing was recorded, so check `getCount()` first.
- **Sorting:** a number stream has only `sorted()`, which is ascending. For descending order, `boxed()` first, then `sorted(Comparator.reverseOrder())`.
- **chars():** one value per UTF-16 `char`, so most emoji count as two. `codePoints()` gives one value per Unicode character. `mapToObj(c -> (char) c)` turns the codes back into `Character` objects.

## Not to be confused with

`map(Payment::amountPaise)` keeps an object stream, a `Stream<Long>` of boxed values with no `sum()`. `mapToLong(Payment::amountPaise)` gives a `LongStream` of plain numbers with `sum()`, `average()` and `max()`.

Rule: arithmetic on the values: `mapToInt` or `mapToLong`. Objects needed afterwards: `map`, or `boxed()` at the end.

## Common mistakes

- **"IntStream.sum() is safe for money totals."** It returns an `int` and wraps around silently past about 2.1 billion. For paise or salaries, use `mapToLong(...).sum()`.

## Interview Qs

### Why use mapToInt instead of map?

`map(Emp::salary)` gives a `Stream<Integer>`: boxed objects, and no `sum()` or `average()`. `mapToInt(Emp::salary)` gives an `IntStream` of plain `int` values, with `sum`, `average`, `max` and `summaryStatistics` built in, and no boxing cost on large lists.

### Why does IntStream.max() return OptionalInt, not int?

An empty stream has no maximum, and any `int` returned would look like a real answer. `OptionalInt` makes the empty case visible, so the caller chooses `orElse(0)`, `orElseThrow()` or `getAsInt()`.

### How do you count one character in a String with streams?

`s.chars().filter(c -> c == 'a').count()`. `chars()` gives an `IntStream` with one value per UTF-16 `char`, and `count()` returns a `long`. For text with emoji, use `codePoints()`, which gives one value per Unicode character.
