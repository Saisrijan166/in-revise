## Why it exists

Reading Java is easier than writing it. Most freezes come from starting with syntax before knowing the input, the output and what to keep track of.

## How it works

| Ask | For "count the even numbers" |
|---|---|
| What data do I get? | `int[] nums` |
| What do I return? | an `int` count |
| Which loop or collection? | one for-each loop |
| What state do I keep? | `count`, raised when `n % 2 == 0` |
| What happens to each value? | 1 no, 2 yes, 3 no, 4 yes… |
| What is the final output? | `3` for 1 to 6 |

<Steps label="Practise one question">
  <Step title="Write">Hide the answer and write it from memory.</Step>
  <Step title="Predict">Write the expected output before running.</Step>
  <Step title="Run">Compile, fix the errors, compare with your prediction.</Step>
  <Step title="Rewrite">Delete it, change one detail of the question, write it again.</Step>
</Steps>

## Example

```java
import java.util.*;                             // Arrays, List, Map: most programs need it
public class Main {
    public static void main(String[] args) {
        System.out.println(countEven(new int[] {1, 2, 3, 4, 5, 6}));
    }
    static int countEven(int[] nums) {          // return it; print in main
        int count = 0;
        for (int n : nums) if (n % 2 == 0) count++;
        return count;
    }
}
```

```text output
3
```

```java
// Input: String. Output: boolean. Logic: compare both ends, move inwards
static boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s.charAt(left++) != s.charAt(right--)) return false;
    }
    return true;
}
System.out.println(isPalindrome("madam") + " " + isPalindrome("java"));
```

```text output
true false
```

```bash
javac Main.java                   # compile: writes Main.class
java Main                         # run the class: no .java, no .class
java Main.java                    # JDK 11+: compile in memory and run, no .class file
rm -f *.class                     # delete compiled classes in this folder
find . -name "*.class" -delete    # ... and in every subfolder
```

## Interview Qs

### How do you start a coding question you have not seen?

Say the input and output aloud, which gives the signature. Pick the loop or collection and the state to keep, write the method, then trace a small input, including an empty or one-element case.

### What does java Main.java do?

Since JDK 11 the launcher, in [source-file mode](card:source-file-mode), compiles that file in memory and runs its main method, without writing a `.class` file. Since JDK 22 it also compiles other source files the program uses.
