## Why it exists

"Create a functional interface, implement it, now with a lambda" is a common follow-up. It checks that you know what a lambda replaces.

## How it works

<Steps label="The same interface, four implementations">
  <Step title="Named class">`class Adder implements Calculator`: the most code.</Step>
  <Step title="Anonymous class">`new Calculator() { ... }`: no class name, still a body.</Step>
  <Step title="Lambda">`(a, b) -> a + b`: only the parameters and the result.</Step>
  <Step title="Method reference">`Integer::sum`: an existing method with the right shape.</Step>
</Steps>

- Built-in interfaces (`Predicate`, `Function`, `Consumer`, `Supplier`, `UnaryOperator`, `BinaryOperator`) and the rules for captured variables: [lambdas](card:lambdas).

## Example

```java
@FunctionalInterface
interface Calculator { int calculate(int a, int b); }      // one abstract method
class Adder implements Calculator {                         // 1. a named class
    public int calculate(int a, int b) { return a + b; }
}
Calculator c1 = new Adder();
Calculator c2 = new Calculator() {                          // 2. an anonymous class
    public int calculate(int a, int b) { return a + b; }
};
Calculator c3 = (a, b) -> a + b;                            // 3. a lambda
Calculator c4 = Integer::sum;                               // 4. a method reference
for (Calculator c : List.of(c1, c2, c3, c4)) System.out.print(c.calculate(2, 3) + " ");
```

```text output
5 5 5 5
```

```java
interface Greeter {
    String name();                                         // abstract: the lambda's body
    default String greet() { return "Hello " + name(); }   // default: comes for free
    static Greeter of(String n) { return () -> n; }        // static: call Greeter.of(...)
}
Greeter g = Greeter.of("Asha");
System.out.println(g.greet());
```

```text output
Hello Asha
```

```java
@FunctionalInterface
interface Rule { boolean check(int n); }
Rule even = n -> n % 2 == 0;
List<Integer> result = List.of(1, 2, 3, 4).stream()
        .filter(even::check)              // filter wants a Predicate: adapt with ::
        .toList();
System.out.println(result);
```

```text output
[2, 4]
```

## Interview Qs

### How can you call an interface method without writing a class that implements it?

You cannot skip the implementation, only the named class. An anonymous class, a lambda or a method reference supplies the body inline, and each gives an object of the interface.

### Can a functional interface have default and static methods?

Yes. Only abstract methods count, so it may add any number of default, static and private methods, like `Greeter` above. A lambda supplies the one abstract method and gets the default methods for free.
