## Why it exists

Java changes twice a year, but only some releases get long-term support. Interviewers ask what each LTS added and which version a feature needs.

## How it works

| LTS | Headline features (final in an earlier release in brackets) |
|---|---|
| 8 | [lambdas](card:lambdas), [Stream API](card:streams), [Optional](card:optional), [default methods](card:abstract-classes-interfaces), [java.time](card:date-time) |
| 11 | modules (9), [`List.of`](card:collections-framework) (9), [`var`](card:data-types) (10), HttpClient, run one `.java` file directly |
| 17 | [switch expressions](card:operators-control-flow) (14), text blocks (15), [records, instanceof patterns](card:records-sealed) (16), sealed classes |
| 21 | [virtual threads](card:virtual-threads), pattern matching for switch, record patterns, sequenced collections |
| 25 | [compact source files and instance main](card:jdk-jre-jvm), [flexible constructor bodies](card:constructors), module import declarations |

- Linked features have their own concept; this table only says when they arrived.

## Interview Qs

### What is an LTS release, and which ones are LTS?

A release that keeps getting updates for years, while a non-LTS release is superseded by the next one six months later. Oracle's LTS releases are 8, 11, 17, 21 and 25; the next planned is 29 (September 2027).

### What is a preview feature?

A feature that is fully specified and built but not yet permanent, shipped to get feedback. It may change or be removed. Use it with `javac --release N --enable-preview` and `java --enable-preview` on that exact release N.
