## Why it exists

Frameworks must work with classes they have never seen, such as your controllers and entities. Annotations mark what to do; reflection finds and runs it, with no hand-written wiring.

## How it works

| Step | API | Note |
|---|---|---|
| Get the class | `User.class`, `obj.getClass()`, `Class.forName("app.User")` | `forName` also initialises the class |
| List members | `getDeclaredMethods()` | all declared here, private too, not inherited |
| | `getMethods()` | public only, inherited included |
| Open private ones | `setAccessible(true)` | across modules only if the package is open |
| Read a label | `isAnnotationPresent`, `getAnnotation` | needs `RUNTIME` retention |

- `@Target` limits where an annotation may go; without it, any declaration.
- Built-ins: `@Override` (checked by the compiler), `@Deprecated`, `@SuppressWarnings`, `@FunctionalInterface`.

## Example

```java
@Retention(RetentionPolicy.RUNTIME) @Target(ElementType.METHOD)
@interface Audit { String value() default ""; }

class OrderService {
    @Audit("create") private void create() { System.out.println("created"); }
}

for (Method m : OrderService.class.getDeclaredMethods())
    if (m.isAnnotationPresent(Audit.class)) {
        m.setAccessible(true);                // private, same module: allowed
        m.invoke(new OrderService());
    }
```

```text output
created
```

## Interview Qs

### What is reflection, and why avoid it in normal code?

It inspects and uses classes, fields and methods at run time. The JVM cannot optimise it as well, errors move from compile time to run time, and private access breaks encapsulation. Keep it for frameworks and tools.

### What are the three retention policies?

SOURCE: dropped by the compiler (`@Override`). CLASS, the default: kept in the .class file, not at run time. RUNTIME: readable by reflection (`@Deprecated`, framework annotations).

### Why does setAccessible fail with InaccessibleObjectException?

Since Java 9 modules decide deep access. A private member of another module is reachable only if its package is opened to your module.
