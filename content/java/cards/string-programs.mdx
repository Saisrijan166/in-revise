## What it is

String programs take text and count it, check it or rebuild it: vowels, the first unique character, anagrams, reversed words, compression. A Java [String](card:strings) cannot change after it is created, so a program either reads its characters or builds new text in a `StringBuilder`. A `char` is stored as a number, so `'c' - 'a'` is 2, which turns a lowercase letter into an array index from 0 to 25.

## Why it exists

Strings are the most common coding-round input. They test loops, char arithmetic, counting and splitting text into words. They also hide edge cases that interviewers like: uppercase letters, extra spaces and an empty string. A solution that works on "listen" can fail on "Listen" or on "  Java   is fun ".

## How it works

| Problem | Pattern |
|---|---|
| Reverse a string | `new StringBuilder(s).reverse().toString()` |
| Palindrome | two ends, moving inwards: [the method](card:coding-method) |
| Character or word frequency, duplicate chars | a [frequency map](card:collection-programs) |
| Remove duplicate chars, keep order | add each char to a `LinkedHashSet` |
| Longest word | split, keep the longest seen |
| Replace a character | `s.replace('a', '*')` returns a new String |
| With streams | `s.chars()`: see [stream patterns](card:stream-coding-patterns) |

1. Normalise the input if the question allows it: `toLowerCase()` for case, `trim()` for outer spaces.
2. Turn it into pieces: chars with `toCharArray()`, or words with `split("\\s+")`.
3. Count or check the pieces in one loop, with an `int[26]`, a Set or a Map.
4. If the answer is new text, append it to a `StringBuilder` and call `toString()` at the end.

## Example

Counting vowels checks each char against a small string of vowels.

```java
String s = "Interview";
int vowels = 0;
for (char c : s.toLowerCase().toCharArray()) {
    if ("aeiou".indexOf(c) >= 0) vowels++;
}
System.out.println(vowels);
```

```text output
4
```

What to notice: `indexOf` returns -1 when the char is missing. Without `toLowerCase()`, the capital I would not count and the answer would be 3.

The first unique character needs two passes: count everything, then scan in the original order.

```java
static char firstUnique(String s) {
    int[] count = new int[26];                  // lowercase a to z
    for (char c : s.toCharArray()) count[c - 'a']++;
    for (char c : s.toCharArray()) {
        if (count[c - 'a'] == 1) return c;      // first in the original order
    }
    return '_';                                 // none
}
System.out.println(firstUnique("swiss") + " " + firstUnique("aabb"));
```

```text output
w _
```

What to notice: the second loop goes over the string, not over the array, so the answer keeps the original order.

Two strings are anagrams when their sorted letters are equal.

```java
static boolean isAnagram(String a, String b) {
    char[] x = a.toCharArray(), y = b.toCharArray();
    Arrays.sort(x);
    Arrays.sort(y);
    return Arrays.equals(x, y);
}
System.out.println(isAnagram("listen", "silent") + " " + isAnagram("rat", "car"));
```

```text output
true false
```

What to notice: `Arrays.equals` compares the contents. `x == y` would compare two different arrays and always be false.

Reversing words shows why `split(" ")` is a trap.

```java
String s = "  Java   is fun ";
System.out.println(s.split(" ").length);               // empty strings too
String[] words = s.trim().split("\\s+");
Collections.reverse(Arrays.asList(words));             // the list view reverses the array
System.out.println(String.join(" ", words));
```

```text output
7
fun is Java
```

What to notice: the 7 pieces are 3 words plus 4 empty strings. `Arrays.asList` is a view over the same array, so reversing the list reverses `words`.

Compression counts each run of equal characters.

```java
static String compress(String s) {               // aaabbc -> a3b2c1
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < s.length(); i++) {
        int count = 1;
        while (i + 1 < s.length() && s.charAt(i) == s.charAt(i + 1)) { i++; count++; }
        sb.append(s.charAt(i)).append(count);
    }
    return sb.toString();
}
System.out.println(compress("aaabbc"));
```

```text output
a3b2c1
```

What to notice: the inner `while` moves `i` to the last char of the run, and the `i + 1 < s.length()` test stops it from reading past the end.

## Rules and defaults

- **split takes a regular expression:** `"a.b.c".split(".")` returns an empty array, because `.` matches any char; write `split("\\.")`.
- **Empty pieces:** `split` keeps empty strings at the start but drops those at the end.

## Interview Qs

### How do you check if two strings are anagrams?

Sort both char arrays and compare them: O(n log n). Or count letters in an `int[26]`, adding for one string and subtracting for the other; all zeros means an anagram, in O(n). Lowercase both first if case should not matter.

### How do you reverse the words in a sentence?

Trim, split on `\\s+`, reverse the array and join with one space. Without a library call, loop over the words from the end and append each to a [StringBuilder](card:strings).
