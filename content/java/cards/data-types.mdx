## Why it exists

Java checks types at compile time. Primitives keep numbers small and fast; references point to objects or `null`.

## How it works

| Type | Bits | Field default |
|---|---|---|
| `byte`, `short`, `int`, `long` | 8, 16, 32, 64 (signed) | `0` |
| `float`, `double` | 32, 64 | `0.0` |
| `char` | 16 (unsigned UTF-16 unit) | `'\u0000'` |
| `boolean` | not defined | `false` |
| any reference type | | `null` |

- Arithmetic on `byte`, `short` or `char` gives an `int`: `byte c = a + b;` does not compile.
- Plain `42` is an `int` and `1.5` a `double`; write `42L` for long and `1.5f` for float.
- Casting between classes (upcasting, downcasting) belongs to [polymorphism](card:polymorphism).

## Example

```java
int a = 5 / 2;                         // 2: the fraction is dropped
double b = 5 / 2.0;                    // 2.5
int big = Integer.MAX_VALUE + 1;       // -2147483648: wraps silently
long n = 42;                           // widening: automatic
int m = (int) 3.99;                    // narrowing: 3, cast required
var names = new ArrayList<String>();   // type is ArrayList<String>
```

## Interview Qs

### What are the default values of variables?

Fields and array elements get `0`, `0.0`, `false`, `'\u0000'` or `null`. Local variables get nothing: the compiler rejects reading one before it is assigned.

### Can you use var for fields or method parameters?

No. `var` works for local variables with an initializer and for loop variables. `var x;` and `var x = null;` do not compile.

### What happens on integer overflow?

The value wraps silently: `Integer.MAX_VALUE + 1` is `Integer.MIN_VALUE`. Use `long`, or `Math.addExact`, which throws `ArithmeticException` on overflow.
