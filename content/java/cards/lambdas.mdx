## Why it exists

Passing behaviour, such as a sort order, once needed an anonymous class: several lines of ceremony for one line of logic. Java 8 added lambdas.

## How it works

| Interface | Method | Shape | Example |
|---|---|---|---|
| `Predicate<T>` | `test` | T → boolean | `s -> s.isBlank()` |
| `Function<T, R>` | `apply` | T → R | `s -> s.length()` |
| `Consumer<T>` | `accept` | T → nothing | `s -> System.out.println(s)` |
| `Supplier<T>` | `get` | nothing → T | `() -> new ArrayList<>()` |
| `BiFunction<T, U, R>` | `apply` | T, U → R | `(a, b) -> a * b` |
| `UnaryOperator<T>`, `BinaryOperator<T>` | `apply` | same type in and out | `s -> s.trim()` |

- A method reference replaces a lambda that only calls one method: `String::length`.
- Primitive versions such as `IntPredicate` and `ToIntFunction` avoid boxing.

## Example

```java
Function<String, Integer> length = String::length;   // method reference
Supplier<List<String>> newList = ArrayList::new;     // constructor reference

int min = 3;                                          // effectively final
List<String> longWords = words.stream()
        .filter(w -> w.length() > min)
        .toList();
// min = 4;    // would make the lambda above a compile error
```

## Interview Qs

### What are the four kinds of method reference?

Static method: `Integer::parseInt`. Method of a particular object: `System.out::println`. Method of any object of a type: `String::length`, where the first argument becomes the receiver. Constructor: `ArrayList::new`.

### Why must captured local variables be effectively final?

The JLS says capturing a local that keeps changing would likely cause concurrency problems. So a lambda may use only locals that are never reassigned after their first value.

### Are Runnable and Comparator functional interfaces?

Yes, both are older interfaces with one abstract method, so lambdas work with them. Comparator also declares `equals`, but that overrides an Object method and does not count.
