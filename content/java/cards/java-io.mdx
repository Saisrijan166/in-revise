## Why it exists

Programs read and write files, sockets and consoles. Java separates raw bytes from text, because text needs a charset to turn bytes into characters.

## How it works

| Need | Classic `java.io` | NIO.2 `java.nio.file` |
|---|---|---|
| Name a file | `File` | `Path.of("a.txt")` (Java 11) |
| Read bytes | `FileInputStream` | `Files.readAllBytes` |
| Read text line by line | `BufferedReader` over `FileReader` | `Files.lines`, `Files.newBufferedReader` |
| Whole small text file | (loop) | `Files.readString` / `writeString` (Java 11) |

- Wrappers stack: `InputStreamReader` turns bytes into chars, `BufferedReader` adds a buffer around it.
- NIO also has channels, buffers and selectors for non-blocking I/O; name them, rarely asked deeper.
- Close every stream: use [try-with-resources](card:try-catch-finally).

## Example

```java
Path file = Path.of("orders.txt");
Files.writeString(file, "ok 1\nERROR 2\n");                 // UTF-8
try (Stream<String> lines = Files.lines(file)) {            // lazy, must be closed
    System.out.println(lines.filter(l -> l.startsWith("ERROR")).count());
}
try (BufferedReader in = Files.newBufferedReader(file)) {   // classic loop
    String line;
    while ((line = in.readLine()) != null) System.out.println(line);
}
```

```text output
1
ok 1
ERROR 2
```

## Defaults

| What | Default | Where |
|---|---|---|
| Charset of `FileReader`, `InputStreamReader` | UTF-8 (before 18: OS and locale) | Java 18+ (JEP 400) |
| Charset of `Files` methods with no charset | UTF-8 | Java SE 25 API |

## Interview Qs

### Byte stream vs character stream?

Byte streams (`InputStream`, `OutputStream`) move raw 8-bit bytes, right for binary files. Character streams (`Reader`, `Writer`) decode bytes into characters with a charset, right for text.

### Why wrap a FileReader in a BufferedReader?

Without a buffer each read can go to the operating system. `BufferedReader` reads a large block at once, serves later reads from memory, and adds `readLine()`.

### java.io vs NIO?

`java.io` is stream-based and blocking. NIO adds buffers, channels and selectors for non-blocking I/O, and NIO.2 adds `Path` and `Files` for simpler, safer file work.
