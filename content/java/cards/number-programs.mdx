## What it is

Number programs take an `int` or a `long` and work on its digits, its divisors or a sequence of values. Almost all of them use one loop with two operators: `%`, the remainder (`1234 % 10` is 4), and `/`, which on whole numbers drops the fraction (`1234 / 10` is 123). Together they let you take a number apart one digit at a time.

## Why it exists

Number programs are the warm-up round. They test a loop, `%` and `/`, and two edge cases people forget: negative numbers and overflow. Overflow means a result is too big for its type, so it wraps around to a wrong value with no error ([primitive types](card:data-types)). A program that passes for 5 can silently fail for 21 or for -7.

## How it works

| Problem | Pattern |
|---|---|
| Reverse, sum or count digits | the digit loop: `rev = rev * 10 + n % 10`, `sum += n % 10`, `count++` |
| Palindrome number | `reverse(n) == n` |
| Prime | try divisors from 2 up to the square root |
| Factorial, power | multiply in a loop: `result *= i` |
| Fibonacci | keep the last two values |
| Max of three | `Math.max(a, Math.max(b, c))` |
| Swap without a temp | `a = a + b; b = a - b; a = a - b;` |
| Character check | `Character.isDigit(c)`, `isLetter`, `isUpperCase` |

1. Decide which shape the question has: digits, divisors or a sequence.
2. For digits, take the last digit with `n % 10`, use it, then drop it with `n /= 10`, and repeat while `n != 0`.
3. For divisors, try each `i` from 2 while `i <= n / i`, and stop at the first one that divides `n`.
4. For a sequence, keep the previous values in variables and compute the next one from them.
5. Choose the type last: an `int` stops at 2,147,483,647, so a growing product needs a `long`.

## Example

Reverse uses the digit loop; comparing the result with the input checks for a palindrome number.

```java
static int reverse(int n) {
    int rev = 0;
    while (n != 0) {
        rev = rev * 10 + n % 10;     // take the last digit
        n /= 10;                     // drop it
    }
    return rev;
}
System.out.println(reverse(1234));
System.out.println(reverse(121) == 121);   // palindrome number
```

```text output
4321
true
```

What to notice: `rev * 10` shifts the digits built so far one place left before adding the new digit. For 1234, `rev` goes 4, 43, 432, 4321.

The prime check stops as soon as it finds a divisor.

```java
static boolean isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= n / i; i++) {     // up to the square root
        if (n % i == 0) return false;
    }
    return true;
}
System.out.println(isPrime(1) + " " + isPrime(17) + " " + isPrime(21));
```

```text output
false true false
```

What to notice: `i <= n / i` means the same as `i * i <= n`, but `i * i` can overflow for large `n`. For 17 the loop tries only 2, 3 and 4.

Factorial shows the overflow limit of a `long`.

```java
static long factorial(int n) {
    long result = 1;
    for (int i = 2; i <= n; i++) result *= i;
    return result;
}
System.out.println(factorial(5));
System.out.println(factorial(20));   // the largest that fits in a long
System.out.println(factorial(21));   // overflows silently
```

```text output
120
2432902008176640000
-4249290049419214848
```

What to notice: 21! is negative, yet nothing failed. With an `int` result it already goes wrong at 13!.

Fibonacci keeps only the last two values.

```java
int a = 0, b = 1;                    // Fibonacci: keep the last two
for (int i = 0; i < 8; i++) {
    System.out.print(a + " ");
    int next = a + b;
    a = b;
    b = next;
}
```

```text output
0 1 1 2 3 5 8 13
```

What to notice: `next` must be computed before `a` and `b` move forward; without it the old `a` is lost.

## Rules and defaults

- **Remainder sign:** `%` takes the sign of the left operand: `-7 % 2` is -1 (JLS 15.17.3).
- **Integer division:** `/` on whole numbers drops the fraction toward zero: `-7 / 2` is -3.
- **Overflow:** `int` and `long` arithmetic wraps without an error. `Math.multiplyExact` and `Math.addExact` throw `ArithmeticException` instead (Java 8), and `BigInteger` holds any size.
- **Math.pow:** takes and returns `double`, so `Math.pow(2, 10)` is `1024.0`.

## Interview Qs

### Why check divisors only up to the square root?

If n = a × b, one of a and b is at most √n. So if nothing up to √n divides n, n is prime. `i <= n / i` tests that bound without the overflow that `i * i` can hit.

### Recursive or loop Fibonacci?

Plain recursion recomputes the same values: fib(5) calls fib(3) twice, so the time grows exponentially. Memoising or a loop makes it O(n); the loop that keeps the last two values also needs only O(1) space.

### How do you swap two numbers without a temporary variable?

`a = a + b; b = a - b; a = a - b;`. With 5 and 9: a becomes 14, b becomes 5, a becomes 9. In an interview, mention that a plain temporary variable is clearer; the trick is only a puzzle.
