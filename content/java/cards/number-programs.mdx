## Why it exists

Number programs are the warm-up round: they test a loop, `%` and `/`, and whether you notice overflow and negative numbers.

## How it works

| Problem | Trick |
|---|---|
| Reverse, sum or count digits | the digit loop: `rev = rev * 10 + n % 10`, `sum += n % 10`, `count++` |
| Palindrome number | `reverse(n) == n` |
| Max of three | `Math.max(a, Math.max(b, c))` |
| Swap without a temp | `a = a + b; b = a - b; a = a - b;` |
| Power | a loop of `result *= base`, or `Math.pow` (a `double`) |
| Character check | `Character.isDigit(c)`, `isLetter`, `isUpperCase` |

- Overflow wraps with no error: see [primitive types](card:data-types).

## Example

```java
static int reverse(int n) {
    int rev = 0;
    while (n != 0) {
        rev = rev * 10 + n % 10;     // take the last digit
        n /= 10;                     // drop it
    }
    return rev;
}
System.out.println(reverse(1234));
System.out.println(reverse(121) == 121);   // palindrome number
```

```text output
4321
true
```

```java
static boolean isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= n / i; i++) {     // up to the square root
        if (n % i == 0) return false;
    }
    return true;
}
System.out.println(isPrime(1) + " " + isPrime(17) + " " + isPrime(21));
```

```text output
false true false
```

```java
static long factorial(int n) {
    long result = 1;
    for (int i = 2; i <= n; i++) result *= i;
    return result;
}
System.out.println(factorial(5));
System.out.println(factorial(20));   // the largest that fits in a long
System.out.println(factorial(21));   // overflows silently
```

```text output
120
2432902008176640000
-4249290049419214848
```

```java
int a = 0, b = 1;                    // Fibonacci: keep the last two
for (int i = 0; i < 8; i++) {
    System.out.print(a + " ");
    int next = a + b;
    a = b;
    b = next;
}
```

```text output
0 1 1 2 3 5 8 13
```

## Interview Qs

### Why check divisors only up to the square root?

If n = a × b, one of a and b is at most √n. So if nothing up to √n divides n, n is prime. `i <= n / i` tests that without the overflow `i * i` can hit.

### Recursive or loop Fibonacci?

Plain recursion recomputes the same values: fib(5) calls fib(3) twice. Memoising or a loop makes it O(n); the loop that keeps the last two values also needs only O(1) space.
