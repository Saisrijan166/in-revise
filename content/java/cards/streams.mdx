## Why it exists

A loop mixes how to step through data with what to compute. A stream states only the what (filter, map, group) and lets the library run it, even in parallel.

## How it works

<Mermaid
  alt="A stream pipeline: a source such as list.stream() feeds lazy intermediate operations filter, then map, then sorted. Nothing runs until the terminal operation collect or toList pulls the elements through and produces the result."
  chart={`flowchart LR
  S["Source: list.stream()"] --> F["filter (lazy)"] --> M["map (lazy)"] --> O["sorted (lazy)"] --> T["Terminal: collect / toList"] --> R(["Result"])`}
/>

- Intermediate: `filter`, `map`, `flatMap`, `distinct`, `sorted`, `limit`, `skip`. Terminal: `collect`, `toList`, `forEach`, `reduce`, `count`, `findFirst`, `anyMatch`.
- `reduce(0, Integer::sum)` folds many values into one; `Collectors.groupingBy` builds a map.
- `findFirst`, `anyMatch` and `limit` short-circuit, so they can finish even on an infinite stream.

## Example

```java
record Emp(String name, String dept, int salary) {}

Map<String, List<String>> namesByDept = emps.stream()
        .filter(e -> e.salary() > 50_000)
        .collect(Collectors.groupingBy(Emp::dept,
                 Collectors.mapping(Emp::name, Collectors.toList())));

int total = emps.stream().mapToInt(Emp::salary).sum();      // IntStream: no boxing
String csv = names.stream().sorted().collect(Collectors.joining(", "));
```

## Interview Qs

### Why use a stream if a for loop already works?

A loop gives step-by-step control. A stream describes a filter-map-collect pipeline that reads more clearly and can run in parallel with one call. It is not automatically faster.

### What is lazy evaluation in streams?

Intermediate operations only build the pipeline. Nothing runs until the terminal operation, which pulls elements through one by one, so `findFirst` or `limit` can stop early.

### What goes wrong with parallelStream().forEach(list::add)?

Several threads change a non-thread-safe `ArrayList` at once, so the result is erratic, even with null entries. Let the stream build the result with `collect` or `toList()`.
