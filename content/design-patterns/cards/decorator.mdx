## Why it exists

Logging, metrics and retries are optional and combine freely. A subclass for every combination explodes; wrapping lets you choose the mix per object.

## How it works

<Mermaid
  alt="The caller calls charge on LoggingGateway. LoggingGateway logs, then calls MetricsGateway, which records a metric, then calls UpiGateway, which does the real charge. All three implement PaymentGateway."
  chart={`flowchart LR
  C[Caller] -- "charge(₹500)" --> L[LoggingGateway]
  L -- delegates --> M[MetricsGateway]
  M -- delegates --> U[UpiGateway: real charge]`}
/>

- Each decorator implements `PaymentGateway` and holds a `PaymentGateway`, so it can wrap the real one or another decorator.
- This is [composition over inheritance](card:composition-over-inheritance) in action. Spring's proxies are covered under [Proxy](card:proxy).

## Example

```java
class LoggingGateway implements PaymentGateway {          // same interface as what it wraps
    private final PaymentGateway inner;
    LoggingGateway(PaymentGateway inner) { this.inner = inner; }

    @Override
    public void charge(BigDecimal amount) {
        System.out.println("charging " + amount);         // added behaviour
        inner.charge(amount);                              // then delegate
    }
}
// new LoggingGateway(new MetricsGateway(new UpiGateway())).charge(BigDecimal.valueOf(500));
```

## Interview Qs

### Where does the JDK use Decorator?

In java.io. `FilterInputStream` wraps another stream and passes calls to it; subclasses such as `BufferedInputStream` add features. `new BufferedInputStream(new FileInputStream(file))` adds buffering to a file stream.

### Decorator or inheritance for optional features?

Decorator. With inheritance, every mix of features needs its own subclass, fixed at compile time. Decorators are combined at runtime, one small class per feature.

### Does the order of decorators matter?

Yes. The outermost decorator gets the call first. Logging outside metrics logs before the metric is recorded; swap them and the order flips.
