## Interview Qs

### Two patterns share a class diagram. How do you tell them apart?

Ask what problem each solves. Many patterns are one object delegating to another; only the intent differs.

### Adapter, Decorator and Proxy all wrap an object. What is the difference?

Only the Adapter changes the interface. With the same interface, a Decorator adds behaviour and a Proxy controls access, such as security or a transaction.
