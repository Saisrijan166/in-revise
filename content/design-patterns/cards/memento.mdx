## Why it exists

A customer fills the payment form, switches from UPI to card, then wants to go back. Copying the form's private fields from outside would break its encapsulation.

## How it works

<Mermaid
  alt="The caretaker asks the payment form, the originator, to save. The form returns a memento holding amount 500 and UPI, and the caretaker pushes it on a stack. On undo the caretaker pops the memento and passes it back, and the form restores its own fields."
  chart={`sequenceDiagram
  participant C as Caretaker (history)
  participant F as PaymentForm (originator)
  C->>F: save()
  F-->>C: memento: ₹500, UPI
  Note over C: push on stack
  C->>F: restore(memento)
  Note over F: fields back to ₹500, UPI`}
/>

- Only the originator writes and reads the memento's contents.
- The caretaker decides when to save and when to restore.

## Example

```java
record PaymentDraft(BigDecimal amount, PaymentMethod method) { }   // the memento
class PaymentForm {                                                 // the originator
    private BigDecimal amount = BigDecimal.valueOf(500);
    private PaymentMethod method = PaymentMethod.UPI;
    PaymentDraft save() { return new PaymentDraft(amount, method); }
    void restore(PaymentDraft d) { amount = d.amount(); method = d.method(); }
    void choose(PaymentMethod m) { method = m; }
}
var form = new PaymentForm();
Deque<PaymentDraft> history = new ArrayDeque<>();                   // the caretaker
history.push(form.save()); form.choose(PaymentMethod.CARD); form.restore(history.pop());
System.out.println(form.save());                                   // after undo
```

```text output
PaymentDraft[amount=500, method=UPI]
```

## Interview Qs

### How would you build undo for the payment form?

Wrap each change in a [command](card:command). Before it runs, push the form's memento on a history stack. Undo pops the last memento and restores it.

### How does Memento keep encapsulation?

The originator makes the snapshot itself, because only it sees its private fields. The caretaker just stores it. A record memento cannot be changed: its fields are final. Keep it nested or package-private to hide it further.
