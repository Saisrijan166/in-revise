## Why it exists

Mixing input handling, business rules and HTML in one place makes each hard to change. Shared steps such as security also get copied into every page.

## How it works

<Mermaid
  alt="Spring MVC request flow. An HTTP request reaches the DispatcherServlet. It asks a HandlerMapping which handler fits, then calls PaymentController, which calls PaymentService. A @Controller returns a view name and a Model; the DispatcherServlet asks a ViewResolver to turn the name into an HTML view. A @RestController instead returns an object that is written to the response body as JSON."
  chart={`flowchart LR
  RQ([HTTP request]) --> DS[DispatcherServlet]
  DS -- "which handler?" --> HM[HandlerMapping]
  DS -- "calls" --> PC[PaymentController]
  PC --> PS[PaymentService]
  DS -- "view name + Model" --> VR[ViewResolver]
  VR --> V[HTML view]
  PC -. "@RestController" .-> J[JSON body]`}
/>

- A HandlerMapping finds the handler and its interceptors; a HandlerAdapter invokes it.
- `@RestController` is `@Controller` plus `@ResponseBody`: return values go to the body, with no view.
- In the original Smalltalk MVC, views observed the model; see [Observer](card:observer).

## Example

```java
@RestController
@RequestMapping("/payments")
public class PaymentController {
    private final PaymentService service;
    public PaymentController(PaymentService service) { this.service = service; }

    @PostMapping
    public PaymentResponse pay(@RequestBody PaymentRequest request) {
        return service.pay(request);           // written as JSON, no view
    }
}
```

## Interview Qs

### What is the front controller in Spring MVC?

The DispatcherServlet. Every request reaches it first. It finds the handler through a HandlerMapping, calls it through a HandlerAdapter, resolves exceptions, and renders the view if there is one.

### What is the difference between @Controller and @RestController?

A @Controller method usually returns a view name that a template renders. @RestController adds @ResponseBody to every method, so the return value is converted, for example to JSON, and written to the response body.
