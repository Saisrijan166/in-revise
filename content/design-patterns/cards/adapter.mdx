## Why it exists

You must use a third-party or legacy class whose methods do not match your interface, and you cannot change it. Rewriting callers for it would spread its API everywhere.

## How it works

<Mermaid
  alt="PaymentService calls charge with a BigDecimal amount on the PaymentGateway interface. UpiAdapter implements that interface and calls ExternalUpiSdk's makePaymentInPaise with a long amount in paise."
  chart={`flowchart LR
  C[PaymentService] -- "charge(BigDecimal)" --> T{{PaymentGateway}}
  T --> A[UpiAdapter]
  A -- "makePaymentInPaise(long)" --> S[ExternalUpiSdk]`}
/>

- An **object adapter** wraps the adaptee and works in any language; a class adapter inherits from it instead.
- JDK: `InputStreamReader` reads a byte stream as characters. Spring MVC: a `HandlerAdapter` lets `DispatcherServlet` call any handler type.

## Example

```java
class UpiAdapter implements PaymentGateway {             // target: PaymentGateway
    private final ExternalUpiSdk sdk;                     // adaptee
    UpiAdapter(ExternalUpiSdk sdk) { this.sdk = sdk; }

    @Override
    public void charge(BigDecimal amount) {               // ₹500 or ₹500.00
        long paise = amount.movePointRight(2).longValueExact();   // 50_000
        sdk.makePaymentInPaise(paise);                    // throws if a fraction of a paisa is left
    }
}
```

## Interview Qs

### Where would you use Adapter in a payment system?

Wrap each provider SDK behind your own `PaymentGateway`. Callers depend only on that interface, so a new or changed SDK needs a new adapter, not changes across the codebase.

### Object adapter or class adapter?

An object adapter holds the adaptee and delegates to it. A class adapter inherits from the adaptee instead, which ties it to that one concrete class, so the object adapter is looser.

### Why not convert rupees to paise with double?

A double cannot hold many decimal amounts, such as 0.1, exactly, so rounding errors creep in. Use BigDecimal, or a long count of paise, and fail loudly if a fraction of a paisa is left.
