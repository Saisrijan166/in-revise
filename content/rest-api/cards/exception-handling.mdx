## Why it exists

Without one central place, every controller repeats try/catch and errors come in different shapes. One advice gives each error its status and one body shape.

## How it works

<Mermaid
  alt="An exception goes to the controller's @ExceptionHandler first, then to the @RestControllerAdvice; either returns a ProblemDetail. Unhandled, Spring Boot's /error sends generic JSON."
  chart={`flowchart TD
  E([Exception thrown in service]) --> L{"@ExceptionHandler in that controller?"}
  L -- yes --> P["ProblemDetail: status + body"]
  L -- no --> G{"@ExceptionHandler in @RestControllerAdvice?"}
  G -- yes --> P
  G -- no --> X["Spring Boot /error: generic JSON"]`}
/>

- The `status` of the returned ProblemDetail becomes the HTTP status.
- What the fields mean (type, title, status, detail, instance): [error responses](card:error-responses).

## Example

```java
@RestControllerAdvice
class ApiErrors extends ResponseEntityExceptionHandler {   // also formats Spring MVC's errors
    @ExceptionHandler(PaymentNotFoundException.class)
    ProblemDetail notFound(PaymentNotFoundException ex) {
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
        pd.setTitle("Payment not found");
        return pd;                                // 404, application/problem+json
    }
}
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| ProblemDetail for Spring MVC's built-in errors | off: `spring.mvc.problemdetails.enabled=false` | Spring Boot 4.1 |
| Message and stack trace in `/error` | `never` (`spring.web.error.include-message`, `include-stacktrace`) | Spring Boot 4.1 |

## Interview Qs

### How do you handle exceptions globally in Spring Boot?

A @RestControllerAdvice class with one @ExceptionHandler method per exception type, each returning a ProblemDetail with the right status. It applies to every controller.

### If @ExceptionHandler handles exceptions, why do we need @ControllerAdvice?

@ExceptionHandler is the mechanism, but inside a controller it covers only that controller. @ControllerAdvice makes the handlers global, so one class serves every controller.

### What does a client get for an exception nobody handles?

Spring Boot's /error mapping sends a JSON error with the status, usually 500, and by default hides the message and stack trace.
