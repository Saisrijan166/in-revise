## Why it exists

Browsers stop a page reading another origin's responses, so a bad site cannot read your data. CORS lets an API relax that for origins it trusts, like its own web app.

## How it works

<Mermaid
  alt="CORS preflight. A page on shop.example wants to POST JSON to api.shop.example. The browser first sends OPTIONS with Origin and Access-Control-Request-Method POST. The API answers with Access-Control-Allow-Origin https://shop.example and the allowed methods and headers. If they match, the browser sends the real POST and lets the page read the response; otherwise it blocks it."
  chart={`sequenceDiagram
  participant P as Page on shop.example
  participant B as Browser
  participant A as api.shop.example
  P->>B: POST /api/payments (JSON)
  B->>A: OPTIONS preflight + Origin
  A-->>B: Allow-Origin, Allow-Methods, Allow-Headers
  B->>A: Real POST
  A-->>B: 201 + Allow-Origin
  B-->>P: Response readable`}
/>

- Simple requests (GET, HEAD, form-style POST) skip the preflight; the browser still checks the response headers.
- `Access-Control-Max-Age` caches the preflight result, so the OPTIONS call is not repeated each time.
- CORS does not stop CSRF: browsers still send cross-site form posts with cookies ([CORS vs CSRF](compare:cors-vs-csrf)).

## Example

```text
OPTIONS /api/payments HTTP/1.1
Origin: https://shop.example
Access-Control-Request-Method: POST
Access-Control-Request-Headers: content-type, authorization

HTTP/1.1 204 No Content
Access-Control-Allow-Origin: https://shop.example
Access-Control-Allow-Methods: POST
Access-Control-Allow-Headers: content-type, authorization
Access-Control-Max-Age: 3600
```

## Interview Qs

### Why does my API work from Postman but fail in the browser?

Postman is not a browser, so it does not apply the same-origin policy. The browser blocks the response because the API did not send a matching `Access-Control-Allow-Origin`, or the preflight failed.

### Is Access-Control-Allow-Origin: * safe?

Only for public data without credentials. Browsers refuse `*` for requests that send cookies or HTTP auth; name the exact origins instead.
