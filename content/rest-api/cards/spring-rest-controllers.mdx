## Why it exists

An API needs one place where HTTP meets Java: match a URL and method to code, read the input, and send data back, usually as JSON.

## How it works

| Annotation | Maps | Example |
| --- | --- | --- |
| `@RequestMapping("/api/payments")` | on the class: the shared path | every method below |
| `@GetMapping("/{id}")` | GET | read PAY101 |
| `@PostMapping` | POST | create a payment |
| `@PutMapping`, `@PatchMapping` | PUT, PATCH | replace, change some fields |
| `@DeleteMapping("/{id}")` | DELETE | remove |

- The DispatcherServlet sends each request to the matching method. What each method means: [HTTP methods](card:http-methods).
- Layers: controller → service → repository. No business rules or SQL in the controller.
- Routing by version: [API versioning](card:api-versioning).

## Example

```java
@RestController
@RequestMapping("/api/payments")
class PaymentController {
    private final PaymentService service;
    PaymentController(PaymentService service) { this.service = service; }
    @PostMapping                                            // POST /api/payments
    ResponseEntity<PaymentResponse> create(@Valid @RequestBody PaymentRequest req) {
        return ResponseEntity.status(HttpStatus.CREATED).body(service.create(req));
    }
    @GetMapping("/{id}")                                    // GET /api/payments/PAY101
    PaymentResponse get(@PathVariable String id) { return service.find(id); }
}
```

Setting the status and headers: [ResponseEntity](card:response-entity).

## Interview Qs

### @RequestMapping vs @GetMapping?

@GetMapping is a shortcut for @RequestMapping with method GET. A plain @RequestMapping matches all methods, so use it on the class for the shared path and the shortcuts on methods.

### How does a returned object become JSON?

With @ResponseBody, Spring passes the return value to an HttpMessageConverter that fits the requested media type. For JSON, Spring Boot 4 uses Jackson 3.

### Why keep the controller thin?

The controller only translates HTTP: bind input, call the service, pick the status. Rules in a service can be reused by other callers and unit-tested without HTTP.
