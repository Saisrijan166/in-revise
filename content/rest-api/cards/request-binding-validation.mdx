## Why it exists

Input arrives in the path, query, headers and body as text. Spring converts it to Java types and checks it in one declared way, so controllers do not repeat if-checks.

## How it works

| Annotation | Reads | Example |
| --- | --- | --- |
| `@PathVariable` | a `{placeholder}` in the path | `/api/payments/{id}` → `PAY101` |
| `@RequestParam` | a query or form parameter | `?status=SUCCESS` |
| `@RequestHeader` | one request header | `Idempotency-Key: order-789-payment` |
| `@RequestBody` | the body, via an HttpMessageConverter | JSON → `PaymentRequest` |

- `@Valid` alone checks nothing: the constraints on the fields do the checking.
- Handle both exceptions; give them one error shape in [exception handling](card:exception-handling).

## Example

```java
record PaymentRequest(
        @NotNull @Positive BigDecimal amount,              // 0 and -500 fail
        @NotBlank @Size(min = 3, max = 3) String currency, // "INR"
        @NotNull PaymentMethod method) { }                 // UPI, CARD, WALLET

@PostMapping
ResponseEntity<PaymentResponse> create(
        @RequestHeader("Idempotency-Key") String key,
        @Valid @RequestBody PaymentRequest req) {
    return ResponseEntity.status(HttpStatus.CREATED).body(service.create(key, req));
}
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| `@PathVariable`, `@RequestParam`, `@RequestHeader` | required; missing value fails | Spring Framework 7.0 |
| `@RequestParam(defaultValue = "0")` | makes the parameter optional | Spring Framework 7.0 |

## Interview Qs

### @PathVariable vs @RequestParam?

@PathVariable reads part of the path that names the resource, like PAY101 in /api/payments/PAY101. @RequestParam reads a query option, like ?status=SUCCESS, used to filter or sort.

### How do you validate a request body?

Put Jakarta constraints such as @NotNull and @Positive on the DTO fields and mark the @RequestBody parameter with @Valid. A failure throws MethodArgumentNotValidException, which becomes 400.

### @Valid vs @Validated?

@Valid is the Jakarta annotation: validate this object and its nested objects. @Validated is Spring's: it can name validation groups, and on a class it turns on method validation through a proxy.
