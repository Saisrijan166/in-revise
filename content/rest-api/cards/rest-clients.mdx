## Why it exists

A service often calls others, such as a payment gateway. A client turns Java objects into HTTP requests and responses back into objects, and handles errors and timeouts.

## How it works

<Compare id="resttemplate-vs-restclient-vs-webclient" />

- Group many interface clients with `@ImportHttpServices` (Spring Framework 7.0).
- Why timeouts and which calls to retry: [retries and timeouts](card:retries-and-timeouts).

## Example

```java
@Service
class GatewayClient {
    private final RestClient http;
    GatewayClient(RestClient.Builder b) { http = b.baseUrl("https://gateway.example.com").build(); }
    GatewayResult charge(ChargeRequest req, String key) {
        return http.post().uri("/charges")
                .header("Idempotency-Key", key)                  // order-789-payment
                .body(req)
                .retrieve()
                .onStatus(HttpStatusCode::is4xxClientError, (rq, rs) -> { throw new GatewayRejected(rs.getStatusCode()); })
                .body(GatewayResult.class);
    }
}
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| Beans you inject | prototype `RestClient.Builder` and `WebClient.Builder`; no `RestTemplate` bean, only `RestTemplateBuilder` | Spring Boot 4.1 |
| 4xx or 5xx with `retrieve()` | throws a `RestClientException` subclass | Spring Framework 7.0 |

## Interview Qs

### RestTemplate vs RestClient vs WebClient?

RestTemplate is the old blocking client with template methods; its removal is planned for Spring Framework 8.0. RestClient is also blocking, with a fluent API. WebClient is non-blocking and reactive. New blocking code uses RestClient.

### What is an HTTP interface client?

A Java interface whose methods carry @GetExchange or @PostExchange. Spring creates a proxy that makes the calls through RestClient or WebClient, so the remote API is declared once.

### How do you handle a 4xx from the called API?

By default retrieve() throws a RestClientException subclass. Add onStatus to map, for example, a 4xx to your own exception, or use exchange() to read the response yourself.
