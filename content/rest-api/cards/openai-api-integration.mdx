## Why it exists

Interviewers ask how a backend adds an AI feature. It is an ordinary call to an external REST API, so the usual client, auth and retry rules apply.

"Write integration code": name the class, then the one call.

| Tech | Java or Spring class | Main call |
| --- | --- | --- |
| OpenAI | `RestClient` | `post().uri("/responses").body(...).retrieve()` |
| Redis | `StringRedisTemplate` | `opsForValue().set(key, value, ttl)`, `get(key)` |
| Kafka producer | `KafkaTemplate` | `send(topic, key, value)` |
| Kafka consumer | `@KafkaListener(topics = "...")` | the method runs for each record |
| AWS S3 | `S3Client` (SDK 2.x) | `putObject(PutObjectRequest, RequestBody)` |
| AWS SQS | `SqsClient` (SDK 2.x) | `sendMessage(SendMessageRequest)` |
| AWS RDS | `JdbcClient` or JPA, as for any SQL database | `sql(...).param(...).update()` |

- Timeouts and `onStatus`: [HTTP clients](card:rest-clients); what to retry: [retries and timeouts](card:retries-and-timeouts).
- [openai-java](card:openai-java-sdk) or [Spring AI](card:spring-ai-chatclient) wrap the same call.
- Log the `x-request-id` header; OpenAI support traces calls by it.

## Example

```java
@Service
class AiClient {
    private final RestClient http;
    AiClient(RestClient.Builder b) {
        http = b.baseUrl("https://api.openai.com/v1")
                .defaultHeader("Authorization", "Bearer " + System.getenv("OPENAI_API_KEY"))
                .build();
    }
    String ask(String prompt) {
        return http.post().uri("/responses")
                .body(Map.of("model", "gpt-6-luna", "input", prompt, "max_output_tokens", 500))
                .retrieve().body(Reply.class).text();
    }
}
```

```java
record Reply(List<Item> output) {
    String text() {                       // skip reasoning items, join the text parts
        return output.stream().filter(i -> "message".equals(i.type()))
                .flatMap(i -> i.content().stream())
                .filter(p -> "output_text".equals(p.type()))
                .map(Part::text).collect(Collectors.joining());
    }
}
record Item(String type, List<Part> content) {}
record Part(String type, String text) {}
```

## Interview Qs

### How would you integrate the ChatGPT API in Spring Boot?

Code calls the OpenAI API, not ChatGPT. One service wraps a RestClient: POST /v1/responses with model and input as JSON and a Bearer key from the environment (never in code, Git or a browser), then map the reply to records.

### What do you do when OpenAI returns 429?

A rate limit is retryable: wait for Retry-After, else back off with jitter, and cap attempts. Quota and spend-limit 429s need action, not retries. Official SDKs already retry 429 and 503; do not stack a second loop.
