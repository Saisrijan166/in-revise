## Why it exists

Clients need an exact, machine-readable contract: URLs, fields, status codes, auth. One shared file lets tools render docs and generate clients.

## How it works

<Mermaid
  alt="Design-first: write the YAML; Codegen makes stubs and clients. Code-first: springdoc scans controllers and serves /v3/api-docs. Swagger UI renders either."
  chart={`flowchart LR
  D[Write openapi.yaml] --> G[Codegen: stubs and clients]
  C[Annotated controllers] --> S[springdoc-openapi]
  S --> F["/v3/api-docs"]
  D --> U[Swagger UI]
  F --> U`}
/>

- [Design-first](card:design-first-openapi): write and review the file, then code. The OpenAPI Initiative recommends it.
- [Code-first](card:code-first-openapi): generate the file from code. Easiest start; some designs prove hard to describe.
- Keep one file in Git as the source of truth; checks against it: [API testing](card:api-testing-strategy).

## Example

```yaml
openapi: 3.2.0
info: { title: Payments API, version: 1.0.0 }
paths:
  /api/payments:
    post:
      security: [{ bearerAuth: [] }]
      requestBody:
        content:
          application/json:
            schema: { $ref: '#/components/schemas/PaymentRequest' }
      responses:
        '201': { description: Payment created with status PENDING }
        '400': { description: Invalid amount or currency }
# components (schemas, securitySchemes) omitted
```

## Defaults

| What | Default | Where |
|---|---|---|
| OpenAPI JSON | `/v3/api-docs` | springdoc-openapi 3.x (Spring Boot 4) |
| Swagger UI | `/swagger-ui.html` | springdoc-openapi 3.x |
| Generated OAS version | 3.1 | springdoc-openapi 3.x, `springdoc.api-docs.version` |

## Interview Qs

### What is the difference between OpenAPI and Swagger?

OpenAPI is the specification; SmartBear donated Swagger 2.0 to the OpenAPI Initiative in 2015. Swagger is SmartBear's tool set: UI, Editor, Codegen.

### Design-first or code-first?

Design-first for shared APIs: consumers review the contract before code exists. Code-first is the easiest start; review the generated file.

### How do you document a Spring Boot REST API?

Add springdoc-openapi 3.x. It scans controllers and serves the file and Swagger UI (paths in Defaults). @Operation adds descriptions.
