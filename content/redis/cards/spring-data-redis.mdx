## Why it exists

Raw client code means hand-made connections and byte conversion everywhere. Spring Data Redis gives templates that convert Java values and share connections; Spring Boot wires them up.

## How it works

<Mermaid
  alt="PaymentService calls a StringRedisTemplate or RedisTemplate. The template's serialisers turn keys and values into bytes. The RedisConnectionFactory hands the command to the client, Lettuce by default or Jedis, which sends it to Redis."
  chart={`flowchart LR
  S[PaymentService] --> T["StringRedisTemplate / RedisTemplate"]
  T --> Z["Serialisers: Java to bytes"]
  Z --> F[RedisConnectionFactory]
  F --> C["Lettuce (default) or Jedis"]
  C --> R[(Redis)]`}
/>

- Connect with `spring.data.redis.host` and `port`, or one `spring.data.redis.url` that overrides them.
- With `commons-pool2` on the classpath, Boot builds a pooled connection factory.
- Whiteboard skeletons for set and get, counters and locks: [Redis code templates](card:redis-code-templates).

## Example

```java
@Bean
RedisTemplate<String, Payment> paymentTemplate(RedisConnectionFactory factory) {
    var template = new RedisTemplate<String, Payment>();
    template.setConnectionFactory(factory);
    template.setKeySerializer(RedisSerializer.string());
    template.setValueSerializer(new JacksonJsonRedisSerializer<>(Payment.class));
    return template;
}

// payment:PAY101 -> {"amount":500,"method":"UPI"}, gone after 5 minutes
paymentTemplate.opsForValue().set("payment:PAY101", payment, Duration.ofMinutes(5));
```

## Defaults

| What | Default | Where |
|---|---|---|
| Server | `localhost:6379` | Spring Boot 4.1 |
| Client library | Lettuce | `spring-boot-starter-data-redis`, Spring Boot 4.1 |
| `RedisTemplate` and `RedisCache` values | JDK serialisation | Spring Data Redis 4.1 |

## Interview Qs

### Do you need a connection pool with Lettuce?

Usually not: one thread-safe connection is shared for normal commands. Blocking commands such as BLPOP and MULTI/EXEC transactions need a dedicated connection, so add `commons-pool2` when you use them a lot.

### How do you store Java objects as JSON?

Define a `RedisTemplate<String, T>` with `RedisSerializer.string()` for keys and `JacksonJsonRedisSerializer` (Jackson 3, Spring Data Redis 4.0+) for values. Avoid JDK serialisation: it is Java-only and unsafe with untrusted data.
