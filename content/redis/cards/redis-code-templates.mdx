## What it is

Redis code templates are four short skeletons for the coding part of a Redis interview: the connection properties, a save with a TTL and a read, a counter for rate limiting, and a lock. Each one uses the `StringRedisTemplate` that Spring Boot already builds, as shown in [Spring Data Redis](card:spring-data-redis). The ideas behind them come from earlier concepts; this page is the code you write on the whiteboard.

## Why it exists

"How would you use Redis in Spring Boot?" is often followed by "write it". Code written from scratch under pressure tends to have the classic bugs: a key with no TTL, a GET and then a SET that two servers run at the same time, or a lock deleted by the wrong worker. Four fixed shapes, learned once, avoid all three.

## How it works

| Asked to write | Write |
|---|---|
| Connect to Redis | the properties below |
| Save with a TTL, read it back | `opsForValue().set(k, v, Duration)` and `get(k)`, below |
| Store Java objects as JSON | a `RedisTemplate` bean in [Spring Data Redis](card:spring-data-redis) |
| Cache a database read by hand | the [cache-aside](card:cache-aside) method |
| Cache with annotations | `@Cacheable` and `@CacheEvict` in [Spring Cache](card:spring-cache-abstraction) |
| Count or rate-limit | INCR and EXPIRE in one script, below |
| Lock a job | `setIfAbsent`, then a token check on release, below |

1. Add `spring-boot-starter-data-redis` and set the connection properties. Spring Boot builds the connection and the `StringRedisTemplate`.
2. Inject `StringRedisTemplate` into your service through its constructor.
3. On every write, pass a `Duration`, so the value and its TTL go in one SET.
4. When a write depends on a read, such as "count, then set the expiry" or "check the owner, then delete", put both steps in one [Lua script](card:lua-and-functions), so no other client runs in between.
5. For a lock, call `setIfAbsent` with a random token and a TTL, and release it with the token-check script.

## Example

The payment service connects with these properties; the password comes from an environment variable, not from the file.

```properties
spring.data.redis.host=localhost
spring.data.redis.port=6379
spring.data.redis.password=${REDIS_PASSWORD}
spring.data.redis.timeout=2s
```

It saves a payment status for 10 minutes and reads it back.

```java
@Service
class PaymentStatusStore {
    private final StringRedisTemplate redis;           // auto-configured by Spring Boot
    PaymentStatusStore(StringRedisTemplate redis) { this.redis = redis; }

    void save(String id, String status) {              // SET payment:9001:status PAID EX 600
        redis.opsForValue().set("payment:" + id + ":status", status, Duration.ofMinutes(10));
    }
    String find(String id) {                           // null when missing or expired
        return redis.opsForValue().get("payment:" + id + ":status");
    }
}
```

The same steps in redis-cli, with the replies Redis gives:

```bash
redis-cli SET payment:9001:status PAID EX 600
redis-cli GET payment:9001:status
redis-cli TTL payment:9001:status
redis-cli GET payment:9999:status
```

```text output
OK
"PAID"
(integer) 600
(nil)
```

The login limiter allows 5 attempts per user per 60 seconds.

```java
private static final RedisScript<Long> HIT = RedisScript.of("""
        local n = redis.call('INCR', KEYS[1])
        if n == 1 then redis.call('EXPIRE', KEYS[1], ARGV[1]) end
        return n""", Long.class);

boolean allowLogin(String userId) {                    // 5 attempts per 60-second window
    Long n = redis.execute(HIT, List.of("rate:user:" + userId + ":login"), "60");
    return n <= 5;                                     // false: answer HTTP 429
}
```

One worker at a time may capture payment 9001.

```java
private static final RedisScript<Long> UNLOCK = RedisScript.of(
        "if redis.call('get', KEYS[1]) == ARGV[1] then return redis.call('del', KEYS[1]) end return 0",
        Long.class);

boolean runOnce(String paymentId, Runnable job) {
    String key = "lock:payment:" + paymentId, token = UUID.randomUUID().toString();
    Boolean got = redis.opsForValue().setIfAbsent(key, token, Duration.ofSeconds(30));
    if (!Boolean.TRUE.equals(got)) return false;       // another worker holds the lock
    try { job.run(); return true; }
    finally { redis.execute(UNLOCK, List.of(key), token); }   // delete only if still mine
}
```

What to notice:

- `set(key, value, Duration)` sends one `SET ... EX 600`, and `get` returns null for the missing `payment:9999:status`, so the caller must check for null.
- The limiter's script sets the expiry only on the first hit (`n == 1`), so the window starts at the first attempt; the sixth call in that window returns false.
- `setIfAbsent` sends `SET lock:payment:9001 <token> EX 30 NX`: true means this worker holds the lock. The `finally` block runs the release even when the job throws.
- The release deletes the key only if it still holds this worker's token. Replace it with a plain `delete` and a worker whose lock expired can remove another worker's lock.

## Rules and defaults

- **Script results:** a Lua integer comes back as a Java `Long`, so declare `RedisScript<Long>`.
- **Script sending:** Spring sends EVALSHA with the script's SHA1 first, and falls back to EVAL with the full text when Redis replies NOSCRIPT (Spring Data Redis 4.1).
- **Keys and arguments:** pass key names in the `keys` list, which the script reads as `KEYS[1]`, and other values as arguments, read as `ARGV[1]`.
- **Boolean results:** `setIfAbsent` returns a `Boolean` that is null inside a pipeline or transaction, so compare with `Boolean.TRUE.equals(...)`.
- **Timeouts:** what `spring.data.redis.timeout` changes, and why to set it, is in [When Redis is slow or down](card:redis-failure-handling).

## Interview Qs

### How do you integrate Redis into a Spring Boot service?

Add `spring-boot-starter-data-redis`, set `spring.data.redis.host` and `port`, and inject the auto-configured `StringRedisTemplate`. Write with `opsForValue().set(key, value, Duration)` so every key gets a TTL, and read with `get`, which returns null on a miss.

### How do you run a Lua script from Spring?

Wrap the script once in `RedisScript.of(text, Long.class)`, kept in a static field, and call `redis.execute(script, keys, args)`. Spring sends EVALSHA, so the script text crosses the network only when Redis has not cached it yet.

### How would you rate-limit login attempts with Redis in Spring Boot?

Keep one counter per user, such as `rate:user:7:login`. A Lua script runs INCR and, on the first hit, EXPIRE 60, then returns the count; above 5 the endpoint answers HTTP 429. One script keeps the count and the expiry together.
