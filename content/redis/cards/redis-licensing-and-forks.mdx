## Why it exists

The 2024 licence change split the ecosystem. Teams now choose between Redis Open Source, Valkey and managed services.

## How it works

| Release | Licence | Note |
|---|---|---|
| Redis 7.2 and earlier | BSD-3-Clause | Valkey forked 7.2.4 |
| Redis 7.4 to 7.8 | RSALv2 or SSPLv1 | Source-available only |
| Redis Open Source 8.x | RSALv2, SSPLv1 or AGPLv3 | Renamed from Community Edition |

- Managed options: Amazon ElastiCache, Amazon MemoryDB, Azure Managed Redis (see the Tree).

## Interview Qs

### What happened to Redis Stack?

Redis 8.0 merged Redis Stack and Community Edition into one Redis Open Source. JSON, the Query Engine, time series and probabilistic types now ship in the core package; no modules to install.

### Redis or Valkey?

Both grew from the same 7.2.4 code. Pick on licence, the features you need and what your cloud offers; for example, ElastiCache runs Valkey, Redis OSS or Memcached.
