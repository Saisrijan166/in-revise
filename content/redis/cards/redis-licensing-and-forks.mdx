## What it is

A licence is the set of legal terms under which you may use, change and share software. Redis has changed its licence twice since 2024, and a fork appeared: Valkey, a copy of the Redis code that a different community now develops. So today "Redis" can mean Redis Open Source 8, an older BSD-licensed release, Valkey, or a managed cloud service that runs one of them.

## Why it exists

Licences differ in what you may do when you change the code or offer it to others as a service. A company that runs Redis itself, or builds a product on it, must know which terms apply. The choice between Redis and Valkey, and between running servers yourself and a managed service, now depends partly on the licence, so interviewers sometimes ask about it.

## How it works

| Release | Licence | Note |
|---|---|---|
| Redis 7.2 and earlier | BSD-3-Clause | Valkey forked 7.2.4 |
| Redis 7.4 to 7.8 | RSALv2 or SSPLv1 | Source-available only |
| Redis Open Source 8.x | RSALv2, SSPLv1 or AGPLv3 | Includes the former Redis Stack |

1. Up to version 7.2, Redis used BSD-3-Clause, a permissive open source licence.
2. In March 2024, Redis announced that, from version 7.4, it would use a choice of RSALv2 or SSPLv1. These are source-available: you can read the code, but they are not open source licences.
3. The same month, the Linux Foundation launched Valkey, which continues from Redis 7.2.4 under BSD.
4. With Redis 8.0, Redis added AGPLv3, a licence approved as open source by the Open Source Initiative (OSI), as a third choice, and merged Redis Stack into one package called Redis Open Source.

## Example

Before you decide which licence applies, check which version a server runs.

```bash
redis-cli INFO server | grep redis_version
```

```text output
redis_version:8.10.2
```

What to notice:

- `INFO server` reports facts about the running server; `grep` keeps only the version line.
- Version 8.10.2 is Redis Open Source 8, so RSALv2, SSPLv1 and AGPLv3 are the available choices. A server that prints 7.2.x is still under BSD.

## Rules and defaults

- **Your choice of licence:** on Redis Open Source 8.x, you pick one of the three licences; the code is the same.
- **Built-in types:** since 8.0, JSON, the Query Engine, time series and probabilistic types ship in the core package, with no modules to install.
- **Managed services:** the provider runs the servers for you. For example, Amazon ElastiCache offers Valkey, Redis OSS or Memcached.

## Interview Qs

### What happened to Redis Stack?

Redis 8.0 merged Redis Stack and the Community Edition into one Redis Open Source. JSON, the Query Engine, time series and probabilistic types now ship in the core package, so there are no modules to install.

### Redis or Valkey?

Both grew from the same Redis 7.2.4 code. Pick on licence terms, the features you need and what your cloud offers; for example, ElastiCache runs Valkey, Redis OSS or Memcached. Newer Redis 8 features, such as the built-in Query Engine, may differ in Valkey, so check before you switch.
