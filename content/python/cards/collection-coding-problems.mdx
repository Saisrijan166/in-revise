## What it is

A set of the list, set and dict problems from coding rounds: removing duplicates, finding duplicates, **Two Sum** (find two numbers that add to a target), finding **common elements** of two lists, and **flattening** a list of lists. Python solves them with sets, dicts and comprehensions instead of nested loops.

## Why it exists

The point is to use hashing. A set membership test or a dict lookup is average O(1), so a problem that looks like it needs two nested loops (O(n²)) often becomes one pass (O(n)). Interviewers want to see you reach for a set or dict rather than scan the list again and again.

## How it works

<Steps label="The common collection moves">
  <Step title="Dedupe">set(items), or dict.fromkeys(items) to keep order.</Step>
  <Step title="Find duplicates">Keep a seen set; a repeat is a duplicate.</Step>
  <Step title="Two Sum">Store value to index; for each x look for target - x.</Step>
  <Step title="Intersect / flatten">set(a) & set(b); nested comprehension to flatten.</Step>
</Steps>

1. A set drops duplicates but loses order; `dict.fromkeys` keeps first-seen order (insertion order is guaranteed since Python 3.7).
2. Two Sum checks `target - x` in a growing map, so it finishes in one pass.
3. `set(a) & set(b)` is set intersection; `|` is union and `-` is difference.

## Example

```python
items = [1, 2, 2, 3, 3, 3]
print(set(items))                       # unordered unique
print(list(dict.fromkeys(items)))       # unique, order kept
print(set([1, 2, 3]) & set([2, 3, 4]))  # common elements
```

```text output
{1, 2, 3}
[1, 2, 3]
{2, 3}
```

What to notice: `set` gives the unique values but no guaranteed order, `dict.fromkeys` keeps the first-seen order, and `&` intersects the two sets to give the common elements.

```python
def two_sum(nums, target):
    seen = {}                 # value -> index
    for i, x in enumerate(nums):
        if target - x in seen:
            return (seen[target - x], i)
        seen[x] = i
    return None

print(two_sum([2, 7, 11, 15], 9))
```

```text output
(0, 1)
```

What to notice: each number is checked against the map of earlier numbers, so the pair is found in a single pass. The lookup `target - x in seen` is O(1), turning an O(n²) double loop into O(n).

```python
nested = [[1, 2], [3, 4], [5]]
print([x for sub in nested for x in sub])   # flatten one level
```

```text output
[1, 2, 3, 4, 5]
```

What to notice: the two `for` clauses read left to right like nested loops: outer `sub`, then inner `x`. It flattens exactly one level, not arbitrarily deep nesting.

## Common mistakes

- **Assuming a set keeps order.** It does not; use `dict.fromkeys` when order matters.
- **Two nested loops for Two Sum.** A value-to-index map solves it in one pass.
- **Reading the flatten comprehension backwards.** The clauses run outer-to-inner, same order as nested `for` loops.

## Interview Qs

### How do you remove duplicates while keeping order?

Use `list(dict.fromkeys(items))`. A plain `set(items)` removes duplicates but loses order, whereas dicts have kept insertion order since Python 3.7, so `fromkeys` preserves the first appearance of each value.

### How does the hash-map Two Sum work?

Walk the list once, keeping a map of value to index. For each number x, check whether `target - x` is already in the map; if so you have the pair. Lookups are O(1), so the whole scan is O(n).

### How do you find the common elements of two lists?

Convert both to sets and intersect: `set(a) & set(b)`. This returns the values present in both. Use `|` for the union and `-` for items only in the first list.
