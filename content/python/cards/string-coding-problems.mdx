## What it is

A set of the string problems that come up in coding rounds: reversing a string, checking a **palindrome** (reads the same backwards), checking an **anagram** (same letters rearranged), counting vowels, and building a **character frequency** map. Python solves most of them with slicing and built-ins rather than manual loops.

## Why it exists

Interviewers use these to see whether you reach for Python's tools or write Java-style loops. Knowing that slicing, `sorted()` and `Counter` turn each one into a line or two shows fluency and avoids off-by-one bugs. They also test that you remember strings are immutable, which changes how you build results.

## How it works

<Steps label="The common string moves">
  <Step title="Reverse">s[::-1] slices from end to start with step -1.</Step>
  <Step title="Palindrome">Compare the string to its reverse.</Step>
  <Step title="Anagram">Sort both and compare, or compare their Counters.</Step>
  <Step title="Count">Walk once, building a dict of char to count.</Step>
</Steps>

1. Slicing and `sorted()` do the heavy lifting in one expression.
2. For counts, `dict.get(c, 0) + 1` or `collections.Counter(s)` builds the map in one pass.
3. Normalise first (lowercase, strip spaces) when case or spaces should not matter.

## Example

```python
s = "level"
print(s[::-1])                       # reverse
print(s == s[::-1])                  # palindrome?
print(sorted("listen") == sorted("silent"))   # anagram?
print(sum(1 for c in "education" if c in "aeiou"))  # vowel count
```

```text output
level
True
True
4
```

What to notice: `s[::-1]` reverses with no loop, the palindrome check is a single comparison, and `sorted(...) == sorted(...)` compares the letter multisets so order does not matter.

```python
from collections import Counter
print(Counter("banana"))
print(Counter("banana")["a"])
```

```text output
Counter({'a': 3, 'n': 2, 'b': 1})
3
```

What to notice: `Counter` builds the full frequency map in one call and lets you index it like a dict, returning 0 for a missing key instead of raising.

```python
freq = {}
for c in "orders":
    freq[c] = freq.get(c, 0) + 1
print(freq)
```

```text output
{'o': 1, 'r': 2, 'd': 1, 'e': 1, 's': 1}
```

What to notice: `dict.get(c, 0)` gives a default of 0 for the first time a character is seen, so the `+ 1` always works without a separate "if key exists" check.

## Common mistakes

- **Building a reversed string in a loop.** `s[::-1]` is shorter and faster; strings are immutable, so concatenation copies.
- **Forgetting to normalise.** "RaceCar" is not a palindrome unless you lowercase it first.
- **Comparing lengths for an anagram.** Equal length is not enough; compare sorted letters or Counters.

## Interview Qs

### How do you reverse a string in Python?

`s[::-1]`. This slices the whole string with a step of -1, producing a new reversed string. No loop or helper is needed, and it works because strings support slicing.

### How do you check if two strings are anagrams?

Compare their sorted characters: `sorted(a) == sorted(b)`, or compare `Counter(a) == Counter(b)`. Both check that the two strings contain the same letters the same number of times, ignoring order.

### How do you count character frequency?

Walk the string once using `dict.get(c, 0) + 1`, or simply call `collections.Counter(s)`, which returns a dict-like map of each character to its count in a single pass.
