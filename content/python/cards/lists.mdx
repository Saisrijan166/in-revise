## What it is

A list is an ordered, [mutable](card:mutable-vs-immutable) sequence written with square brackets, like `[1, 2, 3]`. Ordered means it keeps the order you added items; mutable means you can change, add and remove items after it is made. A list allows duplicates and can hold items of different types.

## Why it exists

Most data comes as a changing collection: the orders in a cart, the lines read from a file, the results you build up in a loop. A list is Python's default container for that. It grows and shrinks, keeps order so you can index and slice it, and offers methods to add, remove and sort. Without it you would juggle fixed-size arrays and manual bookkeeping.

## How it works

| Need | Method | Note |
|---|---|---|
| Add one item | `append(x)` | x goes in as a single element |
| Add many items | `extend(iterable)` | each item is added separately |
| Delete by value | `remove(x)` | first match; `ValueError` if absent |
| Delete by index | `pop(i)` | returns the removed item; `pop()` removes the last |
| Sort in place | `sort()` | returns `None`; use `key=` and `reverse=` |
| Sort to a new list | `sorted(list)` | leaves the original unchanged |

1. You create the list and add items with `append` or `extend`.
2. You change items by index (`orders[0] = ...`) or remove them with `remove`/`pop`.
3. You order it with `sort` (in place) or `sorted` (new list).

## Example

```python
orders = ["pen", "ink"]
orders.append("pad")           # one item
orders.extend(["tape", "clip"])  # each item
first = orders.pop(0)          # remove and return "pen"
orders.sort()
print(first, orders)
```

```text output
pen ['clip', 'ink', 'pad', 'tape']
```

What to notice: `append` added `"pad"` as one item, while `extend` added `"tape"` and `"clip"` separately. `pop(0)` both removed and returned the first item. `sort()` reordered the list in place, so `orders` is now alphabetical; it returned `None`, which we did not store.

## Rules and defaults

- Lists keep insertion order and allow duplicates and mixed types.
- `append` adds exactly one element; `extend` (and `+=`) adds each element of an iterable.
- In-place methods (`sort`, `reverse`, `append`) return `None`.
- `sorted(list)` returns a new sorted list and does not touch the original.

## Not to be confused with

A [tuple](card:tuples) is also ordered, but it is immutable: once created you cannot add, remove or change items. Rule: use a list when the data changes, a tuple for a fixed record. See [List vs Tuple](compare:list-vs-tuple).

## Common mistakes

- **`nums = nums.sort()`.** `sort` returns `None`, so `nums` becomes `None`. Call `nums.sort()` alone or use `sorted`.
- **Using `append` to merge lists.** `a.append(b)` nests `b` as one item; use `extend` or `a + b`.
- **Removing while looping over the same list.** It skips items. Loop over a copy or build a new list.

## Interview Qs

### What is the difference between append and extend?

`append(x)` adds `x` as a single element, so `append([3, 4])` nests a list. `extend(iterable)` adds each item of the iterable separately, so `extend([3, 4])` adds `3` and `4` as two elements.

### What is the difference between sort and sorted?

`list.sort()` sorts in place and returns `None`. `sorted(iterable)` returns a new sorted list and leaves the input unchanged. Use `sorted` when you need the result in an expression or must keep the original order.

### What is the difference between remove and pop?

`remove(value)` deletes the first item equal to `value` and returns nothing. `pop(index)` deletes the item at that index and returns it; `pop()` with no argument removes and returns the last item.
