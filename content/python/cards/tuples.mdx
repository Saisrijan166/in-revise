## What it is

A tuple is an ordered, immutable sequence written with parentheses, like `(10, 20)`. Immutable means its items are fixed once it is created. Because it cannot change, a tuple is hashable when all its items are hashable, so it can be a dictionary key or a set item. It is the natural choice for a fixed record or for returning several values at once.

## Why it exists

Some groups of values belong together and should not change: a coordinate `(x, y)`, a row from a database, the several results a function returns. A tuple says "this is one fixed record". Being immutable also makes it hashable, so a pair like `(city, pincode)` can key a dictionary. A [list](card:lists) could hold the same items but signals that they may change and cannot be a key.

## How it works

<Compare id="list-vs-tuple" />

1. Create with commas: `t = 10, 20` or `t = (10, 20)`; a single item needs a comma: `(10,)`.
2. Read by index or unpack: `x, y = t` spreads the items into variables.
3. Use it where a fixed, hashable value is needed, such as a dict key, or return several values from a function as one tuple.

## Example

```python
def totals(order):
    return order["qty"], order["qty"] * order["price"]   # returns a tuple

count, amount = totals({"qty": 3, "price": 50})   # unpack
locations = {(10, 20): "warehouse"}               # tuple as dict key
print(count, amount, locations[(10, 20)])
```

```text output
3 150 warehouse
```

What to notice: the function returns two values as one tuple, which we unpack into `count` and `amount`. The pair `(10, 20)` works as a dict key because a tuple is hashable; a list `[10, 20]` would raise `TypeError` there.

## Rules and defaults

- The comma makes a tuple: `1, 2` is a tuple; `(1)` is just `1`; `(1,)` is a one-element tuple.
- Tuples are immutable, so there is no `append`, `remove` or `sort`; only `count` and `index`.
- A tuple is hashable (usable as a dict key or set item) only if every item it holds is hashable.
- An item that is itself mutable, like a list inside a tuple, can still be changed; it also makes the tuple unhashable.

## Common mistakes

- **Writing `(10)` for a one-tuple.** That is the integer 10. Use `(10,)`.
- **Trying to change a tuple.** `t[0] = 5` raises `TypeError`. Build a new tuple instead.
- **Using a tuple with a list inside as a key.** It is unhashable and raises `TypeError`.

## Interview Qs

### What is the difference between a list and a tuple?

Both are ordered. A list is mutable and written with `[]`; a tuple is immutable and written with `()`. A tuple is hashable when its items are, so it can be a dict key or set item; a list cannot. Use a tuple for a fixed record.

### How do you create a single-element tuple?

Add a trailing comma: `(10,)` or just `10,`. Without the comma, `(10)` is simply the integer in grouping parentheses, not a tuple.

### Why can a tuple be a dictionary key but a list cannot?

Dict keys must be hashable. A tuple is immutable and hashable when its items are hashable, so it can be a key. A list is mutable and unhashable, so using one as a key raises `TypeError`.
