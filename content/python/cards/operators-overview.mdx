## What it is

An operator is a symbol that combines values to make a new one. Python has arithmetic (`+ - * / // % **`), comparison (`== != > < >= <=`), logical (`and`, `or`, `not`), assignment (`=`, `+=`, and so on) and membership (`in`, `not in`). Each group answers a different question: how much, which is bigger, is this true, store this, is it inside.

## Why it exists

You need to compute, compare and test values all the time. A single set of clear operators means `total > 100`, `qty * price` and `'id' in order` all read like plain maths. The surprises are in the maths operators, where Python chose exact rules that differ from some other languages, so knowing them avoids silent bugs.

## How it works

| Group | Operators | Note |
|---|---|---|
| Arithmetic | `+ - * / // % **` | `/` always float; `//` floors; `**` is power |
| Comparison | `== != > < >= <=` | return `True` or `False` |
| Logical | `and`, `or`, `not` | short-circuit; `and`/`or` return an operand |
| Assignment | `=`, `+=`, `//=`, etc. | combine an operation with storing |
| Membership | `in`, `not in` | on a dict, tests keys |

1. Arithmetic: `/` gives a float, `//` floors toward negative infinity, `%` is the remainder, `**` is power.
2. Logical: `x and y` returns `x` if `x` is falsy, else `y`; `x or y` returns `x` if truthy, else `y`.
3. Membership: `in` scans a sequence or set; on a dict it checks keys.

## Example

```python
print(7 / 2)       # true division
print(7 // 2)      # floor division
print(-7 // 2)     # floors toward negative infinity
print(2 ** 10)     # power
print(0 or "Guest")   # or returns an operand
```

```text output
3.5
3
-4
1024
Guest
```

What to notice: `/` gives `3.5` even though both inputs are ints. `-7 // 2` is `-4`, not `-3`, because floor rounds down. `0 or "Guest"` returns the string, not `True`, because `or` returns the first truthy operand.

## Rules and defaults

| What | Behaviour | Where |
|---|---|---|
| `/` result | always a `float` | Python 3+ |
| `//` rounding | floor, toward negative infinity | Python 3+ |
| `and` / `or` | return an operand and short-circuit | Python 3+ |
| `in` on dict | tests keys | Python 3+ |

## Common mistakes

- Expecting `//` to truncate like C. For negatives it floors: `-7 // 2` is `-4`.
- Expecting `/` to give an int for even division. `6 / 2` is `3.0`; use `//` for an int.
- Using `in` on a dict and expecting it to search values. It searches keys only.

## Interview Qs

### Why does 6 / 2 return 3.0 and not 3?

In Python 3, `/` is true division and always returns a `float`, even when the result is a whole number. Use `//` (floor division) when you want an integer result.

### What is the difference between / and //?

`/` is true division and returns a float. `//` is floor division: it divides and rounds the result down toward negative infinity, returning an int for int operands. So `7 // 2` is `3` and `-7 // 2` is `-4`.

### What does `in` check for a dictionary?

It checks the keys. `'id' in order` tests whether `'id'` is a key, not a value. To test values, use `value in order.values()`.
