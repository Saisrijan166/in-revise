## What it is

A set is an unordered collection of unique, hashable items, written with curly braces, like `{1, 2, 3}`. Unordered means there is no index and no guaranteed order; unique means duplicates are dropped automatically. It uses hashing, so testing whether an item is present is about O(1). A `frozenset` is the immutable version of a set.

## Why it exists

You often need the distinct values from some data, or a fast "is this already seen?" test: unique order ids, tags without repeats, which customers appear in two lists. A set does both in one type. Dropping duplicates is automatic, and membership uses hashing instead of scanning, so `x in big_set` stays fast where `x in big_list` slows down. Set maths (union, intersection, difference) answers "who is in both" directly.

## How it works

| Operation | Symbol | Gives |
|---|---|---|
| Union | `a \| b` | items in either set |
| Intersection | `a & b` | items in both |
| Difference | `a - b` | items in `a` but not `b` |
| Symmetric difference | `a ^ b` | items in exactly one |
| Membership | `x in a` | True/False, about O(1) |

1. Create with `{...}` for items, or `set(iterable)` to dedupe; use `set()` for an empty set.
2. Add with `add(x)` and remove with `discard(x)` (safe) or `remove(x)` (raises if absent).
3. Combine sets with `|`, `&`, `-`, `^`.

## Example

```python
ids = [101, 102, 102, 103, 101]
unique = set(ids)                 # duplicates dropped
vip = {102, 104}
print(unique)
print(unique & vip, unique - vip) # common, and only-in-unique
```

```text output
{101, 102, 103}
{102} {101, 103}
```

What to notice: building a set from the list dropped the repeated `101` and `102`. `&` found the ids present in both sets, and `-` found those in `unique` but not `vip`. The display order is not guaranteed and should not be relied on.

## Rules and defaults

- Items must be hashable (numbers, strings, tuples of hashables); a list cannot be a set item.
- Duplicates are removed automatically; order is not guaranteed and there is no indexing.
- `{}` is an empty dict; an empty set is `set()`.
- A `frozenset` is immutable and hashable, so it can be a dict key or an item of another set.

## Common mistakes

- **Using `{}` for an empty set.** That makes an empty dict. Use `set()`.
- **Expecting order or indexing.** Sets have neither; convert to a `sorted(list)` if you need order.
- **Adding an unhashable item.** `s.add([1, 2])` raises `TypeError`; use a tuple instead.

## Interview Qs

### How do you remove duplicates from a list?

Pass it to `set()`: `set(items)` keeps only unique values. If you need the original order back, use `list(dict.fromkeys(items))`, which preserves insertion order.

### Do sets keep order?

No. A set has no insertion-order guarantee and no indexing, unlike a list or a dict. If you need order, sort the set into a list.

### What is the difference between a set and a frozenset?

A `set` is mutable: you can add and remove items. A `frozenset` is immutable and therefore hashable, so it can be used as a dictionary key or stored inside another set.
