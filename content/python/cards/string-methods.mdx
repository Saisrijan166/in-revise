## What it is

String methods are built-in functions you call on a [string](card:strings), like `"Pen".upper()`. They cover changing case, trimming, searching, splitting and testing characters. Because strings are immutable, every method that changes text returns a new string and leaves the original unchanged.

## Why it exists

Reading and cleaning text is everyday work: trimming spaces from form input, splitting a CSV line into fields, checking whether an order id is all digits. Methods give one tested way to do each job, so you do not loop character by character. Knowing which method raises and which returns a flag (find vs index) avoids crashes on missing input.

## How it works

| Method | Does | Note |
|---|---|---|
| `upper` / `lower` | change case | returns a new string |
| `strip` | trim both ends | pass chars to strip those instead of whitespace |
| `split` / `join` | text to list / list to text | `split()` with no arg splits on any whitespace |
| `replace` | swap all matches | `replace(old, new)` |
| `find` / `index` | position of substring | find returns -1 if missing; index raises `ValueError` |
| `count` | how many times | non-overlapping |
| `startswith` | prefix test | returns True/False |
| `isdigit` / `isalpha` | character test | False on an empty string |

1. You call the method on the string.
2. A search or test returns a number or a boolean; a text change returns a new string.
3. You keep the result; the original string is untouched.

## Example

```python
line = "  pen, ink, pad  "
items = line.strip().split(", ")
print(items)
print(" | ".join(items))
print(line.find("ink"), line.replace("pad", "pencil").strip())
```

```text output
['pen', 'ink', 'pad']
pen | ink | pad
7 pen, ink, pencil
```

What to notice: `strip()` first removes the outer spaces, then `split(", ")` makes a list. `join` rebuilds text from that list. `find("ink")` gives the index 7; `replace` makes a new string, which is why we strip it again. The original `line` still has its spaces.

## Rules and defaults

- Methods return a new value; they never mutate the string (it is immutable).
- `split()` with no argument splits on runs of any whitespace and drops empty parts.
- `find` returns `-1` when the substring is absent; `index` raises `ValueError`.
- `isdigit`, `isalpha` and friends return `False` for an empty string.

## Common mistakes

- **Expecting the string to change.** `s.strip()` alone does nothing lasting; you must assign `s = s.strip()`.
- **Using `index` on maybe-missing text.** It raises `ValueError`. Use `find` or `in` first.
- **Assuming `isdigit` accepts a minus sign or decimal point.** `"-5".isdigit()` and `"3.5".isdigit()` are both `False`.

## Interview Qs

### What is the difference between find and index?

Both return the position of a substring. When the substring is not found, `find` returns `-1`, while `index` raises `ValueError`. Use `find` (or the `in` operator) when the text may be missing.

### How do you turn a comma-separated line into a list and back?

`line.split(",")` splits the text into a list of fields. `",".join(parts)` joins a list of strings back into one string using the comma as a separator.

### Do string methods change the original string?

No. Strings are immutable, so methods like `upper`, `strip` and `replace` return a new string. You must store the result; the original stays the same.
