## What it is

Unpacking spreads the items of an iterable into separate variables in one assignment: `a, b, c = [1, 2, 3]`. A starred target, `first, *rest = xs`, catches the leftover items in a list. The same idea powers swapping two variables (`a, b = b, a`) and spreading a collection into a function call with `*` and `**`.

## Why it exists

Data often comes grouped: a [tuple](card:tuples) returned from a function, a coordinate, a row split from a line. Pulling items out by index (`row[0]`, `row[1]`) is noisy and easy to get wrong. Unpacking names each part directly, which reads better and catches a wrong count early. Swapping and argument spreading fall out of the same mechanism, replacing temp variables and manual loops.

## How it works

<Steps>
<Step title="Plain unpack">`a, b, c = iterable` binds each item to a name; the counts must match exactly.</Step>
<Step title="Starred target">`first, *middle, last = xs` fills the fixed names and puts the rest in a list.</Step>
<Step title="Swap">`a, b = b, a` builds the tuple `(b, a)` on the right, then unpacks it, so no temp is needed.</Step>
<Step title="Spread into a call">`f(*args)` passes each item as a positional argument; `f(**kwargs)` passes each dict pair as a keyword argument.</Step>
</Steps>

## Example

```python
order = ("A1", "pen", 3, 50)
order_id, *details = order          # starred: rest in a list
qty, price = details[-2], details[-1]
qty, price = price, qty             # swap, no temp
print(order_id, details, qty, price)

def line(name, qty): return f"{qty} x {name}"
fields = {"name": "ink", "qty": 2}
print(line(**fields))               # spread dict as keyword args
```

```text output
A1 ['pen', 3, 50] 50 3
2 x ink
```

What to notice: the starred `*details` collected the three leftover items into a list. The swap `qty, price = price, qty` exchanged the values in one line with no temporary. `line(**fields)` spread the dict so each key became a keyword argument, the same as `line(name="ink", qty=2)`.

## Rules and defaults

- Counts must match exactly, or Python raises `ValueError`, unless a starred target absorbs the rest.
- At most one starred target per assignment; it always becomes a list, possibly empty.
- `a, b = b, a` works because the right-hand tuple is built fully before the assignment.
- In a call, `*` spreads an iterable into positional arguments and `**` spreads a mapping into keyword arguments.

## Common mistakes

- **Mismatched counts.** `a, b = [1, 2, 3]` raises `ValueError`. Match the count or use a star.
- **Two starred targets.** `*a, *b = xs` is a `SyntaxError`; only one is allowed.
- **Using `**` on a non-mapping.** `f(**[1, 2])` fails; `**` needs a dict-like object with string keys.

## Interview Qs

### How do you swap two variables in Python?

`a, b = b, a`. Python builds the tuple `(b, a)` from the right side first, then unpacks it into `a` and `b`, so no temporary variable is needed.

### What does `first, *rest = [1, 2, 3, 4]` do?

It binds `first` to `1` and `rest` to the list `[2, 3, 4]`. The starred target collects all remaining items into a list; it would be an empty list if there were none.

### What do `*` and `**` do in a function call?

`*iterable` spreads the items as positional arguments, so `f(*[1, 2])` is `f(1, 2)`. `**mapping` spreads a dict as keyword arguments, so `f(**{"x": 1})` is `f(x=1)`.
