## What it is

These keywords steer a [loop](card:loops). `break` stops the nearest loop right away. `continue` skips the rest of the current pass and jumps to the next item. `pass` does nothing at all; it fills a spot where Python's syntax needs a statement but you have none yet. A loop can also carry an `else` clause, which runs only when the loop ends without a `break`.

## Why it exists

You often want to stop early (you found what you were searching for), skip some items (ignore invalid rows), or leave a block empty for now. `break`, `continue` and `pass` handle those cleanly without extra flags. The loop `else` answers a common question in one place: did the loop run to the end without stopping early? That is exactly the "searched everything and found nothing" case.

## How it works

<Steps>
  <Step title="break">Leaves the nearest loop at once; its else clause is skipped.</Step>
  <Step title="continue">Abandons the current pass and tests the next item or condition.</Step>
  <Step title="pass">Executes nothing and moves on; used as a placeholder.</Step>
  <Step title="else">Runs after the loop only if no break fired, including when the iterable was empty.</Step>
</Steps>

## Example

```python
orders = [("a", True), ("b", False), ("c", True)]
for name, paid in orders:
    if not paid:
        print("unpaid:", name)
        break
else:
    print("all paid")
```

```text output
unpaid: b
```

What to notice: the loop hits an unpaid order `b`, prints it, and `break` exits. Because a `break` fired, the `else` is skipped, so `"all paid"` does not print. If every order were paid, the loop would finish normally and the `else` would run.

## Rules and defaults

| What | Behaviour | Where |
|---|---|---|
| `break` | exits the nearest loop only | Python 3+ |
| `continue` | jumps to the next iteration | Python 3+ |
| `pass` | no operation; placeholder | Python 3+ |
| loop `else` | runs only if no `break` occurred | Python 3+ |

## Common mistakes

- Reading loop `else` as "if the body did not run". It runs when the loop ends without `break`, even for an empty iterable.
- Expecting `break` to exit all nested loops. It exits only the innermost one.
- Using `pass` where you meant `continue`. `pass` does nothing and falls through; `continue` skips to the next item.

## Interview Qs

### What is the difference between break and continue?

`break` stops the nearest loop entirely and moves on after it. `continue` only ends the current iteration and goes to the next item or condition test. The loop keeps running after a `continue`, not after a `break`.

### When does the else clause of a loop run?

It runs when the loop finishes normally, that is, without executing a `break`. A loop over an empty iterable still runs its `else`. It is useful for "searched all items and found no match" logic.

### What does pass do and when is it used?

`pass` is a statement that does nothing. It is a placeholder where syntax requires a statement, such as an empty function, class, or an `if` branch you have not written yet, so the code is valid without any behaviour.
