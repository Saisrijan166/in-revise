## What it is

A loop repeats a block of code. A `for` loop walks through an iterable (a list, string, dict, `range`, file and more), giving you one item each pass. A `while` loop repeats as long as its condition stays truthy, re-checking before every pass. Loops can be nested: a loop placed inside another runs its whole cycle on each pass of the outer one.

## Why it exists

You often need to do the same work for every item, or keep going until something changes. Totalling a list of orders, reading lines from a file, or retrying until a server answers are all repetition. `for` handles "do this for each item", and `while` handles "keep doing this until a condition is met", so you do not copy the same lines by hand.

## How it works

<Steps>
  <Step title="for: get an iterator">Python creates an iterator from the iterable and pulls items one by one until it is exhausted.</Step>
  <Step title="while: test first">The condition is checked before each pass; if it is falsy at the start, the body never runs.</Step>
  <Step title="Body runs">The block executes with the current item (for) or current state (while).</Step>
  <Step title="Repeat or stop">for stops when items run out; while stops when the condition turns falsy.</Step>
</Steps>

## Example

```python
orders = [12, 40, 9]
total = 0
for amount in orders:      # for: walk each item
    total += amount
n = 3
while n > 0:               # while: repeat until condition fails
    n -= 1
print(total, n)
```

```text output
61 0
```

What to notice: the `for` loop takes each amount without any index and adds it to `total`, giving `61`. The `while` loop runs while `n > 0`, lowering `n` each pass until it reaches `0` and the condition turns falsy, so the loop ends cleanly.

## Rules and defaults

| What | Behaviour | Where |
|---|---|---|
| `for` source | any iterable | Python 3+ |
| `while` check | before each pass | Python 3+ |
| Empty iterable / false condition | body runs zero times | Python 3+ |
| `while True:` | runs forever unless `break` | Python 3+ |

## Common mistakes

- Using `for i in range(len(x))` just to read items. Iterate `for item in x:` directly.
- A `while` condition that never changes, causing an infinite loop.
- Modifying a list while iterating over it with `for`, which can skip items; iterate a copy instead.

## Interview Qs

### When do you use a for loop versus a while loop?

Use `for` when you iterate a known collection of items (a list, range, file). Use `while` when you repeat until a condition changes and you do not know the count in advance, such as retrying until success.

### What can a Python for loop iterate over?

Any iterable: lists, tuples, strings (character by character), dicts (keys by default), sets, `range`, files (line by line), and generators. Python creates an iterator from it and pulls items until exhausted.

### How do you avoid an infinite while loop?

Make sure the loop body changes something that eventually makes the condition false, or include a `break` that fires on a stopping condition. `while True:` without a `break` never ends.
