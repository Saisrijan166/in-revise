## What it is

A conditional runs a block only when a condition holds. `if` tests a condition; `elif` tests the next one if the earlier ones failed; `else` runs when none matched. The condition can be any value, not only `True`/`False`, because Python decides each value's truthiness. There is also a one-line form, the ternary `a if cond else b`.

## Why it exists

Programs must take different paths: charge a discount for large orders, warn on empty input, reject invalid data. `if`/`elif`/`else` expresses that branching in plain words. Truthiness makes the common checks short: `if orders:` already means "if there are any orders", so you rarely need to compare against an empty list or zero by hand.

## How it works

1. Python evaluates the `if` condition; if it is truthy, that block runs and the rest are skipped.
2. Otherwise each `elif` is tested in order; the first truthy one runs.
3. If none match, the `else` block runs (if present).
4. Truthiness decides each test: `0`, `0.0`, `''`, `[]`, `{}`, `()`, `set()`, `None` and `False` are falsy; everything else is truthy.

## Example

```python
orders = [12, 40]
total = sum(orders)
if not orders:
    label = "no orders"
elif total > 50:
    label = "big"
else:
    label = "small"
status = "empty" if not orders else "ok"
print(label, status)
```

```text output
big ok
```

What to notice: `not orders` is `False` because the list is non-empty, so the `if` is skipped. `total` is `52`, so the `elif` matches and `label` becomes `"big"`. The ternary gives `status` the value `"ok"` in one line without a full block.

## Rules and defaults

| What | Behaviour | Where |
|---|---|---|
| Branch chosen | first truthy condition only | Python 3+ |
| Falsy values | `0`, `0.0`, `''`, `[]`, `{}`, `()`, `set()`, `None`, `False` | Python 3+ |
| Custom truthiness | from `__bool__` or `__len__` | Python 3+ |
| Ternary | `a if cond else b` | Python 3+ |

## Common mistakes

- `if items == []:` or `if len(items) > 0:` where `if items:` or `if not items:` is clearer.
- Treating a valid `0` as "missing". `if qty:` skips a real zero; use `if qty is not None:` when zero is meaningful.
- Forgetting that only the first matching branch runs; later `elif`s are not checked.

## Interview Qs

### What values are falsy in Python?

`None`, `False`, numeric zero of any type (`0`, `0.0`, `0j`), and empty containers: `''`, `[]`, `()`, `{}`, `set()`, `range(0)`. Everything else is truthy. A class can define its own truthiness with `__bool__` or `__len__`.

### How do you check whether a list is empty?

Use `if not items:` (empty) or `if items:` (non-empty). An empty list is falsy, so this is cleaner than comparing with `[]` or checking `len(items) == 0`.

### What is the ternary (conditional) expression?

`a if cond else b` evaluates to `a` when `cond` is truthy, otherwise `b`. It is a one-line way to choose a value, for example `status = "empty" if not orders else "ok"`.
