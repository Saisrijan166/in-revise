## What it is

Copying an object in Python has three levels. Plain assignment (`b = a`) copies nothing: both names refer to one object. A shallow copy (`copy.copy(a)`, `a[:]`, `list(a)`) builds a new outer object but reuses the same nested objects inside it. A deep copy (`copy.deepcopy(a)`) builds a new outer object and recursively copies every nested object, so the result shares nothing with the original. The difference only matters when the data is nested, like a list of lists.

## Why it exists

You often need an independent copy so edits to one do not affect the other. For flat data a shallow copy is enough and cheap. But when objects are nested, a shallow copy still shares the inner objects, so a change to a nested list leaks back to the original, a classic bug. `copy.deepcopy` exists to give true independence for nested structures, and it safely handles objects that reference each other in a cycle.

## How it works

<Compare id="shallow-deep-copy" />

1. Assignment binds another name to the same object; nothing is duplicated.
2. A shallow copy duplicates the top-level container but points its slots at the original's inner objects.
3. A deep copy duplicates the container and, recursively, every object it contains.

## Example

```python
import copy
a = [[1, 2], [3, 4]]
shallow = copy.copy(a)
deep = copy.deepcopy(a)
a[0].append(99)          # change a nested list
print(shallow)
print(deep)
```

```text output
[[1, 2, 99], [3, 4]]
[[1, 2], [3, 4]]
```

What to notice: `shallow` shares the inner lists with `a`, so appending to `a[0]` also shows in `shallow[0]`. `deep` copied the inner lists too, so it is untouched. The outer lists differ; only the nested objects behave differently.

## Rules and defaults

- `copy.copy(x)` is shallow; `copy.deepcopy(x)` is deep (both from the `copy` module).
- `a[:]`, `list(a)`, `dict(a)` and `set(a)` are shallow copies.
- `deepcopy` tracks already-copied objects, so cycles do not cause infinite recursion.

## Common mistakes

- **Trusting list(a) for nested data.** It copies only the outer list; inner lists stay shared.
- **Using deepcopy everywhere.** It is slower; use a shallow copy when the data is flat.
- **Forgetting assignment is not a copy.** `b = a` aliases; mutating `b` changes `a`, see [variables and objects](card:variables-and-objects).

## Interview Qs

### What is the difference between a shallow and a deep copy?

A shallow copy duplicates only the outer object and shares the nested objects, so nested edits leak. A deep copy (`copy.deepcopy`) recursively duplicates every nested object, giving a fully independent copy.

### How do you make a shallow copy of a list?

Several ways: `copy.copy(a)`, `a[:]`, or `list(a)`. All create a new outer list but reuse the same inner objects, so they are equivalent for a flat list.

### When do you actually need deepcopy?

Only when the structure is nested and the copy must be independent, for example a list of lists or a dict of dicts you will edit without touching the original. For flat data a shallow copy is enough and faster.
