## What it is

Python is a high-level, general-purpose programming language. High-level means you write logic without managing memory or pointers. It is dynamically typed: a name's type is decided while the program runs, not declared ahead of time. It is also strongly typed: it never mixes types silently. It supports object-oriented, procedural and functional styles, and runs on Windows, macOS and Linux unchanged.

## Why it exists

Older languages made you declare every type and manage memory by hand, which is slow to write and easy to get wrong. Python was designed for readable, concise code that works the same across operating systems. One readable script replaces many lines of boilerplate, so it suits scripting, data work, web backends and automation. The trade-off is runtime speed, which Python accepts in exchange for developer speed.

## How it works

| Trait | What it means |
|---|---|
| High-level | No manual memory or pointers |
| Compiled then run | Source becomes bytecode, then the VM runs it |
| Dynamically typed | Type checked at runtime, not declared |
| Strongly typed | No silent type mixing |
| Cross-platform | Same code runs on any OS with Python |

1. You write `.py` source files.
2. CPython, the reference implementation, compiles each module to bytecode.
3. The virtual machine executes that bytecode and produces output. The [execution model](card:python-execution-model) covers these steps in detail.

## Rules and defaults

- Python 3 is the only supported line; Python 2 reached end of life in 2020.
- PEP 8 is the official style guide (4-space indentation, snake_case names).
- Indentation, not braces, defines blocks; inconsistent indentation is a syntax error.

## Common mistakes

- **Calling it "just interpreted".** It compiles to bytecode first; the interpreter runs that bytecode.
- **Confusing dynamic with weak typing.** Python is dynamic but strongly typed; see [dynamic and strong typing](card:dynamic-and-strong-typing).
- **Writing Python 2 syntax.** `print` is a function in Python 3, so `print "hi"` is a syntax error.

## Interview Qs

### Is Python compiled or interpreted?

Both. CPython compiles the source to bytecode, then an interpreter (the virtual machine) executes that bytecode. There is no separate compile command, so people call it interpreted, but a compile step does happen.

### Is Python statically or dynamically typed?

Dynamically typed: a variable's type is bound at runtime and can change on reassignment. It is also strongly typed, so operations between incompatible types raise `TypeError` rather than converting silently.

### What does "cross-platform" mean for Python?

The same source runs on Windows, macOS and Linux without changes, because CPython provides the same bytecode and standard library on each. Only platform-specific calls (like certain OS APIs) differ.
