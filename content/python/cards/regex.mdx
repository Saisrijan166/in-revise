## What it is

A regular expression (regex) is a small pattern that describes text: `\d+` means "one or more digits". Python's built-in `re` module searches, matches and replaces text using these patterns. You usually write the pattern as a raw string (`r"..."`) so the backslashes stay literal.

## Why it exists

Checking or extracting structured text by hand (is this a valid order id? pull every number out) means fiddly loops over characters. A regex states the shape once and the engine does the scanning. It turns many lines of character-by-character code into a single pattern, which is quicker to write and easier to change.

## How it works

<Steps label="Using the re module">
  <Step title="Write the pattern">A raw string like r"\d+" so \d is not read as an escape.</Step>
  <Step title="Pick the function">match (start), search (anywhere), findall (all), sub (replace).</Step>
  <Step title="Read the result">match and search return a match object or None; findall returns a list.</Step>
</Steps>

1. `re.match` and `re.search` return a match object; call `.group()` to get the text, or `None` if there is no match.
2. `re.findall` returns every non-overlapping match as a list of strings.
3. `re.compile(pattern)` builds a reusable pattern object when you use it many times.

## Example

```python
import re

text = "order 42 shipped, order 7 pending"
print(re.search(r"\d+", text).group())   # first number anywhere
print(re.findall(r"\d+", text))          # every number
print(re.sub(r"\d+", "#", text))         # mask the numbers
print(re.match(r"\d+", text))            # starts with 'order', not a digit
```

```text output
42
['42', '7']
order # shipped, order # pending
None
```

What to notice: `search` finds the first number although it is not at the start, `findall` returns both as a list of strings, and `sub` replaces each. `match` returns `None` because the string starts with letters, not a digit.

## Rules and defaults

| What | Behaviour | Note |
|---|---|---|
| Pattern string | Prefer raw `r"..."` | Python 3.14 warns on invalid escapes in normal strings |
| `match` | Anchors at start only | Returns None if match is later |
| `findall` | All non-overlapping matches | Returns a list, not a match object |
| Reuse | `re.compile(pattern)` | Compile once, use many times |

## Common mistakes

- **Forgetting the raw string.** `"\d+"` can be read as an escape; Python 3.14 emits a warning. Use `r"\d+"`.
- **Calling .group() on None.** When there is no match the function returns None; check before calling .group().
- **Using match when you mean search.** match only looks at the start.

## Interview Qs

### What is the difference between re.match and re.search?

`re.match` tries to match only at the start of the string and returns None if the pattern is not there. `re.search` scans the whole string and returns the first match anywhere. For "find it somewhere", use search.

### Why write regex patterns as raw strings?

In a normal string `\d` could be read as an escape sequence, and Python 3.14 warns about invalid ones. A raw string `r"\d+"` keeps the backslash literal, so the regex engine sees the pattern you intended.

### What does re.findall return?

A list of all non-overlapping matches as strings. If the pattern has groups, it returns the groups instead. It never returns a match object, unlike match and search.
