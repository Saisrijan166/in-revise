## What it is

Python has a set of built-in types you use without importing anything. Numbers come as `int`, `float` and `complex`. `bool` holds `True` or `False`. `str` holds text. The containers are `list`, `tuple`, `set`, `frozenset` and `dict`. `NoneType` has one value, `None`, meaning "no value". `range` is a lazy sequence of integers, and `bytes` holds raw binary data. Each type decides what values it can hold and what operations it supports.

## Why it exists

Different data needs different structures: an ordered changeable sequence (list), a fixed record (tuple), unique items (set), key-to-value lookup (dict), or raw bytes. Having these built in, with clear mutability rules, means you pick the right tool instead of building one. Arbitrary-precision ints and a dedicated `None` value remove two common sources of bugs: integer overflow and using `0` to mean "missing".

## How it works

| Type | Meaning | Example |
|---|---|---|
| `int` | Whole number, unbounded | `42`, `2 ** 100` |
| `float` | Decimal number | `3.5` |
| `complex` | Real + imaginary | `2 + 3j` |
| `bool` | Truth value (an int) | `True`, `False` |
| `str` | Text (immutable) | `"apple"` |
| `list` | Ordered, mutable | `[1, 2, 3]` |
| `tuple` | Ordered, immutable | `(1, 2)` |
| `set` / `frozenset` | Unique items | `{1, 2}` |
| `dict` | Key to value | `{"qty": 2}` |
| `NoneType` | No value | `None` |
| `range` | Lazy int sequence | `range(5)` |
| `bytes` | Raw binary | `b"hi"` |

1. A literal creates an object of the matching type.
2. `type(x)` reports the type; `int()`, `str()`, `float()`, `bool()` convert.
3. Mutability depends on the type: list, set and dict change in place; others do not.

## Example

```python
qty = int("3")          # str to int
price = float("9.5")
total = qty * price
flag = bool(total)      # any non-zero number is True
print(total, flag, 2 ** 100)
```

```text output
28.5 True 1267650600228229401496703205376
```

What to notice: `int()` and `float()` convert the strings so arithmetic works. `bool(28.5)` is `True` because any non-zero number is truthy. `2 ** 100` is computed exactly, since Python ints have no fixed width.

## Rules and defaults

- `int` has arbitrary precision; it grows until memory runs out, never overflows.
- `bool` is a subclass of `int`: `True == 1`, `False == 0`, `True + True == 2`.
- `None` is a singleton; compare with `is None`, not `== None`.
- Conversion is explicit: `int("x")` on bad text raises `ValueError`.

## Common mistakes

- **Expecting int overflow.** Python ints never wrap; they grow.
- **Using 0 or "" instead of None.** Use `None` for "no value" and test with `is None`.
- **Thinking bool is separate from int.** It is a subclass, so booleans behave as 1 and 0 in arithmetic.

## Interview Qs

### Does a Python int overflow?

No. `int` has arbitrary precision and grows to fit the value, so `2 ** 100` is exact. Only available memory limits the size, unlike fixed-width integers in C or Java.

### Is bool a separate type from int?

`bool` is a subclass of `int`. `True` equals `1` and `False` equals `0`, so `True + True` is `2` and a boolean can be used anywhere an int is expected.

### How do you convert between types?

Explicitly, with the type constructors: `int("42")`, `float("3.5")`, `str(42)`, `list("ab")`. Bad input raises `ValueError`. Python will not convert silently, because it is strongly typed.
