## What it is

A set of the number problems that come up in coding rounds: computing a **factorial** (n! = 1·2·...·n), generating the **Fibonacci** sequence, checking whether a number is **prime**, testing even or odd, and finding a **missing number** in a run of integers. Each has a short, idiomatic Python form.

## Why it exists

These show whether you know Python's integer tools and a couple of small optimisations, like stopping a prime check at the square root. They also test tuple assignment (`a, b = b, a+b`) and the difference between `/` (always float) and `//` (integer floor division), which interviewers probe because Java has no `//`.

## How it works

<Steps label="The common number moves">
  <Step title="Factorial">Multiply 1 through n in a loop, or call math.factorial.</Step>
  <Step title="Fibonacci">Keep two numbers and roll them forward with one assignment.</Step>
  <Step title="Prime">Reject even/small cases, then test odd divisors up to sqrt(n).</Step>
  <Step title="Missing number">Subtract the actual sum from the expected sum.</Step>
</Steps>

1. `a, b = b, a + b` updates both values at once using the old values on the right.
2. A prime's largest factor to test is `int(n**0.5) + 1`, because factors come in pairs around the square root.
3. The sum formula `n*(n+1)//2` gives the total of 1..n without a loop.

## Example

```python
n = 5
fact = 1
for i in range(2, n + 1):
    fact *= i
print(fact)                 # factorial of 5

a, b = 0, 1
seq = []
for _ in range(6):
    seq.append(a)
    a, b = b, a + b
print(seq)                  # first 6 Fibonacci numbers
```

```text output
120
[0, 1, 1, 2, 3, 5]
```

What to notice: the factorial loop just multiplies up, and `a, b = b, a + b` advances the Fibonacci pair in one line because the right side uses the old `a` and `b` before either is reassigned.

```python
def is_prime(n):
    if n < 2:
        return False
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True

print([x for x in range(2, 12) if is_prime(x)])
```

```text output
[2, 3, 5, 7, 11]
```

What to notice: the loop stops at `int(n**0.5) + 1`, not `n`, so checking 11 tries only divisors up to 3. Any factor above the square root pairs with one below it, so nothing is missed.

```python
nums = [1, 2, 4, 5]        # one number from 1..5 is missing
n = 5
print(n * (n + 1) // 2 - sum(nums))
```

```text output
3
```

What to notice: `n*(n+1)//2` is the expected sum of 1..5 (15); subtracting the actual sum (12) gives the missing number in one pass, with `//` keeping the result an integer.

## Common mistakes

- **Prime-checking up to n.** Stop at the square root; the rest is wasted.
- **Using / for integer math.** `/` always returns a float in Python 3; use `//` for whole numbers.
- **Swapping with a temp variable.** `a, b = b, a + b` is the Python way; no temp is needed.

## Interview Qs

### How do you generate Fibonacci numbers in Python?

Keep two variables and roll them forward: `a, b = 0, 1`, then `a, b = b, a + b` in a loop. The right-hand side uses the old values, so both update together without a temporary variable.

### How do you check if a number is prime efficiently?

Reject numbers below 2, then test divisors from 2 up to `int(n**0.5) + 1`. If none divides n, it is prime. You stop at the square root because any larger factor has a matching smaller one.

### What is the difference between / and // in Python 3?

`/` is true division and always returns a float (`7 / 2` is 3.5). `//` is floor division and returns the value rounded toward negative infinity (`7 // 2` is 3). Use `//` for integer results.
