## Why it exists

Once you scale out, clients need one address to call, and something must pick a server for each request while avoiding servers that are down.

## How it works

<Steps label="One request through a load balancer">
<Step title="Client calls one address">
The client knows only the load balancer's address, often found through [DNS](card:dns).
</Step>
<Step title="Skip unhealthy servers">
Servers that fail their health checks get no traffic until they pass again.
</Step>
<Step title="Pick a server">
An algorithm picks one healthy server, such as round robin or least connections.
</Step>
<Step title="Forward and reply">
The request goes to that server, and the response comes back to the client.
</Step>
</Steps>

- **Layer 4** routes by IP and port without reading the request. **Layer 7** reads HTTP, so `/api` and `/images` can go to different servers.

## Example

A tiny nginx setup. No method line means weighted round robin, the default.

```nginx
upstream backend {
    server app1.example.com weight=2;  # gets 2x the requests of app2
    server app2.example.com;
    server app3.example.com backup;    # used only if the others are down
}

server {
    listen 80;
    location / { proxy_pass http://backend; }
}
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| How a server is picked | Round robin (weighted) | nginx, AWS ALB |
| How a server is picked | Random (was round robin before 3.3) | HAProxy 3.3 and later |
| When nginx skips a server | 1 failed request within 10 s, then skipped for 10 s | nginx `max_fails`, `fail_timeout` |
| Health check timing | Every 30 s; unhealthy after 2 fails; healthy after 5 passes | AWS ALB |
| Active health checks | Only in the paid NGINX Plus | nginx |

## Interview Qs

### What does a load balancer do?

It gives clients one address, spreads requests across servers, and stops sending traffic to servers that fail health checks. That is what makes scaling out work.

### Layer 4 vs Layer 7?

Layer 4 routes by IP and port without reading the request, so it is fast and works for any TCP or UDP traffic. Layer 7 reads HTTP, so it can route by path, host, header or cookie.

### Which algorithm would you pick?

Round robin when requests and servers are similar. Least connections when request times vary. A hash of the client IP or a key when the same client must reach the same server.

### Isn't the load balancer a single point of failure?

Yes, if there is only one. Run a redundant pair (active-passive or active-active), or use a managed load balancer that runs across several availability zones.
