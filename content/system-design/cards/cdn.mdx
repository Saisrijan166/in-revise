## Why it exists

A user far from your servers waits for every round trip, and every request adds load to your origin. A CDN serves files such as images, CSS, JavaScript and video from edge servers close to the user.

## How it works

<Mermaid
  alt="CDN request flow. A user's request is routed by DNS to a nearby edge server. If the file is cached there (a hit), the edge returns it. On a miss, the edge fetches the file from the origin server or bucket, stores it for its TTL, and returns it."
  chart={`flowchart TD
  U([User request]) --> D[DNS picks a nearby edge]
  D --> E{File cached at the edge?}
  E -- hit --> R([Edge returns the file])
  E -- miss --> O[(Origin server or bucket)]
  O --> S[Edge stores it for its TTL]
  S --> R`}
/>

- The origin decides the cache time with `Cache-Control`: `max-age` for every cache, `s-maxage` for shared caches such as CDNs.
- To change a cached file early, purge it, or better, publish it under a new file name.

## Example

Two headers from the origin, as MDN recommends:

```text
# app.3f9c2b.js: the name changes whenever the content changes
Cache-Control: public, max-age=31536000, immutable

# index.html: keep it, but recheck with the origin before each use
Cache-Control: no-cache
```

On deploy, upload `app.4a1d7e.js` and point `index.html` to it. No purge is needed: nobody asks for the old name any more.

## Defaults

| What | Default | Where |
| --- | --- | --- |
| Cache time when the origin sends no `max-age` | 24 hours (86,400 s) | CloudFront default TTL |
| Longest cache time | 1 year (31,536,000 s) | CloudFront maximum TTL |
| Free invalidation paths | 1,000 a month; then paid per path (`/images/*` counts as one) | CloudFront |
| HTML and JSON | Not cached unless you add a rule | Cloudflare |

## Interview Qs

### How does a CDN work?

DNS sends the user to a nearby edge. On a hit, the edge returns the file at once. On a miss, it fetches the file from the origin, returns it, and caches it for its TTL so the next nearby user gets a hit.

### How do you update a file that the CDN has cached?

Prefer versioned file names: a new name is a new cache entry everywhere, even in browsers. A purge clears the CDN only, not browser caches. Keep it for emergencies; CloudFront charges per path after 1,000 a month.

### Push CDN or pull CDN?

Pull: the CDN fetches from your origin on the first miss; no upload step, and it suits heavy traffic. Push: you upload files to the CDN yourself; it suits large files that rarely change.

### Many edges miss the same file at once. How do you protect the origin?

Add a mid-tier cache such as CloudFront Origin Shield. Edges ask it first, and it merges identical misses into as few as one request to the origin.
