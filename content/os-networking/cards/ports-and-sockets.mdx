## Why it exists

One host runs many programs talking to many peers. Ports pick the program; sockets give each conversation its own OS handle.

## How it works

<Steps label="TCP socket calls">
  <Step title="Server: socket(), bind()">Create the endpoint; attach it to an address and port, such as 0.0.0.0:8080.</Step>
  <Step title="Server: listen()">Mark it passive; finished handshakes queue up to the backlog.</Step>
  <Step title="Client: socket(), connect()">The kernel picks an ephemeral source port and connects.</Step>
  <Step title="Server: accept()">Returns a new connected socket (fd) for that client; the listener keeps listening.</Step>
</Steps>

- A socket is a [file descriptor](card:files-and-file-descriptors). Many short outbound connections can [exhaust ephemeral ports](card:ephemeral-port-exhaustion): [pool](card:connection-pooling) them.

## Example

Example run; the ephemeral client port changes each time.

```java
import java.io.*; import java.net.*;
public class Hello {
  public static void main(String[] args) throws IOException {
    try (var server = new ServerSocket(8080);         // socket + bind + listen
         var client = new Socket("localhost", 8080);  // client: socket + connect
         var conn = server.accept()) {                // a NEW socket for this client
      conn.getOutputStream().write("hello\n".getBytes());
      var in = new BufferedReader(new InputStreamReader(client.getInputStream()));
      System.out.println(in.readLine() + " | server port " + conn.getLocalPort() + ", client port " + conn.getPort());
    }
  }
}
```

```text output
hello | server port 8080, client port 56800
```

## Interview Qs

### How can one server port serve thousands of clients?

A TCP connection is named by its 4-tuple. Each client brings a different source IP or port, so every accepted socket on 8080 is a separate connection.

### What is the difference between a port and a socket?

A port is a number in the TCP or UDP header. A socket is the OS object (an fd) a program reads and writes; a connected one is tied to one 4-tuple.

### Name some well-known ports.

22 SSH, 53 DNS, 80 HTTP, 443 HTTPS, 5432 PostgreSQL; 8080 is registered as HTTP alternate.
