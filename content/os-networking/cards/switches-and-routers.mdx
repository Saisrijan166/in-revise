## Why it exists

No single cable joins every device on Earth. Switches join devices into one local network; routers join networks into the Internet.

## How it works

<Compare id="switch-vs-router" />

- A switch learns which MAC sits behind which port from source addresses, and floods frames for unknown MACs.
- With no matching route, not even a default, a router drops the packet and returns ICMP "destination unreachable".
- Load balancers by layer: [L4 vs L7](compare:l4-vs-l7-load-balancer).

## Example

Our laptop calls the shop API at 203.0.113.5. The frame's MACs change per hop; the IPs do not, except where NAT rewrites the source.

```text
Hop                      Ethernet src -> dst       IP src -> dst
laptop -> home router    laptop -> router MAC      192.168.0.140 -> 203.0.113.5
home router (NAT)        router -> ISP MAC         198.51.100.7  -> 203.0.113.5
last router -> LB        router -> LB MAC          198.51.100.7  -> 203.0.113.5
```

## Interview Qs

### What is ARP?

Address Resolution Protocol finds the MAC for an IP on the local network. The host broadcasts "who has 192.168.0.1?", the owner replies with its MAC, and the answer is cached. IPv6 uses Neighbor Discovery instead.

### How do ping and traceroute work?

Ping sends ICMP echo requests and waits for echo replies. Traceroute sends probes with TTL 1, 2, 3 and so on; each router that drops one at zero sends back ICMP time exceeded, revealing the path.

### Packet-filter firewall vs WAF?

A packet filter allows or blocks by IP, port and protocol, often tracking connection state. A WAF works at layer 7: it reads HTTP requests and blocks patterns such as SQL injection.
