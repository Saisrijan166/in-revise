## What it is

Linux is a kernel, the core program that controls the CPU, memory, devices and running programs. By itself it is not a complete operating system. A distribution (distro) such as Ubuntu, Debian or Fedora bundles the kernel with a shell, system tools and applications so you can actually use it. See the [layers of a Linux system](card:linux-architecture).

## Why it exists

Before Linux, a free Unix-like kernel that anyone could read and change did not exist. Commercial Unix was costly and closed. In 1991 Linus Torvalds wrote a new kernel from scratch and released it under the GPL, so developers everywhere could use and improve it without paying or asking permission. That openness is why Linux now runs most servers, Android phones and cloud machines.

## How it works

<Steps>
<Step title="The kernel">Linux talks to the hardware and shares the CPU, memory and devices between programs.</Step>
<Step title="The userland">GNU tools, the shell and system libraries sit on top and give you commands and a way to run programs.</Step>
<Step title="The distribution">A distro such as Ubuntu or Fedora packages the kernel plus the userland, with a package manager to add more software.</Step>
</Steps>

1. The same Linux kernel sits under every distro.
2. Distros differ in their tools, defaults and package manager (apt vs dnf), not in the kernel.
3. "Linux" in daily speech means a distro; strictly it means just the kernel.

## Analogy

<Analogy title="Engine and car" limit="a car has one maker, but one kernel is shared by many distros">The kernel is the engine. A distribution is the whole car built around it: seats, dashboard and controls. Many car brands can share the same engine, just as Ubuntu and Fedora share the same Linux kernel.</Analogy>

## Not to be confused with

The Linux kernel is one thing; a Linux distribution is the kernel plus everything around it. Rule: the kernel is the core shared by all distros, while a distro is the complete, usable system you install.

## Common mistakes

- Calling Linux "an operating system" when strictly it is the kernel; the full OS is the distribution.
- Thinking Linux was forked from Unix source; it is an independent, from-scratch re-implementation.
- Assuming all distros are deeply different; they share one kernel and mostly differ in tools and package manager.

## Interview Qs

### What is Linux?

Linux is an open-source kernel that Linus Torvalds wrote in 1991 under GPL-2.0. It manages hardware, memory and processes. A distribution such as Ubuntu or Fedora adds the shell, tools and apps to make a complete operating system.

### What is the difference between Linux and Unix?

Unix is an older family of operating systems. Linux is Unix-like: it follows Unix design and the POSIX standard, but was written from scratch and shares no original Unix code. That is why it could be released free under the GPL.

### What is a Linux distribution?

A distribution bundles the Linux kernel with a shell, system libraries, tools and a package manager. Ubuntu and Debian use apt; Fedora and RHEL use dnf. All run the same kernel but differ in defaults and tooling.
