## What it is

These are two terminal text editors. `nano` is simple: it works like a basic notepad, and shows its shortcuts along the bottom of the screen. `vim` is a powerful modal editor, which means it has separate modes: in normal mode the keys move the cursor and run commands, and in insert mode the keys type text. You switch to insert mode with `i` and back with `Esc`. Most Linux servers have both.

## Why it exists

You often need to edit a file directly on a server, with no graphical editor available, over an SSH session. A text editor in the terminal solves this. `nano` suits a quick config tweak because nothing is hidden. `vim` is faster for heavy editing once learned, so it is everywhere and worth knowing enough to make a change and get out safely, even if it is not your daily editor.

## How it works

<Steps label="Editing in vim without getting stuck">
<Step title="vim file">Open the file. vim starts in normal mode, where letters are commands, not text.</Step>
<Step title="Press i">Enter insert mode. Now typing adds text, like a normal editor.</Step>
<Step title="Press Esc">Leave insert mode and return to normal mode.</Step>
<Step title="Type :wq or :q!">:wq saves and quits; :q! quits and discards your changes.</Step>
</Steps>

- nano is simpler: just open, type, then `Ctrl+O` to save and `Ctrl+X` to exit. The `^` on screen means the Ctrl key.
- In vim, if a keystroke does something strange, press `Esc` to get back to normal mode and start again.

## Rules and defaults

| Task | nano | vim |
|---|---|---|
| Start typing | Just type | Press `i` first |
| Save | `Ctrl+O` | `:w` (or `:wq` to also quit) |
| Quit | `Ctrl+X` | `:q` |
| Quit without saving | `Ctrl+X`, then answer No | `:q!` |

- **vim opens in normal mode:** typing there runs commands, not text.
- **`Esc` is the safety key in vim:** it always returns you to normal mode.
- **`:q!` forces quit** and throws away unsaved changes; `:wq` saves then quits.

## Common mistakes

- **Typing straight into vim.** You are in normal mode; press `i` first.
- **Being unable to quit vim.** Press `Esc`, then `:q!` to discard or `:wq` to save.
- **Expecting Ctrl+S to save.** Use nano's `Ctrl+O`, or vim's `:w`.

## Interview Qs

### How do you save and exit in vim?

Press `Esc` to make sure you are in normal mode, then type `:wq` and Enter to write the file and quit. To quit without saving, use `:q!`. To only save, use `:w`.

### What does "modal" mean in vim?

vim has modes. In normal mode the keys move the cursor and run commands; in insert mode the keys type text. You enter insert mode with `i` and leave it with `Esc`. This is why you cannot just start typing when vim opens.
