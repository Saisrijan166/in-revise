## What it is

A shell is a program that reads the commands you type, runs them and shows the output. Bash (Bourne-Again SHell) is the shell most Linux distributions use. A terminal is the window or application that displays text and passes your keystrokes to the shell. The terminal is the screen; the shell is the brain behind it.

## Why it exists

You need a way to type instructions to the computer and see results as text. Splitting this into two parts keeps each simple: the terminal only shows characters and reads keys, so it works the same for any program; the shell understands and runs commands, so it can be swapped for another shell without changing the terminal. This is why you can run bash, zsh or fish in the same terminal window.

## How it works

| Part | What it does | Example |
|---|---|---|
| Terminal | Shows text, sends your keystrokes on | GNOME Terminal, the console, an SSH session |
| Shell | Reads a command, runs it, prints the result | bash, zsh, sh |

1. You press keys; the terminal sends them to the shell.
2. The shell reads the line, finds and runs the command, and sends the output back.
3. The terminal displays that output, then the shell shows its prompt again.

## Not to be confused with

A shell is the general idea, any command interpreter; bash is one specific shell. Rule: bash is a shell, but not every shell is bash, since zsh and fish are shells too.

## Common mistakes

- Saying "open the terminal" and "open bash" as if they are the same; the terminal is the window, and bash is the shell it usually starts.
- Assuming commands behave differently because the terminal differs; command behaviour comes from the shell, not the window.

## Interview Qs

### What is the difference between a shell and a terminal?

The terminal is the window that displays text and sends your keystrokes. The shell is the program inside it that reads your commands, runs them and returns output. The terminal shows; the shell does the work.

### What is Bash?

Bash (Bourne-Again SHell) is a command interpreter and the default shell on most Linux distributions. It reads commands, runs them and also works as a scripting language. Other shells include zsh, fish and the older sh.

### Can you use a different shell?

Yes. The terminal just hosts whatever shell you run, so you can use zsh or fish instead of bash in the same window, or change your login shell with chsh. Whatever shell you run interprets your commands.
