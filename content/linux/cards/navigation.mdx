## What it is

These three commands move you around the [filesystem tree](card:filesystem-hierarchy). `pwd` ("print working directory") shows the full [absolute path](card:paths-absolute-relative) of where you are. `ls` lists the files and folders in a directory. `cd` ("change directory") moves you into another folder. With a few options, `ls` also shows file details and hidden files, so you can see exactly what sits in a folder.

## Why it exists

The shell has no window showing your location or folder contents; you must ask. `pwd` answers "where am I", which matters because [relative paths](card:paths-absolute-relative) depend on it. `ls` answers "what is here" before you act on files. `cd` is how you actually move. Options exist because the plain output hides detail: `ls` alone skips permissions and hidden files, which are often the very things you came to check.

## How it works

<Steps label="Walking into a folder">
<Step title="pwd">Print the current directory, for example /home/anita, so you know your starting point.</Step>
<Step title="ls -la">List everything here, including hidden dot-files, with permissions, owner, size and time.</Step>
<Step title="cd project">Move into a sub-folder; now pwd would show /home/anita/project.</Step>
<Step title="cd ..">Go back up one level to /home/anita.</Step>
</Steps>

- `ls -l` gives one file per line: type and permissions, link count, owner, group, size, date, name.
- `ls -a` adds hidden names (`.`, `..`, `.bashrc`); `ls -la` combines both.
- `cd` with no argument goes home; `cd -` returns to the previous directory.

## Example

```bash
pwd
ls -la
```

```text output
/home/anita/app
drwxr-xr-x 3 anita anita 4096 Nov  2 10:15 .
drwxr-xr-x 5 anita anita 4096 Nov  2 09:50 ..
-rw-r--r-- 1 anita anita  142 Nov  2 10:15 .env
-rw-r--r-- 1 anita anita 2048 Nov  2 10:14 Main.java
```

What to notice:

- `ls -la` revealed `.env`, a hidden file that plain `ls` would skip.
- Each line starts with permissions and owner; `d` at the front means a directory, `-` means a regular file. `.` is this folder and `..` is its parent.

## Rules and defaults

- **`ls` hides dot-files by default:** names starting with `.` appear only with `-a`.
- **`ls` alone is terse:** no permissions, owner or time; add `-l` for those.
- **Case matters:** `Main.java` and `main.java` are different files; `cd Docs` fails if the folder is `docs`.
- **`cd` shortcuts:** bare `cd` and `cd ~` go home; `cd -` goes to the previous directory.

## Common mistakes

- **Assuming an "empty" folder.** It may be full of hidden dot-files; check with `ls -a`.
- **Wrong case in a name.** Linux is case-sensitive, unlike default Windows, so `cd MyApp` will not find `myapp`.

## Interview Qs

### How do you see hidden files, and what makes a file hidden?

A file is hidden if its name starts with a dot, like `.bashrc` or `.git`. `ls` skips these by default; run `ls -a` to include them, or `ls -la` to also show permissions, owner, size and time.

### What does ls -l show?

One line per entry with the file type and permissions, the link count, the owner and group, the size, the last-modified time, and the name. The first character is `d` for a directory or `-` for a regular file.
