## Why it exists

Every service needs the same plumbing: an HTTP API, calls to other services, discovery, config, resilience and telemetry. Spring gives a tested choice for each.

## How it works

| Need | Spring choice |
|---|---|
| [HTTP API](card:rest-apis) | Spring Web MVC, `@RestController` |
| Call a service | `RestClient`, `WebClient`, HTTP service client ([which one](compare:restclient-vs-webclient-vs-feign)) |
| [Edge gateway](card:api-gateway) | Spring Cloud Gateway (Server Web MVC or WebFlux) |
| [Discovery](card:service-discovery) | Eureka + Spring Cloud LoadBalancer, or Kubernetes Services |
| [Config](card:configuration-management) | Spring Cloud Config, or Kubernetes ConfigMaps |
| [Circuit breaker](card:circuit-breaker) | Resilience4j through Spring Cloud CircuitBreaker |
| [Kafka](card:kafka-fundamentals) | Spring for Apache Kafka: `KafkaTemplate`, `@KafkaListener` |
| [Health, metrics, traces](card:observability) | Actuator + Micrometer |
| [Contract tests](card:testing-microservices) | Pact; Spring Cloud Contract left the release trains in 2026 |

- `@LoadBalanced` on a `RestClient.Builder` bean lets `http://payment-service` name a service, not a host.
- Annotations that matter here: `@LoadBalanced`, `@GetExchange`, `@FeignClient`, `@KafkaListener`.

## Example

```java
@Service
class PaymentClient {
    private final RestClient http;
    PaymentClient(RestClient.Builder builder) {           // Boot's pre-configured builder
        var factory = new JdkClientHttpRequestFactory();
        factory.setReadTimeout(Duration.ofSeconds(2));    // never wait forever
        http = builder.baseUrl("http://payment-service").requestFactory(factory).build();
    }
    PaymentStatus status(long orderId) {
        return http.get().uri("/payments/{id}", orderId).retrieve().body(PaymentStatus.class);
    }
}
```

## Interview Qs

### Spring Boot vs Spring Cloud?

Spring Boot builds and runs one service. Spring Cloud adds distributed-system parts on top: gateway, config, discovery, load balancing, circuit breakers. Each Cloud release train matches Boot versions.

### Which HTTP client for a new service?

`RestClient` for blocking code, often behind an HTTP service client interface; `WebClient` in reactive apps. `RestTemplate` is deprecated in Spring Framework 7.0, and OpenFeign is feature-complete.

### Do you need Eureka on Kubernetes?

Usually not. Kubernetes Services already give each service a stable name, and Spring Cloud Kubernetes plugs Spring's discovery and config into the platform.
