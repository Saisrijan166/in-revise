## Why it exists

Private tasks still call S3, SQS and Secrets Manager. Sending that through a NAT gateway costs per GB and needs an internet path you may not want.

## How it works

| | Gateway endpoint | Interface endpoint |
| --- | --- | --- |
| Services | S3, DynamoDB | most AWS services, your own and partner services |
| How | prefix-list route in route tables | ENI with a private IP and a security group |
| Cost | no charge | per hour per AZ, plus per GB |
| From on-premises or another Region | no | yes, over VPN, Direct Connect or peering |

- An endpoint policy never replaces IAM or bucket policies; every one of them must allow the call.
- Share your own service: put it behind a Network Load Balancer as an endpoint service; consumers create interface endpoints.

## Interview Qs

### Private ECS tasks read secrets from Secrets Manager. How, without internet?

Create an interface endpoint for Secrets Manager in each AZ's private subnet, turn on private DNS, and let its security group allow 443 from the tasks. The SDK call stays the same.

### Gateway or interface endpoint for S3?

Gateway: free, but only from inside that VPC. Interface: costs per hour and GB, but also works from on-premises and from other Regions.
