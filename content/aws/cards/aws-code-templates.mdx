## Why it exists

"Upload a file to S3" or "send to SQS" are common whiteboard asks. The SDK has thousands of methods, but one shape covers every service.

## How it works

Below: S3 put and get, SQS send-receive-delete, the Spring Cloud AWS way, and RDS from Spring Boot. The rest live with their service:

| Task | Template |
|---|---|
| Log in to RDS with no password | [IAM database authentication](term:iam-database-authentication): the SDK or the AWS Advanced JDBC Wrapper makes the token |
| Share a private file | [pre-signed URL](card:s3) |
| Write once by key | [conditional putItem](card:dynamodb) |
| Encrypt with your key | [SSE-KMS upload](card:kms-and-encryption) |
| Run on a queue message | [Lambda handler](card:lambda) |
| Timeouts, credentials | [client setup](card:aws-sdk-for-java) |

## Example

```java
S3Client s3 = S3Client.builder().region(Region.AP_SOUTH_1).build();     // 1. client, once

PutObjectRequest put = PutObjectRequest.builder()                       // 2. request
        .bucket("payment-receipts").key("receipts/pay_123.txt").build();
s3.putObject(put, RequestBody.fromString("Paid INR 500 for pay_123"));  // 3. call

GetObjectRequest get = GetObjectRequest.builder()
        .bucket("payment-receipts").key("receipts/pay_123.txt").build();
String receipt = s3.getObjectAsBytes(get).asUtf8String();
System.out.println(receipt);
```

```text output
Paid INR 500 for pay_123
```

```java
SqsClient sqs = SqsClient.builder().region(Region.AP_SOUTH_1).build();
String url = sqs.getQueueUrl(b -> b.queueName("receipt-jobs")).queueUrl();

sqs.sendMessage(b -> b.queueUrl(url).messageBody("pay_123"));          // producer

ReceiveMessageRequest receive = ReceiveMessageRequest.builder().queueUrl(url)
        .waitTimeSeconds(20).maxNumberOfMessages(10).build();         // long polling
for (Message m : sqs.receiveMessage(receive).messages()) {
    System.out.println("Making receipt for " + m.body());             // keep it idempotent
    sqs.deleteMessage(b -> b.queueUrl(url).receiptHandle(m.receiptHandle())); // done
}
```

```text output
Making receipt for pay_123
```

```java
@Service
class ReceiptService {
    private final S3Template s3;
    private final SqsTemplate sqs;
    ReceiptService(S3Template s3, SqsTemplate sqs) { this.s3 = s3; this.sqs = sqs; }
    void save(String paymentId, InputStream pdf) {
        s3.upload("payment-receipts", "receipts/" + paymentId + ".pdf", pdf);
        sqs.send("receipt-jobs", paymentId);                  // queue name or URL
    }
    @SqsListener("receipt-jobs")                              // deleted only on success
    void onJob(String paymentId) { System.out.println("Making receipt for " + paymentId); }
}
```


## Interview Qs

### How do you upload a file to S3 from Spring Boot?

Inject one shared `S3Client` (or `S3Template`), build a `PutObjectRequest` with bucket and key, and call `putObject` with a `RequestBody`. No keys in code: the default chain finds the role.

### Do you need the AWS SDK to use RDS from Java?

No. The app talks to the database through JDBC and JPA like any PostgreSQL or MySQL. The SDK only manages the instance, or fetches its secret or IAM token.

### When does @SqsListener delete a message?

Its default acknowledgement mode is ON_SUCCESS: after the method returns without an exception, the message is acknowledged, which in SQS means deleted. If it throws, the message reappears after the visibility timeout.
