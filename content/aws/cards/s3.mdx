## Why it exists

Apps need cheap, durable storage for any number of files, without running disks.

## How it works

| Feature | What it does |
|---|---|
| Versioning | keeps every version; a delete only adds a delete marker |
| Lifecycle rule | after N days, moves objects to a cheaper class or deletes them |
| Pre-signed URL | a time-limited link acting with the signer's permissions |
| Event notification | on upload or delete, tells SQS, SNS, Lambda or EventBridge |
| Multipart upload | parallel parts; advised from 100 MB, needed above 5 GB |

- Bucket policies are resource-based: [how they are evaluated](card:iam-policy-evaluation).
- New uploads get SSE-S3 encryption (since 05-01-2023); see [KMS](card:kms-and-encryption).

## Example

```java
try (S3Presigner presigner = S3Presigner.create()) {
    var get = GetObjectRequest.builder()
            .bucket("payments-receipts")
            .key("receipts/2026/10/pay_123.pdf").build();
    var req = GetObjectPresignRequest.builder()
            .signatureDuration(Duration.ofMinutes(10))
            .getObjectRequest(get).build();
    String url = presigner.presignGetObject(req).url().toString();
}
```

## Defaults

| What | Default | Where |
|---|---|---|
| Storage class on upload | S3 Standard | S3, as of 20-10-2026 |
| Pre-signed URL longest life | 7 days (SDK, CLI); 12 hours (console) | S3 |
| Largest object | 50 TB, by multipart (single PUT: 5 GB) | S3, since 02-12-2025 |

## Interview Qs

### What are the S3 storage classes?

Standard for hot data, Intelligent-Tiering for unknown access, Standard-IA and One Zone-IA for monthly reads, three Glacier classes for archives. Cheaper storage adds retrieval fees or minimum days.

### How does a customer download a private receipt?

The backend checks the user, then signs a short-lived pre-signed GET URL for that key. Whoever holds it can use it until expiry.

### How do you upload a file larger than 5 GB?

Multipart upload: up to 10,000 parts of 5 MiB to 5 GiB, sent in parallel. A lifecycle rule should abort unfinished uploads, whose parts are billed.
