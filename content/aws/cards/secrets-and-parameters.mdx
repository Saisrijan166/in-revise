## Why it exists

A password in code, an image or a config file leaks to everyone who can read them, and it never changes. A managed store controls access with IAM and can rotate it.

## Interview Qs

### Secrets Manager or Parameter Store for a database password?

Secrets Manager: it rotates the password on a schedule (managed rotation for RDS and Aurora) and keeps versions. A SecureString parameter can hold it, but has no built-in rotation, so keep Parameter Store for config.

### How does a Spring Boot app on ECS get its database password?

Either the task definition's `secrets` field injects it as an environment variable at start, or Spring Cloud AWS loads it with `spring.config.import`. The execution role (first case) or task role (second) needs `secretsmanager:GetSecretValue`.
