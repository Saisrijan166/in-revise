## Why it exists

Scanning right from every item for the next bigger one is O(n²). A stack keeps only the items still waiting for an answer.

## How it works

Next greater element of `[2, 1, 5, 3, 6]`:

| Read | Popped (answer = value read) | Stack after |
|---|---|---|
| 2 | none | 2 |
| 1 | none | 2, 1 |
| 5 | 1, 2 | 5 |
| 3 | none | 5, 3 |
| 6 | 3, 5 | 6 |

- Indices left on the stack at the end get -1.
- [Monotonic deque](card:monotonic-queue): also drop the front index once it leaves the window.

## Example

```java
int[] nextGreater(int[] nums) {
    int[] ans = new int[nums.length];
    Arrays.fill(ans, -1);
    Deque<Integer> stack = new ArrayDeque<>();      // indices; values decreasing
    for (int i = 0; i < nums.length; i++) {
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i])
            ans[stack.pop()] = nums[i];             // i answers the popped index
        stack.push(i);
    }
    return ans;
}
```

## Interview Qs

### How does it solve Largest Rectangle in Histogram?

Keep bar indices with increasing heights. When a bar pops, the current index and the new top bound its widest span: area = height × width. O(n).

### How do you get every window maximum in O(n)?

Keep a deque of indices with decreasing values: pop smaller values from the back, drop the front once it leaves the window. The front is the maximum. O(n) time, O(k) space.
