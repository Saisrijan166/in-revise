## What it is

A monotonic stack is a [stack](card:stack) whose values stay in one order: from bottom to top they only decrease, or only increase. It holds the items that are still waiting for their answer, such as "the next item to my right that is bigger than me". When a new item arrives, it pops every waiting item it beats and becomes their answer. Then it waits on the stack itself.

## Why it exists

The brute force for "next greater element" scans to the right from every item until it finds a bigger one: O(n²) for a decreasing array. But once an item finds its answer, nobody needs it again. A stack of only the unanswered items, in order, lets each new item answer several of them at once, so the whole job is one pass.

## How it works

Next greater element of `[2, 1, 5, 3, 6]`:

| Read | Pops (they get the value read) | Stack after, bottom to top |
|---|---|---|
| 2 | none | 2 |
| 1 | none, 1 is smaller than 2 | 2, 1 |
| 5 | 1, then 2 | 5 |
| 3 | none | 5, 3 |
| 6 | 3, then 5 | 6 |

1. Scan the items from left to right.
2. While the stack is not empty and its top is smaller than the current item, pop the top and record the current item as its answer.
3. Push the current item. The stack still decreases from bottom to top, because everything smaller was just popped.
4. At the end, items left on the stack have no greater item to their right; their answer is -1 (or 0 days).

So the key is that the current item answers everyone it pops. The result here is `[5, 5, 6, 6, -1]`.

## Example

Daily Temperatures asks, for each day, how many days you wait for a warmer one. The stack stores indices, so the distance is one subtraction.

```java
int[] dailyTemperatures(int[] temps) {
    int[] ans = new int[temps.length];            // 0 = no warmer day ahead
    Deque<Integer> stack = new ArrayDeque<>();    // indices of days still waiting
    for (int i = 0; i < temps.length; i++) {
        while (!stack.isEmpty() && temps[stack.peek()] < temps[i]) {
            int day = stack.pop();                // day i is warmer than this day
            ans[day] = i - day;                   // distance, thanks to the index
        }
        stack.push(i);
    }
    return ans;
}

int[] t = {73, 74, 75, 71, 69, 72, 76, 73};
System.out.println(Arrays.toString(dailyTemperatures(t)));
```

```text output
[1, 1, 4, 2, 1, 1, 0, 0]
```

What to notice:

- The stack holds indices, and `temps[stack.peek()]` reads the value. Storing values instead would lose the day number, and so the distance.
- `<` pops only strictly colder days. Change it to `<=` and a day with the same temperature would count as warmer, which the problem does not allow.
- The last two days stay on the stack and keep the default 0: no warmer day follows them.

## Rules and defaults

- **Order:** values decreasing from bottom to top find the next greater item; increasing finds the next smaller item.
- **Previous instead of next:** the answer for the current item is whatever is left on top after the pops, which is the nearest earlier item that it did not beat.
- **In Java:** use `Deque<Integer>` with `ArrayDeque`, as for any [stack](card:stack); `push`, `pop` and `peek` work on the same end.
- **Window maximum:** a [monotonic deque](card:monotonic-queue) applies the same idea to a sliding window, and also removes the front index once it leaves the window.

## Interview Qs

### How does a monotonic stack solve Largest Rectangle in Histogram?

Keep bar indices with increasing heights. When a lower bar arrives, it pops taller bars; for each popped bar, the current index and the new top are the first lower bars on its right and left, so they bound its widest rectangle: height × width. Each bar is popped once, so it is O(n).

### How do you get the maximum of every window of size k in O(n)?

Keep a deque of indices whose values decrease from front to back. Pop smaller values from the back before adding a new index, and remove the front once it falls out of the window. The front is always the window's maximum. O(n) time and O(k) space.
