## What it is

A prefix sum array stores running totals. `pre[i]` is the sum of the first `i` items of `nums`, so `pre[0] = 0` (no items) and each next entry adds one more item. The sum of any contiguous range is then the difference of two entries. Combined with a [HashMap](card:hashmap-hashset), the same running total also counts subarrays with a given sum, even when a [sliding window](card:sliding-window) cannot.

## Why it exists

If you answer "what is the sum from index a to b?" with a loop, each question costs O(n), so q questions cost O(n × q). The same additions are repeated in every question. Prefix sums do those additions once, in O(n), and every later question costs O(1). For counting subarrays with sum k, they also avoid the O(n²) check of every start and end.

## How it works

Running total of the running example `nums = [2, 7, 11, 15]`:

| i | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| nums[i] | 2 | 7 | 11 | 15 | |
| pre[i] (sum of the first i items) | 0 | 2 | 9 | 20 | 35 |

1. Make `pre` one slot longer than `nums` and leave `pre[0] = 0`.
2. Walk the array once: `pre[i + 1] = pre[i] + nums[i]`.
3. To get the sum of indices a to b, take everything up to b, `pre[b + 1]`, and remove everything before a, `pre[a]`.
4. For indices 1 to 2: `pre[3] - pre[1] = 20 - 2 = 18`, which is 7 + 11.

So the key is subtraction: a range sum is "total up to the end" minus "total before the start".

## Example

Subarray Sum Equals K counts the contiguous subarrays whose sum is k. Here `nums = [2, 7, -7, 9]` and k = 9, with a negative number that would break a sliding window.

```java
int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> seen = new HashMap<>();    // prefix sum -> how many times
    seen.put(0, 1);                                  // the empty prefix
    int sum = 0, count = 0;
    for (int x : nums) {
        sum += x;                                    // running total up to x
        count += seen.getOrDefault(sum - k, 0);      // earlier prefixes that leave k
        seen.merge(sum, 1, Integer::sum);            // record this prefix
    }
    return count;
}

System.out.println(subarraySum(new int[] {2, 7, -7, 9}, 9));
```

```text output
3
```

What to notice:

- A subarray ending here has sum k exactly when an earlier running total equals `sum - k`, because the subarray's sum is "now" minus "then". So the code counts those earlier totals.
- The three subarrays are `[2, 7]`, `[7, -7, 9]` and `[9]`. The running totals are 2, 9, 2, 11, and the last step finds the total 2 twice, so it adds 2.
- Remove `seen.put(0, 1)` and `[2, 7]`, which starts at index 0, is missed: the method returns 2.

## Rules and defaults

- **Use it when:** the array does not change and you need many range sums, or you must count or find subarrays with a target sum and the numbers can be negative.
- **Size n + 1:** the extra `pre[0] = 0` makes a range that starts at index 0 work with the same formula, `pre[b + 1] - pre[0]`.
- **Updates:** changing one item changes every later prefix, O(n) per update. For many updates, a Fenwick tree (binary indexed tree) is the usual tool.
- **Related shapes:** a [2D prefix sum](card:prefix-sum-2d) gives any rectangle's sum from four stored corners; a [difference array](card:difference-array) adds a value to a whole range by changing two cells; [Product of Array Except Self](card:product-except-self) multiplies a prefix product by a suffix product.

## Common mistakes

- **"Use int for the running total."** With many large values the total can overflow an int; use long when the sum can pass about 2.1 billion.

## Interview Qs

### Why does the prefix array have n + 1 slots?

`pre[0] = 0` stands for the empty prefix. Then a range that starts at index 0 needs no special case: `sum(0..b) = pre[b + 1] - pre[0]`. With only n slots you would need an if for that case.

### Count subarrays with sum k when the numbers can be negative. How?

Keep a running sum and a HashMap from each prefix sum to how often it occurred, starting with 0 → 1. At each step add the count of `sum - k`, then record `sum`. O(n) average time and O(n) space, and the sign of the numbers does not matter.

### How do you get the product of all other items without division?

Product of Array Except Self: the answer at i is the product of everything to its left times everything to its right. Fill the answers with left products in one pass, then multiply by right products in a second pass from the end. O(n) time.
