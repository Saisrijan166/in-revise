## Why it exists

Roads, friendships, flights and task dependencies are links between things. A list or a tree cannot hold links in every direction; a graph can.

## How it works

<Compare id="adjacency-list-vs-matrix" />

- Dense means close to V² edges; sparse means far fewer.
- Interviews usually hand you an edge list or a grid. Build adjacency lists from the edge list; for grids see [grid traversal](card:grid-traversal).

## Example

```java
// n vertices, edges like {{0, 1}, {1, 2}}
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
for (int[] e : edges) {
    graph.get(e[0]).add(e[1]);
    graph.get(e[1]).add(e[0]);   // drop this line for a directed graph
}
```

## Interview Qs

### Adjacency list or adjacency matrix?

A list uses O(V + E) space and loops over real neighbours, so it suits sparse graphs and most problems. A matrix uses O(V²) space but answers "is u linked to v?" in O(1); use it for dense graphs.

### What is a connected component?

In an undirected graph, a group of vertices that all reach each other and that no outside vertex links into. A graph that is not connected splits into several components. Count them with [DFS](card:dfs) or [union-find](card:union-find).
