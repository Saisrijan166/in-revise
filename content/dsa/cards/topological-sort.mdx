## Why it exists

Courses need prerequisites, builds need their dependencies first. You need one order that respects every "A before B" rule, or proof that none exists.

## How it works

<Steps label="Kahn's algorithm">
  <Step title="Count">Find the in-degree of every vertex.</Step>
  <Step title="Seed">Queue every vertex with in-degree 0 (no prerequisites).</Step>
  <Step title="Peel">Remove one, add it to the order, and lower its neighbours' in-degree; queue any that reach 0.</Step>
  <Step title="Check">Fewer than V in the order means a cycle.</Step>
</Steps>

- An edge `u → v` means u must come before v, so point edges from prerequisite to dependant.

## Example

```java
int[] indegree = new int[n];
for (int u = 0; u < n; u++) for (int v : graph.get(u)) indegree[v]++;
Deque<Integer> queue = new ArrayDeque<>();
for (int u = 0; u < n; u++) if (indegree[u] == 0) queue.offer(u);
List<Integer> order = new ArrayList<>();
while (!queue.isEmpty()) {
    int u = queue.poll();
    order.add(u);
    for (int v : graph.get(u)) if (--indegree[v] == 0) queue.offer(v);
}
return order.size() == n ? order : List.of();   // empty: there is a cycle
```

## Interview Qs

### Course Schedule: can you finish all courses?

Build edges prerequisite → course and run Kahn's algorithm. If every course comes out, yes; if some never reach in-degree 0, they sit on a cycle, so no. O(V + E).

### Kahn's algorithm or DFS?

Both are O(V + E). Kahn's is iterative and shows a cycle when the output is short. DFS reverses the finish order and needs grey/black colours to catch a cycle.
