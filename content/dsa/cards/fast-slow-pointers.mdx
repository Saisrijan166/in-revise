## Why it exists

Marking visited nodes in a set finds a cycle but costs O(n) memory. Two pointers at different speeds find it with O(1) memory.

## How it works

- [Cycle start](card:cycle-start-node): after they meet, move one pointer to the head; step both by one; they meet at node 4.
- [Middle](card:middle-of-linked-list): when fast reaches the end, slow is at the middle.

## Example

```java
boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;    // fast caught up inside a cycle
    }
    return false;                         // fast fell off the end
}
```

## Interview Qs

### Why must the pointers meet if there is a cycle?

Once both are inside the cycle, the gap between them changes by one node every turn. So within one lap the gap becomes zero and they land on the same node.

### How do you find where the cycle starts?

After the first meeting, put one pointer back at the head. Move both one step at a time. The node where they meet again is the first node of the cycle.
