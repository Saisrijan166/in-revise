## Why it exists

Pair, duplicate and frequency questions become slow when each value searches all earlier values. Hashing records useful past information.

## How it works

- Decide exactly what a key maps to: count, first index, latest index or partner.
- Check before putting when a solution must use two distinct positions.
- Use `getOrDefault` for concise counts.

## Example

```java
Map<Integer, Integer> index = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    int need = target - nums[i];
    if (index.containsKey(need)) return new int[] {index.get(need), i};
    index.put(nums[i], i);
}
```

## Interview Qs

### When should you use a HashSet instead of a HashMap?

Use a HashSet when only membership matters. Use a HashMap when each key needs associated information such as a count, index, list, or previous value.

### Why check before inserting in Two Sum?

It ensures the matching value came from an earlier index. Inserting first can accidentally pair an element with itself when the target is twice that value.
