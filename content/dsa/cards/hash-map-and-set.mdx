## Why it exists

HashMap maps a unique key to a value; HashSet stores only unique values. Both use hashing.

## How it works

- Start from the representation shown below.
- Keep its invariant true after every update.
- Check empty input and boundary references before returning.

## Example

```java
Map<String, Integer> counts = new HashMap<>();
counts.put("java", counts.getOrDefault("java", 0) + 1);
Set<Integer> seen = new HashSet<>();
boolean fresh = seen.add(42); // false if already present
```

### What must an implementation preserve?

Its invariant: the structural rule that remains true after every insert, remove, search or traversal step.
