## Why it exists

Dijkstra finds shortest paths from one start when all edge weights are non-negative. It repeatedly expands the cheapest tentative path.

## How it works

- Start from the representation shown below.
- Keep its invariant true after every update.
- Check empty input and boundary references before returning.

## Example

```java
record Edge(int to, int weight) {}
PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(x -> x[1]));
dist[start] = 0; pq.offer(new int[] {start, 0});
while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    if (cur[1] != dist[cur[0]]) continue;
    for (Edge e : graph.get(cur[0])) if (cur[1] + e.weight < dist[e.to]) {
        dist[e.to] = cur[1] + e.weight; pq.offer(new int[] {e.to, dist[e.to]});
    }
}
```
