## Why it exists

Trying every pair costs quadratic time. Two pointers use an ordering or structural fact to rule out many pairs after one comparison.

## How it works

<Steps label="Sorted two-sum">
  <Step title="Start at both ends">Set `left` to 0 and `right` to the last index.</Step>
  <Step title="Compare">If the sum is too small, move left; if too large, move right.</Step>
  <Step title="Stop">Return on equality or when the pointers cross.</Step>
</Steps>

- Each pointer only moves forward or backward, so total work is O(n).

## Example

```java
int left = 0, right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) return 1;
    if (sum < target) left++;
    else right--;
}
return 0;
```

## Interview Qs

### When does sorted two pointers work?

When order lets a comparison discard candidates. For a sorted pair sum, a sum that is too small cannot improve by moving the right pointer left, so move the left pointer right.

### What is fast and slow pointer used for?

Use two speeds in a linked list to find a middle node or detect a cycle. In a cycle, the faster pointer eventually meets the slower one.
