## Why it exists

An array shifts elements to insert in the middle. A linked list grows one node at a time and splices without shifting.

## How it works

<Compare id="array-vs-linked-list" />

- Deleting a node means relinking its predecessor: one step in a doubly linked list, a walk from the head in a singly one.
- Java's `LinkedList.get(i)` walks from whichever end is closer to `i`.

## Example

```java
class ListNode { int val; ListNode next; }

ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next; // save the rest
        curr.next = prev;          // flip the link
        prev = curr;
        curr = next;
    }
    return prev;                   // the new head
}
```

## Interview Qs

### Array vs linked list?

Arrays index in O(1) but shift to insert. Linked lists splice at a held node in O(1) but reach index i in O(n) and need memory for links.

### Why is linked-list access O(n)?

Nodes are not side by side in memory, so the i-th one has no computable address. You follow links from the head one by one.

### How do you reverse a linked list?

Walk once with `prev`, `curr` and `next`: save `curr.next`, point it back to `prev`, then move both forward. O(n) time, O(1) extra space; `prev` is the new head.
