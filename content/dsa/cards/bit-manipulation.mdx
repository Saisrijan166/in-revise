## Why it exists

Bits represent compact flags. Masks inspect, set, clear or toggle one position.

## How it works

- Read the representation before writing the loop or method.
- Keep each variable's purpose clear.
- Test the smallest valid input and one boundary input.

## Example

```java
int mask = 1 << bit;
boolean set = (value & mask) != 0;
value |= mask;      // set bit
value &= ~mask;     // clear bit
value ^= mask;      // toggle bit
```

## Interview Qs

### What should you state before coding?

State the input shape, the state each variable holds, the condition that ends the loop or recursion, and the expected time and space cost.

### What should you test first?

Test empty or smallest valid input, one normal case, and an index or boundary case. These expose most Java loop and reference mistakes.
