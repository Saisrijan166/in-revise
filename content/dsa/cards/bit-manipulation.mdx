## What it is

Bit manipulation means working directly on the binary digits, or bits, of an integer. A Java `int` has 32 bits, and negative numbers use two's complement, where the leftmost bit marks a negative value. The bitwise operators `&`, `|`, `^` and `~` combine numbers one bit position at a time, and the shifts `<<`, `>>` and `>>>` move all bits left or right. A mask is a number with chosen bits set, used to pick out those bits.

## Why it exists

Some classic questions have a neat answer once you think in bits. "Find the one value without a pair" needs a HashSet of O(n) space, or one `int` and XOR. "Is n a power of two?" needs a loop dividing by 2, or one expression. Listing all subsets of n items needs recursion, or a loop over the numbers 0 to 2^n - 1. Interviewers ask a few of these to check that you understand binary numbers.

## How it works

| Operator | Result bit is 1 when | Typical use |
| --- | --- | --- |
| `a & b` | both bits are 1 | test a bit; `x & 1` is 1 for odd x |
| `a \| b` | either bit is 1 | set a bit: `x \| (1 << k)` |
| `a ^ b` | exactly one bit is 1 | flip a bit: `x ^ (1 << k)`; cancel pairs |
| `~a` | a's bit is 0 | clear a bit: `x & ~(1 << k)` |
| `<<`, `>>`, `>>>` | bits move | `x << k` is x × 2^k; `x >> k` is x ÷ 2^k rounded down |

1. Write the number in binary: 12 is `1100`.
2. Build a mask for the bit you care about: bit 2 is `1 << 2`, which is `0100`.
3. Combine with the right operator: `12 & 4` is 4, not 0, so bit 2 is set.
4. For the lowest 1 bit, subtract 1: `12 - 1` is `1011`, which flips the lowest 1 and every 0 below it, so `12 & 11` is `1000`.
5. Wrap every bitwise test in brackets before comparing: `(x & mask) != 0`.

So the key is: a mask selects bits, and `&`, `|`, `^` read, set or flip them.

## Example

Single Number and power of two, plus the binary results of the main tricks on 12.

```java
static int single(int[] nums) {                  // every value twice except one
    int x = 0;
    for (int n : nums) x ^= n;                   // equal pairs cancel to 0
    return x;
}
static boolean powerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }

int x = 12;                                      // binary 1100
System.out.println(single(new int[] {4, 1, 2, 1, 2}) + " " + powerOfTwo(16));
System.out.println(Integer.toBinaryString(x & (x - 1)) + " " + Integer.toBinaryString(x & -x));
System.out.println(Integer.bitCount(x) + " " + (-8 >> 1) + " " + (-8 >>> 28) + " " + (1 << 32));
```

```text output
4 true
1000 100
2 -4 15 1
```

What to notice:

- `single` returns 4 because the two 1s and the two 2s cancel. It uses one `int`, so the extra space is O(1).
- `x & (x - 1)` turns `1100` into `1000`, and `x & -x` keeps only the lowest 1 bit, `100`. A power of two has a single 1 bit, so dropping it leaves 0; without `n > 0`, both 0 and `Integer.MIN_VALUE` would pass.
- `-8 >> 1` is -4 because `>>` copies the sign bit, while `-8 >>> 28` shifts in zeros and gives the positive 15.
- `1 << 32` is 1, not 2^32: an `int` shift uses only the low 5 bits of the distance, so 32 acts as 0. Use `1L << 32`.

## Rules and defaults

- **Precedence:** `==` and `!=` bind tighter than `&`, `^` and `|`, so always bracket a bitwise test.
- **Shift distance:** for `int` only the low 5 bits of the distance are used (0 to 31); for `long`, the low 6 bits (0 to 63).
- **Negative numbers:** in two's complement, `-x` equals `~x + 1`, which is why `x & -x` isolates the lowest 1 bit.
- **Subset masks:** the loop over masks 0 to 2^n - 1 costs O(2^n × n), so it fits only for about n ≤ 20.
- **Library helpers:** `Integer.bitCount(x)` counts 1 bits and `Integer.toBinaryString(x)` prints the bits while debugging.

## Interview Qs

### All numbers appear twice except one. Find it in O(1) space.

XOR all the values. `a ^ a` is 0, `a ^ 0` is a, and XOR order does not matter, so every pair cancels and the single value is left. It is O(n) time and O(1) extra space, where a HashSet would need O(n) space.

### How do you count the 1 bits in an int?

Call `Integer.bitCount(n)`. By hand, repeat `n &= n - 1` until n is 0 and count the steps: each step clears exactly one 1 bit, so the loop runs once per set bit, not 32 times.

### How do you check whether a number is a power of two?

`n > 0 && (n & (n - 1)) == 0`. A power of two has exactly one 1 bit, and `n - 1` flips that bit and every bit below it, so the AND is 0. The `n > 0` check rules out 0 and negative values.
