## Why it exists

Some classic questions need only O(1) space once you use bits.

## How it works

| Operator | Bit is 1 when | Use |
| --- | --- | --- |
| `a & b` | both are 1 | test a bit; `x & 1` for odd |
| `a \| b` | either is 1 | set a bit |
| `a ^ b` | exactly one is 1 | flip a bit, cancel pairs |
| `~a` | a's bit is 0 | clear: `x & ~mask` |
| `<<`, `>>`, `>>>` | bits shift | times or divided by 2^k |

## Example

```java
int single(int[] nums) {             // all twice except one
    int x = 0;
    for (int n : nums) x ^= n;
    return x;
}
boolean powerOfTwo(int n) { return n > 0 && (n & (n - 1)) == 0; }
void subsets(int n) {                // every subset of 0..n-1
    for (int mask = 0; mask < (1 << n); mask++)
        for (int i = 0; i < n; i++)
            if ((mask & (1 << i)) != 0) { /* i is in */ }
}
```

## Interview Qs

### All numbers appear twice but one. Find it in O(1) space.

XOR all values: pairs cancel to 0, leaving the single one. O(n) time, O(1) space.

### How do you count the 1 bits in an int?

`Integer.bitCount(n)`, or count steps of `n &= n - 1` until 0.
