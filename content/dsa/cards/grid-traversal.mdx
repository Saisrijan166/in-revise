## Why it exists

Islands, mazes and spreading problems hide a graph in a grid. Seeing cells as nodes lets you reuse plain DFS and BFS.

## How it works

<Mermaid
  alt="Cell (r, c) links to four neighbours: r-1 and r+1 in its column, c-1 and c+1 in its row."
  chart={`flowchart TD
  U["(r-1, c)"] --- C(("(r, c)"))
  C --- D["(r+1, c)"]
  L["(r, c-1)"] --- C
  C --- R["(r, c+1)"]`}
/>

- Mark visited in a boolean grid, or overwrite the cell if allowed.
- Diagonal moves allowed? Use 8 offsets.

## Example

```java
int[] dr = {-1, 1, 0, 0}, dc = {0, 0, -1, 1};
int numIslands(char[][] grid) {
    int count = 0;
    for (int r = 0; r < grid.length; r++)
        for (int c = 0; c < grid[0].length; c++)
            if (grid[r][c] == '1') { count++; sink(grid, r, c); }
    return count;
}
void sink(char[][] grid, int r, int c) {
    if (r < 0 || c < 0 || r >= grid.length || c >= grid[0].length || grid[r][c] != '1') return;
    grid[r][c] = '0';                                   // mark visited
    for (int d = 0; d < 4; d++) sink(grid, r + dr[d], c + dc[d]);
}
```

## Interview Qs

### Walk me through Number of Islands.

Scan every cell. Each unvisited land cell starts a flood fill that marks its island; count the starts. O(rows × cols).

### How do you solve Rotting Oranges?

Multi-source BFS: queue every rotten orange first; each BFS level is one minute. If a fresh orange is left, return -1.

### DFS or BFS on a grid?

BFS for fewest steps. Either counts regions, but deep recursive DFS on a large grid can overflow the stack ([recursion](card:recursion)); then use BFS.
