## Why it exists

BFS uses a queue and marks a vertex when discovered. It visits by increasing edge distance from the start.

## How it works

- Start from the representation shown below.
- Keep its invariant true after every update.
- Check empty input and boundary references before returning.

```java
Queue<Integer> q = new ArrayDeque<>();
boolean[] seen = new boolean[n];
q.offer(start); seen[start] = true;
while (!q.isEmpty()) {
```
