## Why it exists

Most interview questions vary the story, not the underlying structure. Recognising the structure prevents brute force from becoming the only plan.

## How it works

| Problem clue | First pattern to test |
| --- | --- |
| contiguous range | window or prefix sum |
| sorted values | two pointers or binary search |
| duplicate / complement | set or map |
| repeated minimum / maximum | heap |

- Say the invariant aloud before the loop.
- Reject a pattern if its required property is absent.

## Interview Qs

### How do you choose an algorithm pattern?

I look for structural clues: contiguous ranges, sorted order, membership lookup, repeated best choice, or branching choices. I combine that with constraints, then state the condition the loop must preserve.

### What is a loop invariant?

It is a fact true before and after every loop iteration. For a valid sliding window, for example, the tracked counts must always match the current window.
