## What it is

The Java coding toolkit is the small set of ready-made JDK methods you reach for again and again in a coding round. Most are static helpers: you call them on the class, as in `Arrays.sort(a)`, not on an object. `Arrays` works on arrays, `Collections` on lists, `Character` on single characters, and `Math` and `Integer` on numbers. The methods of each container, such as `map.getOrDefault`, are taught in that container's own concept.

## Why it exists

In a timed round every hand-written loop is a chance for an off-by-one bug. Sorting, copying part of an array, counting how often a value appears or turning text into a number are all one JDK call each. Using the call is shorter, already tested, and tells the interviewer you know the library, which leaves your time for the actual algorithm.

## How it works

| Task | Call |
|---|---|
| Sort all or part of an array | `Arrays.sort(a)`, `Arrays.sort(a, from, to)` |
| Fill, slice, print, compare | `Arrays.fill(a, -1)`, `copyOfRange(a, from, to)`, `toString(a)`, `equals(a, b)` |
| Sum or max of an `int[]` | `Arrays.stream(a).sum()`, `Arrays.stream(a).max().getAsInt()` |
| Sort a list in descending order | `list.sort(Collections.reverseOrder())` |
| Sort by one field, then another | `Comparator.comparing(P::age).thenComparing(P::name)` |
| Count, swap, reverse in a list | `Collections.frequency(list, x)`, `swap(list, i, j)`, `reverse(list)` |
| Classify a char | `Character.isDigit(c)`, `isLetter(c)`, `isLetterOrDigit(c)` |
| Text to number, and back | `Integer.parseInt(s)`, `String.valueOf(n)` |
| String to `char[]`, and back | `s.toCharArray()`, `new String(chars)` |
| `int[]` to `List<Integer>`, and back | `Arrays.stream(a).boxed().toList()`, `list.stream().mapToInt(Integer::intValue).toArray()` |
| Wrap an index around | `Math.floorMod(i - 1, n)` |

1. Convert the input into the shape you work with: `toCharArray()` for a string, `parseInt` for numbers given as text.
2. Prepare it with one call: `Arrays.sort`, or `Arrays.fill` to set every slot of a table to a start value.
3. Process it with the small checks: `Character.isDigit`, `Math.max`, `Math.floorMod`.
4. Convert the result to the type the method must return, and print arrays with `Arrays.toString` while debugging.

So the key is: convert, prepare, process, convert back, with one JDK call at each step. Methods of maps, sets, queues and heaps are in [HashMap and HashSet](card:hashmap-hashset), [Queue and Deque](card:queue-and-deque) and [Heap](card:heap-priority-queue); `Arrays.binarySearch` is in [Binary Search](card:binary-search).

## Example

The running array, mixed up, goes through the toolkit's most common calls.

```java
int[] nums = {15, 2, 11, 7};
Arrays.sort(nums);                                   // [2, 7, 11, 15]
int[] mid = Arrays.copyOfRange(nums, 1, 3);          // index 3 is excluded
int digits = 0;
for (char c : "a1b22".toCharArray()) {
    if (Character.isDigit(c)) digits += c - '0';     // '2' - '0' is 2
}
List<Integer> list = Arrays.stream(nums).boxed().toList();
int prev = Math.floorMod(0 - 1, nums.length);        // index before 0, wrapped
System.out.println(Arrays.toString(mid) + " " + digits + " " + list + " " + prev);
```

```text output
[7, 11] 5 [2, 7, 11, 15] 3
```

What to notice:

- `copyOfRange(nums, 1, 3)` copies indexes 1 and 2 only, so the slice is `[7, 11]`. Every `from, to` pair in these helpers excludes `to`.
- `c - '0'` works because digit characters are stored in order, so `'2'` minus `'0'` is 2. Without the `isDigit` check, letters would add nonsense values.
- `boxed()` turns each `int` into an `Integer`, which a `List` can hold. The list from `toList()` cannot be changed; `add` on it throws.
- `Math.floorMod(-1, 4)` is 3, the last index. Plain `-1 % 4` would be -1 and crash as an index.

## Rules and defaults

- **Sorting primitives:** `Arrays.sort(int[])` sorts ascending and takes no `Comparator`. For another order, sort an `Integer[]` or a `List`.
- **Unmodifiable result:** `Stream.toList()` (Java 16+) returns a list you cannot change; wrap it in `new ArrayList<>(...)` if you need to add or remove.
- **Bad number text:** `Integer.parseInt` accepts an optional leading `+` or `-` and throws `NumberFormatException` for anything else that is not a number, such as `"12a"`.
- **Powers:** `Math.pow` and `Math.sqrt` return `double`; cast with `(int)` or `(long)`. For powers of two, `1 << k` is exact (you will see it in [Bit Manipulation](card:bit-manipulation)).

## Common mistakes

- **"Arrays.toString prints a 2D array."** For an `int[][]` it prints each row as an object code, such as `[[I@7cb502c, [I@275bf9b3]`. Use `Arrays.deepToString(grid)`.
- **"Collections.sort works on arrays too."** It takes a `List`. Arrays use `Arrays.sort`.

## Interview Qs

### How do you sort an int[] in descending order?

`Arrays.sort` for primitive arrays takes no `Comparator`, so `Collections.reverseOrder()` does not compile there. Sort ascending, then reverse the array in place with two pointers. Or box it to an `Integer[]` and call `Arrays.sort(boxed, Collections.reverseOrder())`, which costs extra memory for the objects.

### Why use Math.floorMod instead of %?

`%` gives a result with the sign of the left side: `-1 % 5` is -1, which is not a valid index. `Math.floorMod(-1, 5)` is 4, because its result takes the sign of the divisor. Use it whenever an index can step below 0 in a circular array.

### How do you convert between an int[] and a list of Integers?

`Arrays.stream(a).boxed().toList()` gives a `List<Integer>` (unmodifiable, Java 16+). Back again: `list.stream().mapToInt(Integer::intValue).toArray()`. `Arrays.asList(a)` is wrong for an `int[]`: it gives a list holding the array itself.
