## Why it exists

A timed round rewards fast, correct code. One JDK call is shorter and safer than a hand-written loop.

## How it works

| Task | Call |
|---|---|
| Sort all or part of an array | `Arrays.sort(a)`, `Arrays.sort(a, from, to)` |
| Fill, slice, print, compare | `Arrays.fill(a, -1)`, `copyOfRange(a, from, to)`, `toString(a)`, `equals(a, b)` |
| Sum or max of an `int[]` | `Arrays.stream(a).sum()`, `.max().getAsInt()` |
| Sort a list descending | `list.sort(Collections.reverseOrder())` |
| Sort by one field, then another | `Comparator.comparing(P::age).thenComparing(P::name)` |
| Count, swap, reverse in a list | `Collections.frequency(list, x)`, `swap(list, i, j)`, `reverse(list)` |
| Classify a char | `Character.isDigit`, `isLetter`, `isLetterOrDigit` |
| Text to number, and back | `Integer.parseInt(s)`, `String.valueOf(n)` |
| String to char[], and back | `s.toCharArray()`, `new String(chars)` |
| `List<Integer>` → `int[]` | `list.stream().mapToInt(Integer::intValue).toArray()` |
| Wrap an index backwards | `Math.floorMod(i - 1, n)` |

- Every `to` is excluded. A running min or max starts at `Integer.MAX_VALUE` or `MIN_VALUE`.
- Container methods: [HashMap and HashSet](card:hashmap-hashset), [strings](card:strings), [ArrayList](card:dynamic-array), [queue](card:queue-and-deque), [stack](card:stack), [heap](card:heap-priority-queue); `Arrays.binarySearch`: [binary search](card:binary-search).

## Example

```java
int[] nums = {5, 3, 9, 1};
Arrays.sort(nums);                                 // [1, 3, 5, 9]
int[] mid = Arrays.copyOfRange(nums, 1, 3);        // [3, 5]
int sum = 0;
for (char c : "a1b22".toCharArray()) {
    if (Character.isDigit(c)) sum += c - '0';      // 1 + 2 + 2 = 5
}
List<Integer> list = Arrays.stream(nums).boxed().toList();
int last = Math.floorMod(0 - 1, nums.length);      // 3, not -1
```

## Interview Qs

### How do you sort an int[] in descending order?

Primitive `Arrays.sort` takes no Comparator. Sort, then reverse with two pointers, or box to `Integer[]` and pass `Collections.reverseOrder()`.

### Why use Math.floorMod instead of %?

`%` takes the sign of the left side: `-1 % 5` is -1, not a valid index. `Math.floorMod(-1, 5)` is 4: the floor modulus takes the sign of the divisor.
