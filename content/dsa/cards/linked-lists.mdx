## Why it exists

A linked list stores values in nodes. Singly linked nodes point next; doubly linked nodes also point previous; circular lists link tail to head.

## How it works

- Start from the representation shown below.
- Keep its invariant true after every update.
- Check empty input and boundary references before returning.

## Example

```java
class Node { int value; Node next; Node(int v) { value = v; } }
Node head = new Node(10);
head.next = new Node(20);
Node newHead = new Node(5);
newHead.next = head; // insert at front
head = newHead;
```

## Interview Qs

### What must an implementation preserve?

Its invariant: the structural rule that remains true after every insert, remove, search or traversal step.

### How do you explain complexity?

State the operation, how many elements or levels it can touch, and any auxiliary memory such as a queue, recursion stack or helper array.
