## What it is

An interval is a range with a start and an end, such as a meeting from 9 to 11, written [9, 11]. Two intervals overlap when each one starts before the other ends. Interval problems ask you to merge overlapping ranges, insert a new range, or count how many overlap at one time. Almost all of them start the same way: [sort](card:sorting-basics) the intervals by start.

## Why it exists

Without sorting, any interval may overlap any other, so you would compare every pair, which is O(n²). Once the intervals are sorted by start, a range that overlaps something must overlap the range just before it in the merged list. So a single left-to-right pass is enough, and the whole job costs O(n log n) for the sort.

## How it works

<Steps label="Merge [[8, 10], [1, 3], [2, 6], [15, 18]]">
  <Step title="Sort by start">The list becomes [1, 3], [2, 6], [8, 10], [15, 18].</Step>
  <Step title="Start the result">The first range, [1, 3], goes into the merged list.</Step>
  <Step title="Overlap: extend">[2, 6] starts at 2, before 3, so the last range becomes [1, max(3, 6)] = [1, 6].</Step>
  <Step title="Gap: add">[8, 10] starts after 6, so it is added as a new range. [15, 18] is added the same way.</Step>
</Steps>

1. Sort the intervals by their start value.
2. Put the first interval into the result.
3. For each next interval, compare its start with the end of the last interval in the result.
4. If the start is not after that end, they overlap: set the last end to the larger of the two ends.
5. Otherwise there is a gap: add the interval to the result as a new range.

So the key is that sorting makes every overlap appear between neighbours.

## Example

The merge from the steps above, in Java:

```java
int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));   // by start
    List<int[]> merged = new ArrayList<>();
    for (int[] cur : intervals) {
        int[] last = merged.isEmpty() ? null : merged.get(merged.size() - 1);
        if (last != null && cur[0] <= last[1]) last[1] = Math.max(last[1], cur[1]); // overlap
        else merged.add(cur);                                          // gap: new range
    }
    return merged.toArray(new int[0][]);
}

System.out.println(Arrays.deepToString(merge(new int[][] {{8, 10}, {1, 3}, {2, 6}, {15, 18}})));
```

```text output
[[1, 6], [8, 10], [15, 18]]
```

What to notice:

- `Integer.compare(a[0], b[0])` sorts by start safely. The shortcut `a[0] - b[0]` can overflow for large values; you will see why in [Java pitfalls](card:java-pitfalls).
- `cur[0] <= last[1]` treats touching ranges like [1, 4] and [4, 5] as overlapping. Change it to `<` if the problem says they do not.
- `Math.max` keeps the larger end, so a range inside another, like [2, 3] inside [1, 5], does not shrink it.
- `last[1] = ...` changes the array from the input, so the caller's intervals are modified. Copy them first if that matters.

## Rules and defaults

- **Sort key:** merging, inserting and meeting rooms sort by start. Keeping the most non-overlapping intervals sorts by end; that is the [greedy](card:greedy) activity-selection rule.
- **Already sorted input:** inserting one interval into a sorted, non-overlapping list needs no sort, only one O(n) pass.
- **Touching ends:** decide with the interviewer whether [1, 2] and [2, 3] overlap before writing the test.
- **Counting overlaps:** to find the most intervals open at once, use a sweep line: +1 at each start, -1 at each end, events sorted by time.

## Interview Qs

### How many meeting rooms are needed?

As many as the most meetings open at one moment. Make a +1 event at each start and a -1 event at each end, sort the events by time, and track the running count; its maximum is the answer. Ask whether a meeting ending at 10 frees its room for one starting at 10, and if so, process ends before starts at equal times.

### What is the fewest number of intervals to remove so none overlap?

Keep as many intervals as possible, then remove the rest. Keeping the most is activity selection: sort by end and keep each interval that starts at or after the last kept end. The answer is n minus the number kept, in O(n log n).

### How do you insert an interval into a sorted, non-overlapping list?

No sort is needed. Copy the ranges that end before the new one starts. Merge every range that overlaps it into one, taking the smallest start and the largest end. Then copy the remaining ranges. It is one O(n) pass.
