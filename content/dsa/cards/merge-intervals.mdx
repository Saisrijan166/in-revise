## Why it exists

Comparing every pair of intervals is O(n²). After sorting by start, overlaps sit next to each other, so one pass is enough.

## How it works

<Steps label="Merge intervals">
  <Step title="Sort by start">[[1,3],[8,10],[2,6]] becomes [[1,3],[2,6],[8,10]].</Step>
  <Step title="Overlap? Extend">[2,6] starts before 3, so the last range becomes [1,6].</Step>
  <Step title="Gap? Start new">[8,10] starts after 6, so it is added as is.</Step>
</Steps>

- The comparator must not subtract: see [Java pitfalls](card:java-pitfalls).

## Example

```java
int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    List<int[]> merged = new ArrayList<>();
    for (int[] cur : intervals) {
        int[] last = merged.isEmpty() ? null : merged.get(merged.size() - 1);
        if (last != null && cur[0] <= last[1]) last[1] = Math.max(last[1], cur[1]);
        else merged.add(cur);
    }
    return merged.toArray(new int[0][]);
}

System.out.println(Arrays.deepToString(merge(new int[][] {{1, 3}, {2, 6}, {8, 10}})));
```

```text output
[[1, 6], [8, 10]]
```

## Interview Qs

### How many meeting rooms are needed?

The most meetings open at one moment. Make a +1 event at each start and a -1 at each end, sort them, and track the running count's maximum. Ask whether a meeting ending at 10 frees a room for one starting at 10.

### Fewest intervals to remove so none overlap?

Keep the most intervals, then remove the rest. Keeping the most is activity selection: sort by end and keep each one that starts after the last kept end (see [greedy](card:greedy)).

### Insert an interval into a sorted, non-overlapping list?

No sort needed: copy the ranges that end before it, merge every range that overlaps it, then copy the rest. One O(n) pass.
