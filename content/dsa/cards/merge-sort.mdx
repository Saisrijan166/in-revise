## Why it exists

Merge sort divides an array, recursively sorts both halves, then merges them. It is stable and uses extra merge storage.

## How it works

- Start from the representation shown below.
- Keep its invariant true after every update.
- Check empty input and boundary references before returning.

## Example

```java
void merge(int[] a, int l, int m, int r, int[] tmp) {
    int i = l, j = m + 1, k = l;
    while (i <= m && j <= r) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (i = l; i <= r; i++) a[i] = tmp[i];
}
```
