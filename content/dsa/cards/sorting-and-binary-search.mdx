## Why it exists

Linear search checks each value. Binary search works only on sorted data and discards half each comparison.

## How it works

- Start from the representation shown below.
- Keep its invariant true after every update.
- Check empty input and boundary references before returning.

## Example

```java
int left = 0, right = a.length - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (a[mid] == target) return mid;
    if (a[mid] < target) left = mid + 1;
    else right = mid - 1;
}
return -1;
```
