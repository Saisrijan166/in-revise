## Why it exists

Interview solutions become shorter and clearer when the Java collection directly represents the operation the algorithm needs.

## How it works

- Prefer interfaces in declarations: `Map`, `Set`, `Deque`, `List`.
- `ArrayDeque` has `push/pop` for a stack and `offer/poll` for a queue.
- A `PriorityQueue` exposes its best item with `peek` and removes it with `poll`.

## Example

```java
Map<Integer, Integer> count = new HashMap<>();
Deque<Integer> queue = new ArrayDeque<>();
PriorityQueue<Integer> max = new PriorityQueue<>(Comparator.reverseOrder());
```

## Interview Qs

### Why use ArrayDeque instead of Stack?

`ArrayDeque` implements `Deque` and supports both stack and queue operations. The Java API recommends `Deque` in preference to the legacy `Stack` class for LIFO stacks.

### How do you make a max-heap in Java?

Create `new PriorityQueue<>(Comparator.reverseOrder())` for naturally ordered values. Its head is then the greatest value according to that reversed comparator.
