## Why it exists

Many problems need items in order with fast access by position. An array gives each item a numbered slot in one block of memory.

## How it works

| Operation | Cost | Why |
|---|---|---|
| `a[i]` read or write | O(1) | address = start + i × item size |
| Find a value | O(n) | no shortcut unless sorted |
| Insert or delete at i | O(n) | shift the items after i |

- New arrays are filled with defaults: `0`, `false`, `'\u0000'`, or `null` for objects.
- A 2D array is an array of rows; rows may have different lengths (jagged).

## Example

```java
int[] nums = new int[5];          // [0, 0, 0, 0, 0]
nums[2] = 7;                      // O(1)
int[][] grid = new int[3][4];     // 3 rows, 4 columns
int[][] jagged = new int[3][];    // rows created later
jagged[0] = new int[1];
jagged[1] = new int[2];
System.out.println(nums[5]);      // ArrayIndexOutOfBoundsException
```

## Interview Qs

### Why is array access O(1)?

Items are the same size and stored next to each other, so the address of item i is computed from the start address. No scanning.

### Why is inserting in the middle of an array slow?

Every item after the insert point must move one slot right, which is O(n). If the array is full, a bigger array must be allocated and all items copied.
