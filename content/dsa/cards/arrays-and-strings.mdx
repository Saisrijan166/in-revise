## Why it exists

Arrays and strings are common inputs. Their indexed layout lets a solution update a small amount of state while moving forward once.

## How it works

- Use a frequency array only when its value range is known and small.
- Use a map when keys are sparse or arbitrary.
- Use a write index to compact an array in place.

## Example

```java
int write = 0;
for (int x : nums) {
    if (x != 0) nums[write++] = x;
}
```

## Interview Qs

### When do you use a frequency array versus a HashMap?

Use an array when keys are a small known integer or character range. Use a HashMap when keys are sparse, large, negative, or not conveniently mapped to indices.

### What edge cases matter for array code?

Check empty and one-element input, duplicate values, and boundaries. Never calculate `length - 1` and use it as an index without confirming the array is non-empty.
