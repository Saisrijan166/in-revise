## Why it exists

Many questions only ask whether things connect: can A reach B, how many groups, is there a loop. DFS answers them with little code.

## How it works

<Compare id="bfs-vs-dfs" />

- **Undirected cycle:** reaching a visited vertex that is not your parent means a cycle.
- **Directed cycle:** colour vertices white, grey (on the current path), black (done). An edge to a grey vertex is a cycle.

## Example

```java
int countComponents(int n, List<List<Integer>> graph) {
    boolean[] seen = new boolean[n];
    int count = 0;
    for (int i = 0; i < n; i++)
        if (!seen[i]) { count++; dfs(i, graph, seen); }
    return count;
}
void dfs(int u, List<List<Integer>> graph, boolean[] seen) {
    seen[u] = true;
    for (int v : graph.get(u)) if (!seen[v]) dfs(v, graph, seen);
}
```

## Interview Qs

### BFS or DFS: how do you choose?

Fewest steps in an unweighted graph: BFS. Reachability, components, cycles or exploring every path: DFS, which is shorter to write. Both cost O(V + E).

### How do you detect a cycle in a directed graph?

Run DFS with three colours. Mark a vertex grey on entry and black on exit. Meeting a grey vertex means you returned to the current path, so there is a cycle.

### Why can recursive DFS crash in Java?

Each call takes a stack frame, so a very long path can overflow the thread stack with StackOverflowError (see [recursion](card:recursion)). For very deep graphs, use an explicit `ArrayDeque` stack.
