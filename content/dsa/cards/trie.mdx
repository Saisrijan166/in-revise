## Why it exists

A trie stores words character by character. Nodes share prefixes and an end flag marks a complete word.

## How it works

- Start from the representation shown below.
- Keep its invariant true after every update.
- Check empty input and boundary references before returning.

## Example

```java
class TrieNode {
    TrieNode[] next = new TrieNode[26];
    boolean word;
}
void insert(TrieNode root, String s) {
    for (char c : s.toCharArray()) {
        int i = c - 'a';
        if (root.next[i] == null) root.next[i] = new TrieNode();
        root = root.next[i];
    }
    root.word = true;
}
```
