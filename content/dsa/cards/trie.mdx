## Why it exists

A HashSet can say whether "cart" is a word, but not which stored words start with "ca". A trie answers prefix questions by walking the prefix once.

## How it works

<Mermaid
  alt="A trie holding car, cart and cat: root, c, a, then branches r and t. r and both t nodes are marked end of word."
  chart={`flowchart TD
  R((root)) --> C((c))
  C --> A((a))
  A --> RR(("r *"))
  A --> T(("t *"))
  RR --> T2(("t *"))`}
/>

- `*` marks the end of a word: car, cart, cat.
- Search and startsWith walk the same path; only search checks the end mark.

## Example

```java
class Trie {
    Trie[] next = new Trie[26];
    boolean isWord;

    void insert(String word) {
        Trie node = this;
        for (char c : word.toCharArray()) {
            if (node.next[c - 'a'] == null) node.next[c - 'a'] = new Trie();
            node = node.next[c - 'a'];
        }
        node.isWord = true;
    }
}
```

## Interview Qs

### What is a trie, and when do you use it?

A tree of characters where shared prefixes share nodes. Use it for prefix queries: autocomplete, longest prefix match, and searching many words at once (Word Search II).

### Trie or HashSet for a dictionary?

Pick a HashSet for exact lookups only; pick a trie when you need startsWith or all words with a prefix.

### How would you implement search and startsWith?

Walk one child per character; return false at a missing link. At the end, search returns the node's end-of-word flag; startsWith returns true.
