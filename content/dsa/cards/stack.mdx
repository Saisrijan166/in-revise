## What it is

A stack is an [ADT](card:data-structures) that keeps items like a pile of plates: you add and remove only at one end, called the top. Adding is called push, removing is called pop, and reading the top without removing it is called peek. The last item pushed is the first one popped, which is called LIFO: last in, first out. In Java you get a stack from the `Deque` interface, usually backed by `ArrayDeque`, a resizable array.

## Why it exists

Many tasks must finish the most recent unfinished thing first. When you check the brackets in `([)]`, the bracket you must close next is the one opened last. When methods call methods, the one that started last must return first. Without a stack you would search back through everything seen so far for the newest open item, O(n) each time. A stack always keeps that item on top, so reaching it is O(1). Bracket matching, method calls, expression evaluation and depth-first search all work this way.

## How it works

1. `push(10)`, `push(20)`, `push(30)`: each new item goes on top, so 30 is now the top.
2. `peek()` returns 30 and leaves the stack unchanged.
3. `pop()` removes and returns 30; 20 becomes the top.
4. Popping the rest returns 20, then 10, the reverse of the order they went in.
5. `pop()` on the now-empty `ArrayDeque` throws `NoSuchElementException`, while `peek()` and `poll()` return `null`. Popping an empty stack is called underflow.

So the key is: every operation touches only the top, which is why each one is O(1).

## Example

Valid parentheses: each opening bracket pushes the closer it expects, and each closer must match the top.

```java
boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(')');           // remember the closer we now need
        else if (c == '[') stack.push(']');
        else if (c == '{') stack.push('}');
        else if (stack.isEmpty() || stack.pop() != c) return false;
    }
    return stack.isEmpty();                      // anything left was never closed
}

System.out.println(isValid("([]{})") + " " + isValid("(]") + " " + isValid("(("));
```

```text output
true false false
```

What to notice:

- Pushing the expected closer, not the opener, makes the check one comparison: `stack.pop() != c`.
- `stack.isEmpty()` is checked before `pop()`. For `")"` the stack is empty, and without that check `pop()` would throw instead of returning `false`.
- The last line catches openers that were never closed, such as `"(("`. Each character is pushed or popped once, so the method is O(n) time and O(n) space.

## Rules and defaults

- **Methods map to the front:** on a `Deque`, `push` is `addFirst`, `pop` is `removeFirst` and `peek` is `peekFirst`. So the top of the stack is the first element, and printing an `ArrayDeque` lists the top first.
- **Costs:** most `ArrayDeque` operations are amortised O(1); `contains` and removing a given item are O(n).
- **Legacy class:** `java.util.Stack` extends `Vector`; its `pop()` and `peek()` throw `EmptyStackException` on an empty stack.
- **Overflow:** a stack overflows when it runs out of room. For the JVM's own call stack this happens when recursion goes too deep, and Java throws `StackOverflowError`.

## Not to be confused with

The call stack is memory the JVM manages for you: each method call that has not returned keeps a frame on it, and the newest call returns first. A stack data structure is one you create in your code, such as an `ArrayDeque`, and it lives as an ordinary object. Both are LIFO. Rule: the call stack is how [recursion](card:recursion) runs; an explicit stack is how you write the same idea with a loop.

## Common mistakes

- **Calling `pop()` without checking.** On an empty `ArrayDeque` it throws `NoSuchElementException`. Check `isEmpty()` first, or use `poll()`, which returns `null`.

## Interview Qs

### What is a stack, and where is it used?

A stack is a LIFO collection: push, pop and peek work at the top in O(1). It fits any problem where the newest unfinished item must be handled first: bracket matching, method calls, expression evaluation and depth-first search.

### What is the difference between stack overflow and stack underflow?

Overflow means the stack has no room left; in Java it usually means recursion went too deep, and the JVM throws `StackOverflowError`. Underflow means popping an empty stack: `Stack` throws `EmptyStackException`, and `ArrayDeque.pop()` throws `NoSuchElementException`.

### How would you build a stack that returns its minimum in O(1)?

Store pairs: each item together with the minimum of everything at or below it. Push stores min(value, current minimum); pop removes the pair; getMin reads the minimum stored in the top pair. Every operation stays O(1), at the cost of storing one extra number per item.
