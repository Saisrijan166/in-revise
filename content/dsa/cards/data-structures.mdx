## What it is

A data structure is a way to keep data in memory together with the operations you run on it, such as add, find and remove. An array keeps items side by side in numbered slots; a linked list keeps each item in its own object that points to the next. The list of operations and what they promise, without saying how data is stored, is called an abstract data type (ADT), or interface. A data structure is one concrete way to deliver an ADT.

## Why it exists

Suppose you store a million usernames and must check whether "asha" is taken. In an unsorted array you compare against every name, up to a million steps. In a hash set, which you will meet in [hash tables](card:hashing), the same check takes about one step on average. The data is the same; only the layout differs. Choosing a data structure is choosing which operations will be cheap, and most interview problems come down to that choice.

## How it works

| Family | How items are arranged | Examples in this tech |
|---|---|---|
| Linear | one after another, in a single sequence | array, linked list, stack, queue |
| Non-linear | one item links to several others | tree, heap, graph |
| Hash-based | a hash of the key picks the slot | HashMap, HashSet |
| Specialised | built for one job | trie (prefixes), union-find (groups) |

Every structure in this tech is taught in the same three steps:

1. **What it stores:** the shape of the data, for example items side by side, or nodes joined by links.
2. **How each operation works:** the steps an operation takes on that shape, for example jumping straight to slot 5, or walking node by node.
3. **What each operation costs:** how the number of steps grows with the number of items, measured with [Big-O](card:big-o), the next concept.

So the key is: the layout decides the steps, and the steps decide the cost.

## Example

Java's `Queue` is an ADT, and two different data structures implement it:

```java
Queue<String> a = new ArrayDeque<>();   // items kept in an array
Queue<String> b = new LinkedList<>();   // items kept in linked nodes
for (Queue<String> q : List.of(a, b)) {
    q.offer("first");
    q.offer("second");                  // same two operations
    System.out.println(q.poll());       // same FIFO result
}
```

```text output
first
first
```

What to notice:

- The loop only uses `Queue` operations: `offer` adds at the back, `poll` removes from the front. Both objects answer `first`, because both keep the promise of the ADT.
- The storage behind them differs: one array versus a chain of nodes. That changes speed and memory, not the result.
- Because the variables are declared as `Queue`, swapping `new LinkedList<>()` for `new ArrayDeque<>()` needs no other change.

## Rules and defaults

- **Static structure:** its size is fixed when it is created. A Java array is static: once created, its length never changes, so a bigger one means a new array.
- **Dynamic structure:** it grows and shrinks while the program runs. `ArrayList` grows its storage automatically as you add items; a linked list adds one node at a time.
- **Families are a guide, not a rule:** some books file hash tables under non-linear. What matters in an interview is the cost of each operation, not the label.

## Not to be confused with

An ADT says what operations exist, such as push and pop for a stack. A data structure is how the data is laid out to provide them, such as an array. An algorithm is a step-by-step procedure that solves a problem, such as sorting, and it usually works on a data structure. Rule: ADT = what you can do; data structure = how data is kept; algorithm = the steps that use it.

## Interview Qs

### What is a data structure?

It is a way to organise data in memory, together with its operations, so that the operations a program uses most are cheap. An array gives any position by index in one step; a HashMap finds a value by its key in about one step on average.

### What is the difference between an ADT and a data structure?

An ADT lists the operations and their meaning, such as a queue's offer and poll in first-in-first-out order. A data structure is one way to store the data that delivers those operations, with its own costs. Java's `Queue` interface is the ADT; `ArrayDeque` and `LinkedList` are data structures.

### What is the difference between linear and non-linear data structures?

In a linear structure the items form one sequence, so each item has at most one next item: arrays, linked lists, stacks and queues. In a non-linear structure one item can link to several others: trees, heaps and graphs.
