## Why it exists

Lists and arrays are flat. Many things are hierarchies: folders, an HTML page, an org chart. A tree stores the parent-child links directly.

## Example

```java
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

int height(TreeNode node) {          // edges; empty tree = -1
    if (node == null) return -1;
    return 1 + Math.max(height(node.left), height(node.right));
}
```

## Interview Qs

### What is the difference between depth and height?

Depth counts edges from the root down to the node (root = 0). Height counts edges from the node down to its deepest leaf (leaf = 0).

### How many edges does a tree with n nodes have?

Exactly n - 1. Adding one more edge creates a cycle; removing one splits the tree in two.
