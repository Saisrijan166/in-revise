## Why it exists

A root container with extra kernel powers can break out to the node. Pods need safe settings, and the cluster must refuse unsafe ones.

## How it works

| securityContext field | Set to | Stops |
|---|---|---|
| `runAsNonRoot` | `true` | Starting a container whose user is root (UID 0) |
| `allowPrivilegeEscalation` | `false` | A process gaining more rights than its parent |
| `capabilities.drop` | `[ALL]` | Extra kernel powers such as `NET_RAW` |
| `seccompProfile.type` | `RuntimeDefault` | Unneeded system calls |
| `readOnlyRootFilesystem` | `true` | Writes to the container's own files |

- Restricted needs the first four; read-only root is extra. Container values override Pod values.
- Custom rules (allowed registries, required labels): ValidatingAdmissionPolicy (CEL, stable since 1.30), Kyverno or OPA Gatekeeper.
- Private images: pull with `imagePullSecrets`; see [Secrets](card:configmaps-and-secrets).

## Example

payment-service under the restricted level:

```yaml
# Namespace payments
metadata:
  labels: { pod-security.kubernetes.io/enforce: restricted }
---
# Pod template of the payment-service Deployment
spec:
  securityContext: { runAsNonRoot: true, runAsUser: 1000, seccompProfile: { type: RuntimeDefault } }
  containers:
    - name: payment-service
      image: payment-service:1.4.0
      securityContext: { allowPrivilegeEscalation: false, capabilities: { drop: [ALL] } }
```

## Interview Qs

### How do you stop containers running as root?

Set `runAsNonRoot: true`; the kubelet then refuses a container whose image runs as UID 0. Enforce `restricted` on the namespace to reject Pods without it.

### What replaced PodSecurityPolicy?

Pod Security Admission (stable since 1.25): three fixed levels set by namespace labels. Custom rules go to ValidatingAdmissionPolicy, Kyverno or OPA Gatekeeper.

### How do you move an existing namespace to restricted safely?

Keep enforce at baseline; set audit and warn to restricted. Preview with `kubectl label --dry-run=server`, fix the reported Pods, then enforce restricted.
