## Why it exists

By default any Pod, even a hacked one, can call any Pod, such as the payments database. Policies allow only needed calls.

## How it works

<Mermaid
  alt="A NetworkPolicy selects the payment-service Pods. order-service (namespace orders) and the gateway (namespace infra) may connect on 8080; any other Pod is blocked."
  chart={`flowchart LR
  O[order-service, ns orders] -- "allowed :8080" --> P[payment-service Pods]
  G[gateway, ns infra] -- "allowed :8080" --> P
  X[any other Pod] -. blocked .-> P`}
/>

- One `from` item with both selectors means AND; two items mean OR.
- Default deny egress also blocks DNS; allow port 53 to the cluster DNS.
- No layer 7 rules, TLS or explicit deny rules; for layer 7 and TLS use a [service mesh](card:service-mesh) or Gateway.

## Example

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata: { name: payment-service-callers, namespace: payments }
spec:
  podSelector: { matchLabels: { app: payment-service } }
  policyTypes: [Ingress]
  ingress:
    - from:
        - namespaceSelector: { matchLabels: { kubernetes.io/metadata.name: orders } }
          podSelector: { matchLabels: { app: order-service } }    # AND
        - namespaceSelector: { matchLabels: { kubernetes.io/metadata.name: infra } }  # OR
      ports: [{ port: 8080 }]
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| Traffic when no policy selects a Pod | all allowed, in and out | Kubernetes 1.37 |
| `policyTypes` left out | Ingress, plus Egress if egress rules exist | Kubernetes 1.37 |

## Interview Qs

### How do you let only order-service call payment-service?

Add default deny (`podSelector: {}`, no rules) in payments, then allow order-service's namespace and labels on port 8080, as in the example.

### You added default deny for egress and now nothing resolves. Why?

Egress deny blocks DNS too. Allow egress on port 53 (UDP and TCP) to the cluster DNS Pods.

### Does a NetworkPolicy work on every cluster?

No. The CNI plugin enforces it; without support the object is accepted but does nothing.
