## What it is

A transformer is the particular [neural network](card:neural-networks) design that modern [LLMs](card:what-is-an-llm) are built on. Its central part is self-attention: a step that lets each [token](card:tokens) look at all the other tokens in the same input and decide which of them matter for its own meaning. It was introduced in 2017 and replaced the older designs that read text one word at a time. When people say "the model understands context", this attention step is what they mean.

## Why it exists

Older [recurrent networks](card:neural-networks) read a sentence one word at a time, carrying a running summary forward. That had two problems: training was slow because the words had to be processed in sequence, and words far apart were hard to connect because the summary faded over distance. Self-attention removes both: it connects any two tokens directly in one step, and it looks at all positions at the same time, so training can run in parallel.

## How it works

Take "The customer asked about the refund because it was late". The model needs to tie "it" to "refund". Attention does this with three roles per token: a query (what this token is looking for), a key (what each token offers) and a value (the information each token passes on).

1. The token "it" forms a query describing what it needs to resolve its meaning.
2. That query is compared with the key of every token, giving a relevance score for each.
3. The scores are turned into weights that add up to one, so "refund" gets a high weight and unrelated words get low ones.
4. The new representation of "it" is the weighted blend of every token's value, so it now mostly carries the meaning of "refund".

So the key is that each token rebuilds its meaning from the tokens it finds most relevant, and the model learned which those are during training.

## Example

This is what self-attention produces, written out as the weights for one token rather than code.

```text
Resolving "it" in: The customer asked about the refund because it was late
  attention weight on "refund"   = 0.62   (highest)
  attention weight on "customer" = 0.11
  attention weight on "late"     = 0.09
  ... remaining tokens share the rest ...
New meaning of "it" = 0.62*value(refund) + 0.11*value(customer) + ...
```

What to notice:

- The weights add up to one, so the new meaning of "it" is a blend, dominated here by "refund".
- These weights are illustrative, not a measured run; the point is the shape, one token drawing most from another.
- Multi-head attention runs several of these blends in parallel, each free to focus on a different kind of link, such as grammar in one head and subject matter in another.

## Rules and defaults

- **Order is added, not built in:** attention alone ignores word order, so a transformer adds positional encoding to tell tokens apart by position (Vaswani et al., 2017).
- **Cost is quadratic:** standard self-attention compares every token with every other, so cost grows with the square of the input length; this is why long [context](card:context-window) is expensive.
- **Decoder-only for chat:** most chat LLMs are decoder-only, so each token attends only to earlier tokens. Encoder-only models such as BERT see the whole input and power [embeddings](card:embeddings) and [rerankers](card:reranking).

## Interview Qs

### Explain attention without the maths.

For each token, the model asks which other tokens help explain it, gives each a weight, and blends their information into that token. That is how "it" picks up the meaning of "refund". The query, key and value are just the three roles each token plays; skip the formulas unless you are asked.

### Why did transformers replace RNNs?

An RNN must process tokens one after another, which is slow and lets links between distant words fade. A transformer looks at all tokens at once, so training runs in parallel on GPUs, and self-attention connects any two tokens directly however far apart they are.

### Why is a long context expensive?

Standard self-attention compares every token with every other token, so the work grows with the square of the input length. Doubling the number of tokens roughly quadruples the attention cost, which is why very long prompts are slow and costly.
