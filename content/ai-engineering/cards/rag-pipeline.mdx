## Why it exists

Reading and embedding thousands of pages per question is too slow. So that work runs once, ahead of time, and each question needs only one fast search.

## How it works

<Mermaid
  alt="Ingestion, offline: documents are loaded, chunked, embedded and stored with metadata in pgvector. Query time, online: the question is embedded and searched in pgvector, the top-K chunks are filtered or reranked, put into a prompt, and the LLM answers with citations."
  chart={`flowchart LR
  D[Documents] --> C[Load and chunk]
  C --> E[Embed]

  Q([Question]) --> S[Embed and search top-K]
  V --> S
  S --> R[Filter or rerank]
  R --> P[Prompt + LLM]
  P --> A([Answer + citations])`}

- Stage details: [chunking](card:chunking), [embeddings](card:embeddings), [vector databases](card:vector-databases), [filters](card:metadata-and-filtering), [reranking](card:reranking), [citations](card:grounding-and-citations).

## Example

```java
@Service
class RefundHelp {
    private final VectorStore store;
    private final ChatClient chat;
    RefundHelp(ChatClient.Builder builder, VectorStore store) {
        this.store = store;
        this.chat = builder.defaultAdvisors(QuestionAnswerAdvisor.builder(store).build()).build();
    }
    void ingest(Resource policy) {   // offline: load, chunk, embed + store
        store.add(TokenTextSplitter.builder().build().apply(new TextReader(policy).get()));
    }
    String ask(String q) { return chat.prompt().user(q).call().content(); }   // online
}
```

## Interview Qs

### How do you build RAG?

Ingestion: load, clean, chunk, embed, store vectors with metadata. Query: embed the question, search top-K with tenant filters, rerank, prompt the LLM to answer only from the chunks with citations. Then evaluate.

### A refund policy changed. What do you do?

Re-ingest that document: delete its old chunks by document id, then chunk and embed the new version. No model change is needed; the next question sees the new text.

### Which Spring AI pieces do RAG?

Ingestion: `DocumentReader`, `TokenTextSplitter`, `VectorStore`. Query time: `QuestionAnswerAdvisor`, or `RetrievalAugmentationAdvisor` for a modular flow.
