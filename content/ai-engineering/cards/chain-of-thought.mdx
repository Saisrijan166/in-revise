## What it is

Chain-of-thought (CoT) is a prompting technique: you ask the model to write out its reasoning steps before giving the final answer, instead of answering in one jump. A **reasoning model** is a model trained to do this thinking on its own, internally, before it replies; with these models you set an **effort level** rather than telling it to think. So CoT is something you ask for, while a reasoning model has it built in.

## Why it exists

On a multi-step problem, such as checking refund eligibility against a policy with several conditions, a model that answers in one shot often skips a step and gets it wrong. Making it work through the steps first gives each step a chance to be correct, and the final answer builds on them. Wei et al. (2022) showed this lifts large models on arithmetic, commonsense and logic tasks.

## How it works

The two routes reach the same place, but who writes the steps and what you control differ.

| | Chain-of-thought prompt | Reasoning model |
|---|---|---|
| Who writes the steps | You ask, the model writes them in the reply | The model, internally |
| You control | The wording and any worked examples | An effort level |
| Steps visible | Yes, in the reply | No; a summary at most |
| Cost | Longer visible output | Hidden reasoning tokens |

1. For a plain model, add an instruction like "work through the steps, then give the answer", or show a worked example.
2. The model writes the steps and then the answer, so you can see and check its reasoning.
3. For a reasoning model, do not add that instruction; instead set the effort (OpenAI `reasoning.effort`; Anthropic adaptive thinking with `effort`).
4. The reasoning model thinks internally and returns the answer, with at most a summary of its thinking.

So the key is to match the technique to the model: prompt for steps on a plain model, set effort on a reasoning model.

## Example

In an app you want a decision your code can use, not the thinking. Ask for a short `reason` field instead of the raw chain of thought, which a reasoning model may not expose anyway.

```json
{
  "orderId": "42",
  "eligible": true,
  "reason": "Returned 3 days after delivery; the example policy allows 7 days"
}
```

What to notice:

- The output is [structured](card:structured-output): `eligible` is a boolean your code can branch on, not prose it must parse.
- `reason` is one short sentence for a human to audit, not the model's full internal reasoning, so it stays cheap and safe to log.
- Asking a reasoning model to dump its raw thinking into the reply is discouraged and may be declined; a short reason is the reliable middle ground.
- This is an example reply shape, not output from a run; LLM replies are not reproducible.

## Rules and defaults

- **Reasoning models set effort, not wording:** OpenAI uses `reasoning.effort`; Anthropic uses adaptive thinking with `effort`, which replaced the older `budget_tokens` (verified 21-10-2026). Sampling and reasoning controls change fast, so re-check the provider docs before interviews.
- **Reasoning tokens are billed as output:** they add cost and latency and count toward the output limit, so a low limit can cut off the answer.
- **Do not force CoT on reasoning models:** OpenAI says "think step by step" is unnecessary and can hurt; keep the prompt clear and direct.
- **Skip reasoning for simple tasks:** plain extraction or classification does not need it; it only adds cost and latency.

## Not to be confused with

**Chain-of-thought** is a prompt asking a model to show its steps. A **[reasoning model](card:base-vs-instruct-vs-reasoning-model)** is a model that does the steps internally and gives you an effort dial. Rule: CoT is the technique; a reasoning model is a model with that behaviour built in, so you tune effort, not wording.

## Interview Qs

### What is chain-of-thought prompting?

Asking the model to write its intermediate reasoning steps before the final answer, rather than answering in one jump. Wei et al. (2022) showed it improves large models on arithmetic, commonsense and logic tasks, because each step gets a chance to be correct.

### Should you add "think step by step" for a reasoning model?

No. A reasoning model already reasons internally, and OpenAI says such prompts are unnecessary and can hurt. Set the effort level instead, and keep the prompt clear and direct. Manual chain-of-thought is for plain models that do not reason on their own.

### What do reasoning tokens cost you?

They are billed as output tokens, take up context space, and add latency, even though you usually do not see them. They also count toward the output limit, so if the limit is too low the hidden thinking can consume it and leave the visible answer empty or cut off.
