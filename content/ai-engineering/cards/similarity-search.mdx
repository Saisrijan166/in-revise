## Why it exists

Once text is a vector, "find related text" becomes "find the nearest vectors". You need a rule for "near".

## How it works

<Compare id="cosine-vs-dot-product-vs-euclidean" />

- Embed the question, score it against stored vectors, keep the top K.
- Scoring every vector is [exact kNN](card:exact-knn); millions of vectors need an [ANN index](card:vector-databases).

## Example

```java
public class Cosine {
    static double cosine(double[] a, double[] b) {
        double dot = 0, na = 0, nb = 0;
        for (int i = 0; i < a.length; i++) { dot += a[i] * b[i]; na += a[i] * a[i]; nb += b[i] * b[i]; }
        return dot / (Math.sqrt(na) * Math.sqrt(nb));
    }
    public static void main(String[] args) {
        System.out.println(cosine(new double[]{1, 2, 3}, new double[]{2, 4, 6})); // same direction
        System.out.println(cosine(new double[]{1, 0}, new double[]{0, 1}));       // unrelated
    }
}
```

```text output
1.0
0.0
```

## Interview Qs

### What is cosine similarity?

It measures the angle between two vectors. Pointing the same way gives 1, at right angles gives 0. Vector length is ignored, so it compares direction, which is where embeddings keep meaning.

### Cosine similarity or dot product?

Dot product also counts vector length. For unit-length vectors the two are equal, and computing a dot product is slightly faster. Otherwise use the metric the embedding model recommends.

### Similarity vs distance?

Similarity: bigger is closer. Distance: smaller is closer. Cosine distance is 1 minus cosine similarity, so both give the same order.
