## What it is

A neural network is a model built from many simple units called neurons, arranged in layers. Each neuron takes a weighted sum of the numbers coming into it, adds a bias, and applies an activation function to produce its own output, which feeds the next layer. The weights are the parameters that [training](card:how-models-learn) learns. "Deep learning" simply means a neural network with many hidden layers (the layers between input and output).

## Why it exists

For text, images and sound, nobody can write by hand the features that separate, say, a fraud photo from a normal one. A neural network learns those features itself: early layers pick up simple patterns, later layers combine them into complex ones, all from raw data. Stacking many layers (going deep) is what lets it capture patterns too subtle for hand-made features or shallow models.

## How it works

<Mermaid
  alt="A small neural network. Two input values, the features, connect to three neurons in a hidden layer; every connection has its own weight. The three hidden neurons connect to one output neuron, which gives the prediction."
  chart={`flowchart LR
  X1((x1)) -- w --> H1((h1))
  X1 -- w --> H2((h2))
  X1 -- w --> H3((h3))
  X2((x2)) -- w --> H1
  X2 -- w --> H2
  X2 -- w --> H3
  H1 --> Y((output))
  H2 --> Y
  H3 --> Y`}
/>

1. The input values enter the first layer; each connection carries its own weight.
2. Every neuron multiplies its inputs by those weights, sums them, adds a bias, and applies its activation (such as ReLU, which outputs `max(0, x)`).
3. Its output becomes input to the next layer, and this repeats layer by layer until the output layer gives the prediction.
4. Training adjusts all the weights so the predictions get closer to the right answers.

So the key is that the activation at each step is what makes stacked layers more than one big linear sum.

## Analogy

<Analogy title="An assembly line" limit="Real neurons are biological cells; here each 'worker' is just arithmetic, and the whole line is tuned by training, not by a manager.">
Each layer is a station on an assembly line. A station takes the parts from the station before, combines them in its own way, and passes a more finished piece along. By the last station, simple inputs have been built up into a final decision.
</Analogy>

## Example

The diagram above is the whole mechanism, so the "code" worth seeing is one neuron's arithmetic, written plainly.

```text
output = activation( w1*x1 + w2*x2 + bias )
       = max(0, w1*x1 + w2*x2 + bias)   // with ReLU activation
```

What to notice:

- The weights `w1`, `w2` and the `bias` are the numbers training sets; the inputs `x1`, `x2` come from the data or the previous layer.
- The `max(0, ...)` is the activation. Remove it and every layer becomes a plain weighted sum, so the whole network collapses to one linear step and cannot learn curved patterns.
- Real networks stack millions of such neurons; the transformer, the type behind [LLMs](card:transformer-and-attention), arranges them so each position can attend to the others.

## Interview Qs

### What is an activation function and why is it needed?

It applies a non-linear function to each neuron's output. Without it, any stack of layers is still one linear function and can only draw straight-line boundaries. The non-linearity is what lets the network learn complex, curved patterns. ReLU, which outputs `max(0, x)`, is the usual default.

### What makes deep learning "deep"?

Many hidden layers. Each layer builds on the one before, so the network learns its own features, from simple edges or words up to complex concepts, instead of relying on features a person hand-crafted.

### Why do neural networks need GPUs?

Training and inference are mostly huge numbers of independent weighted sums. GPUs have thousands of cores that run such operations in parallel, so they finish far faster than a general-purpose CPU that handles only a few at a time.
