## Why it exists

Hand-made features miss patterns in text, images and sound. A neural network learns its own features from raw data, layer by layer.

- Without activations, stacked layers act like one linear layer, so depth adds nothing.
- Training sets the weights: see [how models learn](card:how-models-learn).
- Transformers replaced RNNs in modern language models: see [transformers](card:transformer-and-attention).

## Interview Qs

### What is an activation function and why is it needed?

It applies a non-linear function to each neuron's output. Without it, any stack of layers is still one linear function and cannot learn complex patterns. ReLU is the usual default.

### What makes deep learning "deep"?

Many hidden layers. Each layer builds on the one before, so the network learns its own features, from simple to complex, instead of relying on hand-made ones.

### Why do neural networks need GPUs?

Training and inference are mostly huge numbers of weighted sums. GPUs and other accelerators run them in parallel, far faster than a general-purpose CPU.
