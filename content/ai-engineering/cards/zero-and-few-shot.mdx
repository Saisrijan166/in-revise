## Why it exists

Some formats and labels are hard to describe in words. Showing a few examples is often quicker and more reliable than writing more rules.

## How it works

<Compare id="zero-shot-vs-few-shot" />

- Make examples diverse and in one consistent format; wrap them in `<example>` tags.
- Too many similar examples can make the model copy them too closely.
- Weights change only in training: see [how models learn](card:how-models-learn).

## Example

```text
Classify the message as refund-status, payment-failed or other.

<example>Message: My UPI payment failed but the money was debited.
Label: payment-failed</example>
<example>Message: When will I get ₹500 back for order 42?
Label: refund-status</example>
<example>Message: Can I change my delivery address?
Label: other</example>

Message: {message}
Label:
```

## Interview Qs

### When would you use few-shot over zero-shot?

When the output format is unusual, labels follow specific rules, or replies must be consistent. Start zero-shot; add a few diverse examples if results drift.

### Does few-shot prompting change the model?

No. The examples are part of the input for that call. The model follows the pattern in context and its weights stay the same; changing weights is fine-tuning.

### How many examples should you give?

Anthropic suggests 3–5 diverse examples. Each one adds input tokens to every call, and too many similar ones can make the model overfit to them.
