## Why it exists

A model needs a fixed vocabulary of ids. Whole words leave rare words unknown; single characters make text too long. Sub-word tokens sit in between and can encode any text.

## How it works

| Text (tiktoken, o200k_base) | Tokens | Count |
|---|---|---|
| `Where is my refund?` | Where · is · my · refund · ? | 5 |
| `मेरा रिफंड कहाँ है?` (same question, Hindi) | म · ेरा · र · िफ · ंड · कहाँ · है · ? | 8 |
| `tokenization` | token · ization | 2 |

- A tokenizer such as byte-pair encoding (BPE) merges frequent character runs into tokens.
- Inside a sentence, a word's first token usually carries its leading space: `" refund"`.
- Tokenizers differ by model, so count with the model you will call.

## Example

```text
Request to the model:   system prompt + history + question   = input tokens
Model's reply:          visible answer (+ hidden reasoning)  = output tokens
Bill and rate limits:   input tokens + output tokens
```

## Interview Qs

### Why do tokens matter to a backend developer?

They set the context limit, the price and the latency of each call. Long prompts and long answers cost more and run slower, so trim the input and cap the output with a max-tokens setting.

### How do you know how many tokens a prompt uses?

Count with the provider's tokenizer before sending: tiktoken for OpenAI models, the token counting endpoint for Claude. After the call, read the usage field in the response.
