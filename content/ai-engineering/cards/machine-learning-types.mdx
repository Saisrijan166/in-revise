## What it is

Machine learning comes in a few kinds, and which one applies depends on the data you have rather than the problem you want to solve. A label is the right answer attached to a training example. Supervised learning gets labelled examples; unsupervised learning gets none and looks for structure; reinforcement learning gets no labels either but earns rewards for the actions it takes. Self-supervised learning is a trick that makes labels out of raw data, and it is how LLMs are mostly trained.

## Why it exists

You rarely get to pick your data; you get what the business already has. Sometimes every record carries an answer (past tickets with their category), sometimes nothing is labelled (a dump of complaint texts), and sometimes you can only judge a result after a sequence of actions (a game, or tuning replies from human rankings). Each situation needs a different learning method, so naming the kinds tells you which methods are even possible.

## How it works

<Compare id="supervised-vs-unsupervised-vs-reinforcement" />

1. Look at your data: does each example already carry the right answer?
2. If yes, use supervised learning. It predicts a category (classification, such as refund-or-not) or a number (regression, such as days-to-refund).
3. If no labels exist and you want to find groups, use unsupervised learning, such as clustering.
4. If there are no fixed answers but actions can be scored, use reinforcement learning, which learns a policy from rewards.

So the key question is simply "what answers, if any, does my data already contain?".

## Example

A single labelled example for a ticket classifier is just the input text paired with its answer. The model sees thousands of these and learns the mapping.

```json
{ "text": "Refund for order 42 not received yet", "label": "refund" }
```

What to notice:

- `text` is the feature, the input the model reads; `label` is the answer it must learn to produce.
- This pairing is what makes it supervised. Remove the `label` field and the same data could only be used unsupervised, for clustering.
- To cluster such texts without labels, you first turn each into a numeric [embedding](card:embeddings) so a model can measure which texts are similar.

## Rules and defaults

- **Supervised needs labels up front:** no labelled examples means no supervised model; labelling is often the costliest step.
- **Unsupervised has no single right answer:** its output is structure, such as clusters, that a person still has to interpret.
- **Self-supervised is not a fourth separate method:** it is supervised learning where the label is taken from the data itself (hide a token, predict it), used to pre-train LLMs on raw text.

## Interview Qs

### Supervised vs unsupervised learning?

Supervised learning trains on examples that carry the right answer (a label) and predicts it for new data. Unsupervised learning gets no labels and finds structure, such as clusters, which a person interprets later. The deciding factor is whether your data is labelled.

### Classification vs regression?

Both are supervised. Classification predicts a category, such as fraud or not fraud. Regression predicts a number, such as how many days a refund will take. The difference is the output type: a fixed set of classes versus a continuous value.

### Is LLM pre-training supervised or unsupervised?

Self-supervised: the model makes its own labels from raw text by predicting hidden or next tokens, so no person labels the data. Supervised fine-tuning on human-written examples comes after, to shape how the model answers.
