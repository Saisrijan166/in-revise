## Why it exists

Reports need per-category counts side by side, groups with no rows, and rows compared with an average. GROUP BY alone does none.

## How it works

| Need | Pattern | Watch out |
|---|---|---|
| Categories as columns | `SUM(CASE WHEN … THEN 1 ELSE 0 END)`, or `COUNT(CASE WHEN … THEN 1 END)` | Without ELSE 0, SUM gives NULL; COUNT gives 0 |
| Groups with zero rows | Parent `LEFT JOIN` child, `COUNT(child.id)` | A child condition in WHERE drops empty groups |
| Above the overall average | `WHERE x > (SELECT AVG(x) FROM …)` | The subquery must return one value |
| Above the group's own average | `AVG(x) OVER (PARTITION BY g)` in a subquery | Or a correlated subquery |

- Why: [COUNT(column) skips NULLs](card:aggregates-group-by); [child conditions belong in ON](card:joins).

## Example

```sql
SELECT d.name,
       COUNT(e.id)                                     AS staff,
       COALESCE(SUM(e.salary), 0)                      AS payroll,
       SUM(CASE WHEN e.salary >= 90 THEN 1 ELSE 0 END) AS senior
FROM departments d
LEFT JOIN employees e ON e.dept_id = d.id
GROUP BY d.id, d.name;
```

```text
name  | staff | payroll | senior
Eng   | 5     | 440     | 3
Sales | 2     | 130     | 0
HR    | 0     | 0       | 0      <- COUNT(*) would show 1
```

## Interview Qs

### Employees who earn more than their department's average?

Compute `AVG(salary) OVER (PARTITION BY dept_id) AS dept_avg` in a subquery; keep `salary > dept_avg`. A correlated subquery gives the same rows, except rows with a NULL dept_id.

### How do you turn rows into columns?

Write one aggregate over a CASE per output column. PostgreSQL also accepts `COUNT(*) FILTER (WHERE status = 'PAID')`. The column list is fixed in the query text.
