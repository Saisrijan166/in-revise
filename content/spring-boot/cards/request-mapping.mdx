## Why it exists

A request carries data in the verb, path, query string, headers and body. Mapping annotations route it to one method and hand over each value already converted to a Java type.

## How it works

<Mermaid
  alt="One request split into parts. The verb and path POST /payments/42/refunds pick the method through @PostMapping. The path segment 42 goes to @PathVariable. The query ?notify=true goes to @RequestParam. The Authorization header goes to @RequestHeader. The JSON body goes to @RequestBody."
  chart={`flowchart LR
  R(["POST /payments/42/refunds?notify=true"]) --> M["@PostMapping: picks the method"]
  R --> P["42: @PathVariable"]
  R --> Q["notify=true: @RequestParam"]
  H(["Header: Authorization"]) --> RH["@RequestHeader"]
  B(["Body: amount 500"]) --> RB["@RequestBody"]`}
/>

- Missing `@RequestParam` or `@RequestBody` gives 400; the type is converted for you (`long`, enums, dates).
- Spring Framework 7 adds built-in [API versioning](card:api-versioning): `@GetMapping(version = "1.2")`.

## Example

```java
@RestController
@RequestMapping("/payments")                          // shared path
class PaymentController {
    @GetMapping("/{id}")                               // GET /payments/42
    PaymentResponse one(@PathVariable long id) { ... }

    @GetMapping                                        // GET /payments?status=PAID
    List<PaymentResponse> list(@RequestParam(defaultValue = "OPEN") String status) { ... }

    @PostMapping                                       // JSON body
    PaymentResponse create(@RequestBody CreatePayment request) { ... }
}
```

## Interview Qs

### If @RequestMapping can map requests, why do we need @GetMapping?

@GetMapping is @RequestMapping fixed to GET. Plain @RequestMapping matches every HTTP method unless you set one, so shortcuts are shorter and safer on methods; @RequestMapping stays on the class for the shared path.

### Both get values from the URL: why @PathVariable and @RequestParam?

They mean different things. A path variable identifies the resource, like /payments/42. A request parameter filters, sorts or pages, like ?status=PAID.

### @RequestBody vs @RequestParam?

@RequestParam reads the query string or form fields. @RequestBody converts the whole body, usually JSON, into one object through a message converter.
