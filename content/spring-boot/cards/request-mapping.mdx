## Why it exists

An HTTP request carries data in several places: the verb, the path, the query string, headers and the body. Mapping annotations route the request to one method and hand it each value already converted to the right Java type.

## How it works

<Compare id="pathvariable-vs-requestparam-vs-requestbody" />

- `consumes` and `produces` match the `Content-Type` and `Accept` headers; a mismatch gives 415 or 406.
- `@PathVariable long id` needs no name because Boot's parent POM compiles with `-parameters`.
- API versioning (Framework 7, Boot 4): `version = "1.2"` matches only 1.2; `"1.2+"` matches 1.2 and the supported versions above. A missing version gives 400 unless it is made optional or given a default.

## Example

```java
@RestController
@RequestMapping("/api/orders")                            // shared path
class OrderController {
    @GetMapping("/{id}")                                   // GET /api/orders/42
    Order one(@PathVariable long id) { ... }

    @GetMapping                                            // GET /api/orders?status=PAID
    List<Order> list(@RequestParam(defaultValue = "OPEN") String status) { ... }

    @PostMapping(consumes = "application/json")            // body: {"item":"pen"}
    Order create(@RequestBody OrderRequest request) { ... }

    @GetMapping(path = "/{id}", version = "2.0+")          // with header X-Version: 2.0
    OrderV2 oneV2(@PathVariable long id) { ... }
}
```

Tell Boot where to read the version (`application.properties`):

```properties
spring.mvc.apiversion.use.header=X-Version
spring.mvc.apiversion.default=1.0
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| HTTP methods of `@RequestMapping` | All of them | Spring Framework 7.0 |
| `@RequestParam`, `@RequestBody` | Required | Spring Framework 7.0 |
| API version, once versioning is on | Required (missing gives 400) | Spring Framework 7.0 |

## Interview Qs

### @RequestMapping vs @GetMapping?

@GetMapping is @RequestMapping with method = GET. Plain @RequestMapping matches every HTTP method unless you set one, so use the verb shortcuts on methods and @RequestMapping on the class for the shared path.

### @PathVariable vs @RequestParam vs @RequestBody?

@PathVariable reads a segment of the URL path, like the id in /users/42. @RequestParam reads a query parameter or form field, like ?page=2. @RequestBody converts the request body, usually JSON, into an object through a message converter.

### How do you version a REST API in Spring Boot 4?

Use Spring Framework 7's built-in API versioning. Tell Boot where the version is, for example spring.mvc.apiversion.use.header=X-Version, then map methods with version = "1.1" or a baseline like "1.2+". Missing or unsupported versions get 400.
