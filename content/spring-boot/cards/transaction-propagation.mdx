## Why it exists

Service methods call each other, and each may be @Transactional. Spring must know whether the inner call shares the outer transaction or runs on its own.

## How it works

| Propagation | A transaction exists | No transaction |
| --- | --- | --- |
| `REQUIRED` (default) | Join it | Start one |
| `REQUIRES_NEW` | Suspend it, start a new one | Start one |
| `NESTED` | Savepoint inside it | Start one |
| `SUPPORTS` | Join it | Run without one |
| `MANDATORY` | Join it | Throw an exception |
| `NOT_SUPPORTED` | Suspend it, run without one | Run without one |
| `NEVER` | Throw an exception | Run without one |

- The inner method must be on another bean, so the call goes through its proxy.
- Spring advises a pool larger than the number of concurrent threads before using `REQUIRES_NEW`.

## Example

```java
@Transactional                                       // REQUIRED
public void placeOrder(OrderRequest request) {
    audit.record("attempt " + request.id());         // REQUIRES_NEW: commits now
    orders.save(Order.from(request));
    stock.reserve(request);                          // throws: the order rolls back,
}                                                    // the audit row stays

// In AuditService, another bean
@Transactional(propagation = Propagation.REQUIRES_NEW)
public void record(String message) { auditLog.save(new AuditEntry(message)); }
```

## Interview Qs

### If REQUIRED can start a transaction, why do we need REQUIRES_NEW?

For work that must commit on its own, such as an audit log or a failure record. REQUIRED would roll it back together with the caller.

### What is UnexpectedRollbackException?

An inner REQUIRED method failed and marked the shared transaction rollback-only. The outer method caught the error and tried to commit, so Spring throws this to show nothing was committed.

### REQUIRES_NEW vs NESTED?

REQUIRES_NEW is a separate transaction with its own commit. NESTED is one transaction with a savepoint: the inner part can roll back alone, but nothing commits until the outer one does.
