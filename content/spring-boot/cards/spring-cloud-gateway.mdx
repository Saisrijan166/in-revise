## Why it exists

Clients should not need every service's address, and each service should not repeat routing, rate limiting and resilience code. A gateway does this once, at the edge.

## How it works

<Mermaid
  alt="Gateway flow. A client sends GET /orders/42. The route with predicate Path=/orders/** matches. Pre filters such as the rate limiter run. The request goes to an orders instance through lb://orders. Post filters change the response, which goes back to the client."
  chart={`flowchart LR
  C([Client]) -- "GET /orders/42" --> M{"Predicate: Path=/orders/**"}
  M -- match --> PRE["Pre filters: rate limit"]
  PRE -- "lb://orders" --> S[orders instance]
  S --> POST["Post filters"]
  POST --> C`}
/>

- Route filters apply to one route; global filters to every route.
- Rate limiting keeps a token bucket per key in Redis and answers 429 when it is empty.

## Example

```yaml
spring:
  cloud:
    gateway:
      server:
        webflux:
          routes:
            - id: orders
              uri: lb://orders
              predicates:
                - Path=/orders/**
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| `lb://` and no instance found | 503 (404 with `use404=true`) | Spring Cloud Gateway 5.0 |
| Over the rate limit | 429 Too Many Requests | Spring Cloud Gateway 5.0 |
| Rate-limit key | The user's principal name; no key is denied | Spring Cloud Gateway 5.0 |

## Interview Qs

### What does an API gateway do?

It is the single entry point: it routes each request to the right service and does shared work once, such as rate limiting and circuit breaking.

### Predicates vs filters?

A predicate is a condition on the request, such as `Path=/orders/**`; the route matches when its predicates are true. A filter changes the request before it is forwarded, or the response after.

### How do you rate limit in Spring Cloud Gateway?

Add the RequestRateLimiter filter with the Redis rate limiter. It keeps a token bucket per key: `replenishRate` is the steady rate, `burstCapacity` the bucket size. Over the limit it returns 429.
