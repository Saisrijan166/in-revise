## Why it exists

Clients should not need every service's address, and every service should not repeat routing, rate limiting and resilience code. A gateway does this once, at the edge.

## How it works

<Mermaid
  alt="Gateway flow. A client sends GET /orders/42. The gateway handler mapping checks the routes; the route with predicate Path=/orders/** matches. Pre filters run, such as rate limiting and adding headers. The request goes to an orders instance through lb://orders. Post filters change the response, which goes back to the client."
  chart={`flowchart LR
  C([Client]) -- "GET /orders/42" --> M{"Route match? (predicates)"}
  M -- "Path=/orders/**" --> PRE["Pre filters: rate limit, headers"]
  PRE -- "lb://orders" --> S[orders instance]
  S --> POST["Post filters: change response"]
  POST --> C`}
/>

- **Predicates** decide *if* a route matches; **filters** decide *what changes*. Route filters apply to one route, global filters to all.
- All "pre" filter logic runs, then the proxied call, then all "post" logic.
- **Rate limiting:** `RequestRateLimiter` keeps a token bucket per key in Redis and answers 429 Too Many Requests when it is empty.

## Example

Add `spring-cloud-starter-gateway-server-webflux`, then define routes in Java (or under `spring.cloud.gateway.server.webflux.routes`):

```java
@Bean
RouteLocator routes(RouteLocatorBuilder builder) {
    return builder.routes()
        .route("orders", r -> r.path("/orders/**")
            .filters(f -> f
                .addResponseHeader("X-Gateway", "edge")
                .circuitBreaker(c -> c.name("orders").fallbackUri("forward:/fallback")))
            .uri("lb://orders"))
        .build();
}
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| URI without a port | 80 for http, 443 for https | Spring Cloud Gateway 5.0 |
| `lb://` and no instance found | 503 (404 with `use404=true`) | Spring Cloud Gateway 5.0 |
| Over the rate limit | 429 Too Many Requests | Spring Cloud Gateway 5.0 |
| Rate-limit key | The user's principal name; no key means denied | Spring Cloud Gateway 5.0 |

## Interview Qs

### What does an API gateway do in a microservice system?

It is the single entry point. It routes each request to the right service and handles shared work once, such as rate limiting, circuit breaking and header changes, so each service and client stays simpler.

### Predicates vs filters?

A predicate is a condition on the request, such as `Path=/orders/**` or a header; a route matches when all its predicates are true. A filter changes the request before it is forwarded, or the response after it returns.

### How do you rate limit in Spring Cloud Gateway?

Add the RequestRateLimiter filter with the Redis rate limiter. It keeps a token bucket per key, by default the user's principal name: replenishRate is the steady rate, burstCapacity the bucket size. Over the limit, it returns 429.

### Spring Cloud Gateway vs Zuul?

Zuul 1 was Netflix's gateway; Spring put it into maintenance mode in 2018 and removed it in 2020.0. Spring Cloud Gateway replaced it, in a reactive WebFlux variant and a servlet Web MVC variant.
