## Why it exists

Services call other services over HTTP. A client turns Java objects into requests and responses back into objects, and handles connections, errors and timeouts. Spring offers one blocking and one reactive client, plus a declarative layer on top.

## How it works

<Compare id="restclient-vs-webclient-vs-resttemplate" />

- An HTTP interface client is a Java interface with `@GetExchange`-style methods. `@ImportHttpServices` registers it as a bean, and Boot 4 reads its base URL from `spring.http.serviceclient.<group>.base-url`.
- A 4xx or 5xx response throws a `RestClientException` subclass; `onStatus(...)` lets you handle it your way.
- Migrate step by step: `RestClient.create(restTemplate)` reuses an existing template's setup.

## Example

```java
@Service
class PriceClient {
    private final RestClient http;

    PriceClient(RestClient.Builder builder) {               // auto-configured by Boot
        this.http = builder.baseUrl("https://prices.example.com").build();
    }

    Price price(String sku) {
        return http.get().uri("/prices/{sku}", sku)
                .retrieve()                                  // 4xx/5xx throw RestClientException
                .body(Price.class);
    }
}
```

The same call as an HTTP interface client:

```java
@HttpExchange("/prices")
interface PriceApi {
    @GetExchange("/{sku}")
    Price price(@PathVariable String sku);
}
// On a @Configuration class: @ImportHttpServices(group = "prices", types = PriceApi.class)
// In application.properties: spring.http.serviceclient.prices.base-url=https://prices.example.com
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| Builders you can inject | Prototype `RestClient.Builder`, `WebClient.Builder`; `RestTemplateBuilder` | Spring Boot 4.1 |
| HTTP library for RestClient | Apache HttpClient, else Jetty, Reactor Netty, JDK `HttpClient` | Spring Boot 4.1 (auto-detected) |
| HTTP Service group with no name | `default` | Spring Boot 4.1 |
| Starters | `spring-boot-starter-restclient`, `spring-boot-starter-webclient` | Spring Boot 4.0+ |

## Interview Qs

### RestTemplate vs RestClient vs WebClient?

RestTemplate: the classic blocking client with template methods, now deprecated. RestClient: also blocking, with a fluent API and new features such as API versioning. WebClient: non-blocking and reactive, for WebFlux apps or streaming. New blocking code should use RestClient.

### Is RestTemplate deprecated?

Spring Framework 7.0 deprecates it in the reference docs; the class gets @Deprecated(forRemoval = true) in 7.1, and the team plans to remove it in 8.0. It still works in Boot 4.1, which provides a RestTemplateBuilder but no RestTemplate bean.

### What is an HTTP interface client?

A Java interface whose methods carry @HttpExchange or @GetExchange. Spring generates a proxy that makes the calls through RestClient or WebClient. In Boot 4, @ImportHttpServices registers the proxies as beans, and properties set each group's base URL.
