## Why it exists

Classic Java web apps were a war deployed into a separately installed server. With the server inside, the app is one jar that starts with `java -jar`, which suits containers.

## How it works

| You add | Server | Stack |
| --- | --- | --- |
| `spring-boot-starter-webmvc` | Tomcat (default) | Servlet |
| webmvc minus `spring-boot-starter-tomcat`, plus `spring-boot-starter-jetty` | Jetty | Servlet |
| `spring-boot-starter-webflux` | Reactor Netty (default) | Reactive |

- `server.port=0` picks a free port; `-1` keeps the context but opens no HTTP port.
- On shutdown the server stops new requests and lets running ones finish: graceful by default.

## Example

```properties
server.port=9090
# graceful is the default; immediate turns it off
server.shutdown=graceful
spring.lifecycle.timeout-per-shutdown-phase=20s
```

## Defaults

| What | Default | Where |
| --- | --- | --- |
| `server.port` | `8080` | Spring Boot 4.1 |
| `server.shutdown` | `graceful` | Spring Boot 4.1 |

## Interview Qs

### Which embedded servers does Spring Boot support, and how do you switch?

Tomcat (default) and Jetty for servlet apps; Reactor Netty is the WebFlux default. Boot 4 removed Undertow. To switch, exclude `spring-boot-starter-tomcat` and add `spring-boot-starter-jetty`.

### How do you change the port, or pick a random one?

Set `server.port=9090` in application.properties, or the `SERVER_PORT` variable. `server.port=0` picks a free port.

### Can you run Boot without any web server?

Yes. Set `spring.main.web-application-type=none`, or leave web starters off the classpath.
