## Why it exists

Picking compatible versions of dozens of libraries is slow and error-prone. Starters bundle the libraries for one feature, and Boot's BOM fixes one tested version of each.

## How it works

| Starter | Brings |
| --- | --- |
| `spring-boot-starter-webmvc` | Spring MVC and embedded Tomcat |
| `spring-boot-starter-data-jpa` | Spring Data JPA with Hibernate |
| `spring-boot-starter-validation` | Bean Validation with Hibernate Validator |
| `spring-boot-starter-actuator` | Production features: health, metrics |
| `spring-boot-starter-test` | JUnit Jupiter, Hamcrest and Mockito |

- Versions come from the `spring-boot-dependencies` BOM. Get it by inheriting `spring-boot-starter-parent`, or import the BOM if you must keep another parent ([compare](compare:starter-parent-vs-bom-import)). Gradle uses the dependency-management plugin or `platform(...)`.
- **Boot 4:** auto-configuration is split into small modules, each with its own starter. Flyway, for example, now needs `spring-boot-starter-flyway`.

## Example

```xml
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>4.1.1</version>
</parent>
<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-webmvc</artifactId>
        <!-- no <version>: the BOM manages it -->
    </dependency>
</dependencies>
```

## Interview Qs

### What is a Spring Boot starter?

A dependency descriptor that brings a tested set of libraries for one feature. `spring-boot-starter-data-jpa`, for example, brings Spring Data JPA and Hibernate, so you add one dependency instead of many.

### How does Spring Boot manage dependency versions?

Through the `spring-boot-dependencies` BOM. Inherit `spring-boot-starter-parent` or import the BOM, then leave out `<version>` for managed libraries. Upgrading Boot upgrades them all together, in a tested combination.

### How do you override one managed version?

With the parent, set its property, such as `<slf4j.version>`. With an imported BOM, declare that dependency in `dependencyManagement` before the Boot BOM. Do it with care: each Boot release is tested with its own set.

### What is Spring Initializr?

A web tool at start.spring.io that generates a ready project. You pick the build tool, language, Boot and Java version, jar or war packaging, and the starters you need.
