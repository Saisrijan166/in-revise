# 1. Python Fundamentals

## 1.1 Introduction to Python

- Python: High-level, general-purpose programming language known for simple and readable syntax.
- Interpreted Language: Python code is executed by the Python runtime. It is commonly described as interpreted, although CPython also compiles code into bytecode.
- Dynamically Typed: You don't need to declare variable types. Python determines the type at runtime.
- Strongly Typed: Python does not automatically combine incompatible types, such as a string and an integer.
- Object-Oriented: Python supports classes, objects, inheritance, polymorphism, and encapsulation.
- Cross-Platform: Python programs can run on Windows, Linux, and macOS.
- Open Source: Python is free to use and has a large community.
- Case-Sensitive: `name` and `Name` are different variables.
- Indentation: Python uses indentation to define code blocks instead of `{}`.
- PEP 8: Official Python style guidelines for writing readable code.
- Python Version: Python 3 is the modern version used in development.

### Example

```
name = "Srijan"age = 25print(name)print(age)print(type(age))
```

Output:

```
Srijan
25
<class 'int'>
```

## 1.2 Python Execution Basics

- Source Code: Python code written in `.py` files.
- Bytecode: Intermediate instructions generated by Python before execution.
- PVM (Python Virtual Machine): Executes Python bytecode.
- CPython: The standard and most commonly used Python implementation, written in C.
- Jython: Python implementation that runs on the JVM.
- PyPy: Alternative Python implementation that uses JIT compilation.
- REPL: Interactive environment where you can execute Python statements one by one.
- Script: A Python file containing executable code.
- Module: A Python file that contains reusable code.
- Package: A collection of related Python modules, usually organized in directories.

# 2. Variables and Data Types

## 2.1 Variables

- Variable: A name that refers to an object stored in memory.
- Dynamic Assignment: The same variable can refer to objects of different types.
- Multiple Assignment: Assign multiple values in one statement.
- Variable Naming: Names can contain letters, numbers, and underscores but cannot start with a number.
- Reserved Keywords: Words such as `class`, `if`, `for`, and `return` cannot be used as variable names.
- Type Inference: Python determines the variable's type automatically.

### Example

```
name = "Srijan"age = 25a, b, c = 10, 20, 30x = 10x = "Python"
```

## 2.2 Built-in Data Types

Python has several important built-in data types.

| Data type  | Meaning                       | Example     |
| ---------- | ----------------------------- | ----------- |
| `int`      | Integer numbers               | `10`        |
| `float`    | Decimal numbers               | `10.5`      |
| `complex`  | Complex numbers               | `2+3j`      |
| `str`      | Text                          | `"Hello"`   |

## 2.4 Type Checking

- `type()`: Returns the exact type of an object.
- `isinstance()`: Checks whether an object belongs to a type or its subclasses.


Interview difference: Prefer `isinstance()` when checking types because it supports inheritance.

# 3. Operators

## 3.1 Arithmetic Operators

| Operator | Meaning             | Example   |
| -------- | ------------------- | --------- |

- `/` always returns a float.
- `//` rounds down towards negative infinity.


- `==` Equal to.
- `!=` Not equal to.
- `>` Greater than.
- `<` Less than.
- `>=` Greater than or equal.
- `<=` Less than or equal.

Important: `==` compares values, while `is` checks object identity.

## 3.3 Logical Operators

- `and`: True when both conditions are true.
- `or`: True when at least one condition is true.
- `not`: Reverses a Boolean result.

```
age = 25print(age > 18 and age < 60)  # Trueprint(age < 18 or age > 60)   # Falseprint(not age > 18)           # False
```

## 3.4 Assignment Operators

| Operator | Meaning                 |
| -------- | ----------------------- |

## 3.5 Membership Operators

- `in`: Checks whether an element exists in a collection.
- `not in`: Checks whether an element does not exist.

```

```

For dictionaries, membership checks keys by default.

## 3.6 Identity Operators

- `is`: Checks whether two variables refer to the same object.
- `is not`: Checks whether they refer to different objects.

```
a = [1, 2]b = [1, 2]print(a == b)  # Trueprint(a is b)  # False
```

Remember:

- `==` → Same value?
- `is` → Same object?

Use `is None` to check for `None`.

# 4. Conditional Statements and Loops

## 4.1 Conditional Statements

- `if`: Executes code when a condition is true.
- `elif`: Checks another condition if previous conditions were false.
- `else`: Executes when all previous conditions are false.
- Nested if: An if statement inside another if statement.
- Ternary Expression: Short one-line conditional expression.

### Example

```
age = 20if age >= 18:    print("Adult")elif age >= 13:    print("Teenager")else:    print("Child")
```

Ternary:

```
result = "Pass" if marks >= 40 else "Fail"
```

## 4.2 Loops

- `for`: Iterates over an iterable such as a list, string, tuple, or range.
- `while`: Repeats while a condition is true.
- Nested Loop: A loop inside another loop.
- Infinite Loop: A loop that never stops unless interrupted.

### Example

```
for i in range(5):    print(i)
```

Output:

```
0
1
2
3
4
```

```
i = 0while i < 3:    print(i)    i += 1
```

## 4.3 Important Loop Keywords

- `break`: Immediately exits the nearest loop.
- `continue`: Skips the current iteration and moves to the next.
- `pass`: Does nothing; used as a placeholder.
- `range()`: Generates a sequence of integers.
- `enumerate()`: Returns index and value while iterating.
- `zip()`: Iterates over multiple iterables together.
- `else` in loops: Runs when a loop completes normally, without hitting `break`.

### Example

```
for i in range(5):    if i == 3:        break    print(i)
```

```
names = ["A", "B", "C"]for index, name in enumerate(names):    print(index, name)
```

```
a = [1, 2, 3]b = ["A", "B", "C"]for x, y in zip(a, b):    print(x, y)
```

### Important `range()` rules

```
range(start, stop, step)
```

- Default start = `0`.
- Stop value is excluded.
- Default step = `1`.
- Step can be negative.

```
print(list(range(1, 5)))# [1, 2, 3, 4]print(list(range(5, 0, -1)))# [5, 4, 3, 2, 1]
```

- Indexing: Accessing individual characters using positions.
- Slicing: Extracting a portion of a string.
- Concatenation: Joining strings using `+`.
- String Formatting: Inserting values into strings.
- Escape Characters: Special characters such as `\n` and `\t`.

# 6. Lists

## 6.1 List Basics

- List: Ordered, mutable collection of elements.
- Ordered: Maintains insertion order.
- Mutable: Elements can be changed, added, or removed.
- Duplicates: Allowed.
- Heterogeneous: Can store different data types.
- Nested List: A list inside another list.

### Example

```
numbers = [10, 20, 30, 40]print(numbers[0])print(numbers[-1])numbers[1] = 25print(numbers)
```

## 6.2 Important List Methods

| Method             | Purpose                            |
| ------------------ | ---------------------------------- |
| `append(x)`        | Add one element at the end         |
| `extend(iterable)` | Add multiple elements              |
| `insert(i, x)`     | Insert at a position               |
| `remove(x)`        | Remove first matching value        |
| `pop()`            | Remove and return last element     |
| `pop(i)`           | Remove and return element at index |
| `clear()`          | Remove all elements                |
| `index(x)`         | Return first matching index        |
| `count(x)`         | Count occurrences                  |
| `sort()`           | Sort list in place                 |
| `reverse()`        | Reverse list in place              |
| `copy()`           | Create a shallow copy              |

### Example

```
numbers = [3, 1, 2]numbers.append(4)numbers.extend([5, 6])numbers.insert(0, 10)numbers.remove(1)print(numbers)numbers.sort()print(numbers)
```

## 6.3 Important List Differences

append() vs extend()

```
a = [1, 2]a.append([3, 4])# [1, 2, [3, 4]]b = [1, 2]b.extend([3, 4])# [1, 2, 3, 4]
```

remove() vs pop()

- `remove(value)` removes by value.
- `pop(index)` removes by index and returns the removed element.
- `pop()` removes the last element.

sort() vs sorted()

- `sort()` changes the original list and returns `None`.
- `sorted()` returns a new sorted list and works with any suitable iterable.

```
a = [3, 1, 2]b = sorted(a)a.sort()print(a)  # [1, 2, 3]print(b)  # [1, 2, 3]
```

## 6.4 List Comprehension

- List Comprehension: A short way to create a new list using an expression and an iterable.
- Can include conditions.
- Usually more concise than a traditional loop.

```
numbers = [1, 2, 3, 4, 5]squares = [x * x for x in numbers]even = [x for x in numbers if x % 2 == 0]print(squares)print(even)
```

# 7. Tuples, Sets and Dictionaries

## 7.1 Tuples

- Tuple: Ordered, immutable collection.
- Duplicates: Allowed.
- Indexing: Supported.
- Slicing: Supported.
- Modification: Cannot add, remove, or replace tuple elements.
- Use Case: Fixed collections of values.

```
data = (10, 20, 30)print(data[0])print(data[1:])# Single-element tuplex = (10,)
```

Important: A single-element tuple requires a trailing comma.

### Tuple Unpacking

```
person = ("Srijan", 25)name, age = personprint(name)print(age)
```

## 7.2 Sets

- Set: Collection of unique, hashable elements.
- Duplicates: Automatically removed.
- Ordering: Sets do not guarantee insertion-order iteration.
- Indexing: Not supported.
- Mutable: Yes.
- Use Case: Removing duplicates and mathematical set operations.

```
numbers = {1, 2, 2, 3}print(numbers)# {1, 2, 3}numbers.add(4)numbers.remove(2)
```

### Important Set Methods

| Method                   | Purpose                                  |
| ------------------------ | ---------------------------------------- |
| `add()`                  | Add element                              |
| `update()`               | Add multiple elements                    |
| `remove()`               | Remove element; error if missing         |
| `discard()`              | Remove element; no error if missing      |
| `pop()`                  | Remove and return an arbitrary element   |
| `clear()`                | Remove all elements                      |
| `union()`                | Combine unique elements                  |
| `intersection()`         | Get common elements                      |
| `difference()`           | Get elements only in first set           |
| `symmetric_difference()` | Get elements in either set, but not both |

### Set Operations

```
a = {1, 2, 3}b = {3, 4, 5}print(a | b)  # Unionprint(a & b)  # Intersectionprint(a - b)  # Differenceprint(a ^ b)  # Symmetric difference
```

Set vs frozenset:

- `set` is mutable.
- `frozenset` is immutable and hashable.

## 7.3 Dictionaries

- Dictionary: Mutable collection of key-value pairs.
- Keys: Must be hashable and unique.
- Values: Can be of any type.
- Duplicates: Keys cannot be duplicated; assigning an existing key updates its value.
- Ordering: Preserves insertion order in modern Python.
- Access: Values are accessed using keys.

### Example

```
student = {    "name": "Srijan",    "age": 25,    "skills": ["Java", "Python"]}print(student["name"])print(student.get("age"))
```

### Important Dictionary Methods

| Method         | Purpose                               |
| -------------- | ------------------------------------- |
| `get()`        | Get value safely                      |
| `keys()`       | Return keys                           |
| `values()`     | Return values                         |
| `items()`      | Return key-value pairs                |
| `update()`     | Add or update values                  |
| `pop()`        | Remove specified key and return value |
| `popitem()`    | Remove and return last inserted pair  |
| `setdefault()` | Get value or insert default           |
| `clear()`      | Remove all items                      |
| `copy()`       | Shallow copy                          |

### Example

```
user = {"name": "Srijan"}user["age"] = 25user.update({"city": "Hyderabad"})print(user.get("email", "Not found"))for key, value in user.items():    print(key, value)
```

Important differences:

- `dict["key"]` raises `KeyError` if missing.
- `dict.get("key")` returns `None` by default if missing.
- Dictionary keys must be hashable.
- Lists and dictionaries cannot be dictionary keys.
- Strings, integers, and suitable tuples can be dictionary keys.

# 8. Functions

## 8.1 Function Basics

- Function: Reusable block of code that performs a specific task.
- `def`: Keyword used to define a function.
- Parameter: Variable defined in the function declaration.
- Argument: Actual value passed when calling a function.
- Return: Sends a result back to the caller.
- Function Call: Executing a function.
- Docstring: Documentation written inside a function, class, or module.
- Scope: Determines where a variable can be accessed.

### Example

```
def add(a, b):    return a + bresult = add(10, 20)print(result)
```

## 8.2 Parameters and Arguments

- Positional Arguments: Values passed according to parameter position.
- Keyword Arguments: Values passed using parameter names.
- Default Arguments: Parameters with predefined values.
- Variable-Length Arguments: Allow a function to accept a variable number of arguments.
- Required Arguments: Parameters that must receive values.

### Example

```
def greet(name, message="Hello"):    print(message, name)greet("Srijan")greet("Srijan", "Welcome")greet(name="Srijan", message="Hi")
```

## 8.3 \*args and \*\*kwargs

Very important interview topic.

- `*args`: Collects extra positional arguments into a tuple.
- `**kwargs`: Collects extra keyword arguments into a dictionary.

```
def demo(*args, **kwargs):    print(args)    print(kwargs)demo(10, 20, name="Srijan", age=25)
```

Output:

```
(10, 20)
{'name': 'Srijan', 'age': 25}
```

Remember:

- `*` is associated with positional argument unpacking.
- `**` is associated with keyword argument unpacking.
- The names `args` and `kwargs` are conventions; the symbols are what matter.

## 8.4 Return vs Print

- `print()`: Displays output on the screen.
- `return`: Sends a value back to the caller.
- A function without an explicit return statement returns `None`.

```
def add(a, b):    print(a + b)def multiply(a, b):    return a * bx = add(2, 3)       # Prints 5y = multiply(2, 3)  # Returns 6print(x)  # Noneprint(y)  # 6
```

## 8.5 Lambda Functions

- Lambda: Small anonymous function written in one expression.
- Commonly used with `map()`, `filter()`, and sorting.
- Can contain an expression, not multiple statements.

```
square = lambda x: x * xprint(square(5))# 25
```

## 8.6 Recursion

- Recursion: A function calling itself.
- Base Condition: Stops recursion.
- Recursive Case: Calls the function again with a smaller or changed problem.
- Python has a recursion limit; deep recursion can raise `RecursionError`.

```
def factorial(n):    if n == 0:        return 1    return n * factorial(n - 1)print(factorial(5))# 120
```

## 8.7 Scope: LEGB Rule

Python searches for variables in this order:

1. L – Local: Inside the current function.
2. E – Enclosing: Inside outer functions.
3. G – Global: At module level.
4. B – Built-in: Python's built-in names.

### Important keywords

- `local`: Variable defined inside a function.
- `global`: Allows modifying a module-level variable inside a function.
- `nonlocal`: Allows modifying a variable in an enclosing function.

```
x = 10def demo():    global x    x = 20demo()print(x)  # 20
```

## 8.8 Important Function Concepts

- First-Class Functions: Functions can be assigned to variables, passed as arguments, and returned from other functions.
- Higher-Order Functions: Functions that accept other functions or return functions.
- Closure: An inner function remembers variables from its enclosing scope.
- Decorator: A function that wraps another function to add or modify behavior.
- Pure Function: Produces the same output for the same input without side effects.
- Side Effect: A function changes something outside its local scope, such as a global variable or file.

### Decorator Example

```
def my_decorator(func):    def wrapper():        print("Before")        func()        print("After")    return wrapper@my_decoratordef hello():    print("Hello")hello()
```

Output:

```
Before
Hello
After
```

Remember: `@my_decorator` is shorthand for wrapping the function with the decorator.

# 9. Object-Oriented Programming (OOP)

Python supports all major OOP concepts. This is one of the most important interview sections.

## 9.1 Class and Object

- Class: Blueprint used to create objects.
- Object: Instance of a class.
- Attribute: Variable belonging to an object or class.
- Method: Function defined inside a class.
- Instance: An object created from a class.
- `self`: Refers to the current instance.
- `__init__()`: Initialization method called when an instance is created.

### Example

```
class Student:    def __init__(self, name, age):        self.name = name        self.age = age    def display(self):        print(self.name, self.age)s1 = Student("Srijan", 25)s1.display()
```

## 9.2 Constructor and Destructor

- Constructor (commonly called): Initializes an object when it is created. In Python, `__init__()` is technically an initializer, while `__new__()` creates the instance.
- `__init__()`: Initializes the object's attributes.
- `__new__()`: Creates and returns a new instance.
- `__del__()`: Finalizer called when an object is being finalized; timing is not guaranteed.

```
class Demo:    def __init__(self):        print("Object initialized")
```

Important: Do not rely on `__del__()` for important resource cleanup. Prefer context managers.

## 9.3 Four Pillars of OOP

### 1. Encapsulation

- Encapsulation: Combining data and methods inside a class and controlling access to internal data.
- Python uses naming conventions and properties rather than strict private access restrictions.

```
class Employee:    def __init__(self):        self.name = "Srijan"        self._salary = 50000        self.__password = "abc123"
```

- `name`: Public.
- `_salary`: Protected by convention.
- `__password`: Name-mangled to reduce accidental access.

Important: Python does not enforce strict private access like Java.

### 2. Inheritance

- Inheritance: A child class reuses and extends functionality from a parent class.
- Parent/Base Class: Class being inherited.
- Child/Derived Class: Class that inherits another class.
- Method Overriding: Child class provides its own implementation of a parent method.
- `super()`: Accesses functionality through the method resolution order (MRO), commonly used to call parent implementations.

```
class Animal:    def sound(self):        print("Animal sound")class Dog(Animal):    def sound(self):        print("Bark")d = Dog()d.sound()
```

### Types of Inheritance

- Single: One child inherits one parent.
- Multiple: One child inherits multiple parents.
- Multilevel: A class inherits from a child class.
- Hierarchical: Multiple child classes inherit one parent.
- Hybrid: Combination of inheritance types.

### 3. Polymorphism

- Polymorphism: Same interface or method name can behave differently depending on the object.
- Method Overriding: Child class changes inherited method behavior.
- Duck Typing: If an object supports the required behavior, Python allows it to be used without requiring a particular class.

```
class Dog:    def sound(self):        print("Bark")class Cat:    def sound(self):        print("Meow")for animal in [Dog(), Cat()]:    animal.sound()
```

Important: Python does not support traditional Java-style method overloading by defining multiple methods with the same name. The later definition replaces the earlier one. Use default arguments or `*args` when needed.

### 4. Abstraction

- Abstraction: Hiding implementation details and exposing only necessary functionality.
- ABC: Abstract Base Class.
- Abstract Method: Method declared without a complete implementation that concrete subclasses must implement.
- `abc` module: Provides abstract class functionality.

```
from abc import ABC, abstractmethodclass Payment(ABC):    @abstractmethod    def pay(self):        passclass UPI(Payment):    def pay(self):        print("UPI payment")
```

You cannot instantiate an abstract class while it has unimplemented abstract methods.

## 9.4 Types of Methods

| Method          | Meaning                                        |
| --------------- | ---------------------------------------------- |
| Instance Method | Works with object data; receives `self`        |
| Class Method    | Works with class-level data; receives `cls`    |
| Static Method   | Utility method; receives neither automatically |

### Example

```
class Demo:    count = 0    def instance_method(self):        print("Instance method")    @classmethod    def class_method(cls):        print(cls.count)    @staticmethod    def static_method():        print("Static method")
```

## 9.5 Important OOP Terminology

- MRO (Method Resolution Order): Order Python follows to find methods in an inheritance hierarchy.
- `isinstance()`: Checks whether an object belongs to a class or its subclasses.
- `issubclass()`: Checks whether a class inherits from another class.
- Composition: One class contains an object of another class; represents a HAS-A relationship.
- Aggregation: A weaker HAS-A relationship where contained objects can exist independently.
- Association: General relationship between objects.
- Magic/Dunder Methods: Special methods with double underscores, such as `__init__`, `__str__`, and `__len__`.

# 10. Exception Handling

## 10.1 Exception Basics

- Exception: An error or unusual condition that occurs during program execution.
- Error: A broader term for problems in a program.
- Exception Handling: Managing exceptions without unnecessarily crashing the application.
- `try`: Contains code that may raise an exception.
- `except`: Handles an exception.
- `else`: Executes when the try block completes without an exception.
- `finally`: Executes whether an exception occurs or not, subject to process termination.
- `raise`: Manually raises an exception.

# 15. Memory Management and Copying

## 15.1 Memory Management

- Object: Everything in Python is an object.
- Reference: A variable holds a reference to an object.
- Reference Counting: CPython tracks how many references point to an object.
- Garbage Collection: Reclaims memory occupied by unreachable objects.
- Garbage Collector: Helps detect and clean up reference cycles.
- `del`: Removes a name or reference; it does not necessarily destroy the object immediately.
- `gc` module: Provides garbage collection controls.

Important: Python manages memory automatically, but developers should still manage resources such as files and network connections.

## 15.2 Shallow Copy vs Deep Copy

A very common interview question.

- Shallow Copy: Creates a new outer object but keeps references to nested objects.
- Deep Copy: Recursively copies nested objects too.
- Assignment: Creates another reference to the same object, not a copy.

### Example

```
import copyoriginal = [[1, 2], [3, 4]]shallow = copy.copy(original)deep = copy.deepcopy(original)original[0][0] = 100print(shallow)  # [[100, 2], [3, 4]]print(deep)     # [[1, 2], [3, 4]]
```

### Remember

| Operation    | New outer object? | Nested objects copied? |
| ------------ | ----------------- | ---------------------- |
| Assignment   | No                | No                     |
| Shallow copy | Yes               | No                     |
| Deep copy    | Yes               | Yes, recursively       |

## 15.3 Mutable Default Argument Problem

A very common interview question.

Incorrect:

```
def add_item(item, items=[]):    items.append(item)    return items
```

The default list is created once when the function is defined and reused across calls.

Correct:

```
def add_item(item, items=None):    if items is None:        items = []    items.append(item)    return items
```

Rule: Avoid mutable objects such as lists and dictionaries as default function arguments unless shared state is intentional.

# 18. Multithreading, Multiprocessing and Async

Very important when discussing performance and backend development.

## 18.1 Concurrency vs Parallelism

- Concurrency: Multiple tasks make progress during overlapping periods.
- Parallelism: Multiple tasks execute at the same time, typically on multiple CPU cores.
- Thread: Lightweight execution unit within a process.
- Process: Independent running program with its own memory space.

## 18.2 Multithreading

- Multithreading: Runs multiple threads within one process.
- Threads share the same process memory.
- Useful mainly for I/O-bound tasks such as network requests and file operations.
- In standard CPython builds, the GIL limits simultaneous execution of Python bytecode by threads.

```
import threadingdef task():    print("Task running")t = threading.Thread(target=task)t.start()t.join()
```

## 18.3 Multiprocessing

- Multiprocessing: Runs multiple processes.
- Each process has its own memory space.
- Useful for CPU-bound work.
- Can execute CPU tasks in parallel across multiple cores.

```
from multiprocessing import Processdef task():    print("Process running")if __name__ == "__main__":    p = Process(target=task)    p.start()    p.join()
```

## 18.4 GIL (Global Interpreter Lock)

- GIL: A lock in standard GIL-enabled CPython that allows only one thread at a time to execute Python bytecode in an interpreter.
- It affects CPU-bound multithreading performance.
- It does not prevent threads from being useful for I/O-bound tasks.
- Multiprocessing can provide CPU parallelism.
- Free-threaded CPython builds are also available, so the GIL is not universal across all Python configurations.

### Threading vs Multiprocessing

| Feature           | Threading                          | Multiprocessing         |
| ----------------- | ---------------------------------- | ----------------------- |
| Execution unit    | Thread                             | Process                 |
| Memory            | Shared process memory              | Separate process memory |
| CPU-bound work    | Limited by GIL in standard CPython | Good for parallelism    |
| I/O-bound work    | Good                               | Possible, but heavier   |
| Resource overhead | Usually lower                      | Usually higher          |
| Communication     | Shared memory                      | IPC / queues / pipes    |

## 18.5 Asynchronous Programming

- Async Programming: Allows tasks to cooperate without blocking while waiting for operations.
- `async`: Defines a coroutine function.
- `await`: Suspends the coroutine until an awaitable completes.
- Coroutine: A function execution object that can pause and resume.
- Event Loop: Schedules and runs asynchronous tasks.
- `asyncio`: Python's standard asynchronous programming library.

### Example

```
import asyncioasync def task():    print("Start")    await asyncio.sleep(1)    print("End")asyncio.run(task())
```

### Important differences

- Threading → Multiple threads.
- Multiprocessing → Multiple processes.
- Asyncio → Cooperative asynchronous tasks, commonly on one event loop thread.
- `await` does not automatically create a new thread.
- Async programming is especially useful for I/O-bound operations.

```
query = "SELECT * FROM users WHERE name = '" + name + "'"
```

Prefer parameterized queries:

```
cursor.execute(    "SELECT * FROM users WHERE name = ?",    (name,))
```

Placeholder syntax depends on the database driver.
